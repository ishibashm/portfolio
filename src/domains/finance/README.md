# Quant Finance & Trend Analytics Subdomain (Subdomain 3)

## 役割と範囲
- 日本株・J-Quants v2 API / Yahoo Finance 財務データ可視化 (`FinancialStatementVisualizer`)
- 決算サマリー・IR分析 (`/research/yfinance`)
- SNSトレンド・X (Twitter) ポスト収集・マクロ経済指標 (`/trends`, `/x-viewer`)

## ディレクトリ構造
- `components/`: 財務チャート・決算カード・トレンドビューア
- `services/`: 株価・財務データ取得・J-Quants / Yahoo Finance API
