# Next.jsとMDXで作るモダンブログ

Next.jsのApp RouterとMDXを組み合わせることで、**コンテナンツをReactコンポーネントとして書ける**ブログシステムを構築できます。

## MDXとは

MDXは、Markdown文書内でJSXコンポーネントを直接記述できる形式です。これにより：

- 通常のMarkdown記法はそのまま使用可能
- Reactコンポーネントを`<Component />`として埋め込み可能
- props を渡してコンポーネントをカスタマイズできる

## 主な特徴

1. **コンポーネント埋め込み**: カスタムReactコンポーネントを直接記述
2. **シンタックスハイライト**: コードブロックの自動カラーリング
3. **インタラクティブ**: JavaScriptで動作する動的コンテンツ

### コードブロックの例

```typescript
// TypeScriptで記述
const greeting = "こんにちは！";

function BlogComponent({ title }: { title: string }) {
  return (
    <div>
      <h2>{title}</h2>
      <p>{greeting}</p>
    </div>
  );
}
```

### リスト機能

主なメリット：

- 📝 **標準的なMarkdown記法**を使える
- ⚛️ **Reactコンポーネント**を埋め込める
- 🎨 **カスタムスタイリング**が簡単
- 🔧 **プロパティ渡し**でカスタマイズ可能

## 実装のポイント

> **注意**: MDXを使うには適切な設定とライブラリのインストールが必要です。

### 必要なパッケージ

```bash
npm install next-mdx-remote gray-matter
```

### 記事の構造

```markdown
---
title: "記事タイトル"
date: "2025-01-16"
description: "記事の説明"
tags: ["タグ1", "タグ2"]
---

# 記事の本文

MDX形式で書かれた本文...
```

## まとめ

MDXを使うことで、**静的コンテンツに動的な要素を加える**ことができ、より豊かなブログ体験を提供できます。

特に以下のような用途に最適です：

1. 技術ブログでのコードサンプル
2. インタラクティブなチュートリアル
3. カスタムコンポーネントを使ったドキュメント

これで、記事を書くだけでリアルタイムにWebページとして公開できるブログシステムの完成です！
