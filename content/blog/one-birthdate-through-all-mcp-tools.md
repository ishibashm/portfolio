## この記事でやったこと

Cloud Paletteの公開MCP（`https://cloud-palette.com/api/mcp`）には8つのツールがあります。この記事では、**1988年生まれ・三碧木星の一例**を入力にして、全部のツールを2026年10月16日に呼びました。出発地は名古屋（緯度35.1815、経度136.9066）です。

以下の数字は、すべてツールが返した値です。生年月日は例として使ったもので、特定の人の運勢を述べるものではありません。

| ツール                 | 分かること                             |
| ---------------------- | -------------------------------------- |
| `get_honmei_star`      | 本命星（九星気学）                     |
| `get_kanshi`           | 年月日の干支、空亡、干支併臨の年       |
| `judge_directions`     | ある日の8方位の判定                    |
| `find_auspicious_days` | 期間内で方位ごとに使える日             |
| `judge_time_slots`     | 1日を12の刻に分けた判定                |
| `search_municipality`  | 市区町村コードと家賃の目安             |
| `area_directions`      | ある市区町村から見た方位ごとの市区町村 |
| `prefecture_summary`   | 県全体を方位で分けた一覧               |

## 本命星と干支は別の体系から出ている

`get_honmei_star`は本命星3、つまり**三碧木星**を返しました。同じ応答に`physicalStar: 8`もあります。これは木星の黄経にもとづく別の流儀の値で、画面の既定は立春基準の`honmeiStar`だと注記されています。

`get_kanshi`は、年柱**戊辰**、月柱**癸亥**、日柱**甲申**を返しました。日柱から出す空亡は**午・未**です。干支併臨の候補年は、年柱が1988・2048・2108年、月柱が2043・2103年、日柱が2004・2064年でした。仕組みは[干支併臨の数字](/blog/numbers-in-kanshi-heirin)で解説しています。

本命星は九星気学、干支と空亡は四柱推命や算命学の側の概念です。**同じ生年月日から出しますが、別の体系**です。一方が他方を裏付けるわけではありません。違いは[気学以外の体系](/blog/other-systems-beyond-kigaku)にまとめました。

どちらのツールも、年は立春、月は節入りの瞬間で切り替えます。節気時刻は太陽黄経の計算値で、公式暦と数分ずれることがあると応答に書かれています。ここまでは**暦の計算**です。吉凶は、その計算の上に乗せた解釈です。

## 2026年10月16日の8方位

`judge_directions`の既定（天中殺は`strict`）では、この日は`blockedByTenchusatsu: true`でした。2026年は[丙午](/blog/what-is-hinoeuma)の年で、この例の空亡には午が入っています。

各方位の判定は次のとおりです（Sは三盤吉、Bは吉1盤、Xは五大凶殺・天中殺）。

| 方位 | 判定 | 年盤     | 月盤     | 日盤     |
| ---- | ---- | -------- | -------- | -------- |
| 北   | X    | 暗剣殺   | 五黄殺   | 本命殺   |
| 北東 | X    | 問題なし | 本命殺   | 吉       |
| 東   | X    | 本命的殺 | 問題なし | 五黄殺   |
| 南東 | X    | 吉       | 破       | 破       |
| 南   | X    | 五黄殺   | 暗剣殺   | 本命的殺 |
| 南西 | X    | 空亡     | 本命的殺 | 空亡     |
| 西   | X    | 本命殺   | 問題なし | 暗剣殺   |
| 北西 | B    | 問題なし | 吉       | 問題なし |

`tenchusatsuMode`を`weaken`にすると`blockedByTenchusatsu`は`false`になりました。それでも北西のB以外はXのままです。方位の凶殺は天中殺の設定とは別に効いていることが分かります。

当サイトは方位を**真北**基準で測ります。また、**暗剣殺と五黄殺は本命星に関係なく、誰にとっても凶**として扱います。北と南に年盤・月盤でこの二つが出ているのはそのためです。詳しくは[五黄殺と暗剣殺](/blog/five-yellow-and-anken-satsu)をどうぞ。

## 半年先まで探しても「使える日」は0日

`find_auspicious_days`で2026年10月16日から180日（181日分）を走査しました。結果は、8方位すべてで三盤吉の日が0日、使える日も0日でした。`weaken`でも0日です。

応答には、今の年盤が`2027-02-03`まで有効で、その後の年盤で各方位がどうなるかも付いています。たとえば北西は次の年盤でも吉、東・南東・西は問題なし、南は暗剣殺でした。年盤が1年を塞ぐ仕組みは[年盤が1年を塞ぐ](/blog/year-board-blocks-a-whole-year)で説明しています。

0日という結果は「この人は動けない」という意味ではありません。**この設定でこの期間に、三盤そろって条件を満たす日が無かった**という意味です。転勤など不可抗力の移動なら`involuntaryMove`で扱いが変わります。[天中殺に引越すとき](/blog/moving-during-tenchusatsu)も参考にしてください。

## 1日の中の刻

`judge_time_slots`は名古屋の真太陽時で1日を12の刻に分けます。この日の子の刻は前日22時37分に始まりました。

- 卯の刻（4時37分〜6時37分）と辰の刻（6時37分〜8時37分）は「動いてよい」。刻の星が四緑木星・三碧木星で、本命の木と比和でした
- 午の刻（10時37分〜12時37分）と未の刻（12時37分〜14時37分）は「天中殺」
- それ以外の刻は、見た範囲では「ふつう」

応答には`directionJudgment: not_provided_by_time_table`とあります。**刻の表は方位の判定をしません**。「どの方位へ」は`judge_directions`、「何時に」は刻の表と、役割が分かれています。時間の考え方は[時間が吉とされた理由](/blog/why-time-was-thought-lucky)にあります。

## 名古屋と愛知県の地域情報

`search_municipality`で「名古屋」を引くと、名古屋市中区（コード23106、家賃の目安は1㎡あたり月3,167円）などが返りました。家賃は総務省「統計でみる市区町村のすがた」（e-Stat）を加工した2023年の値です。

`area_directions`で中区から見ると、北西の最寄りは清須市（8km）、あま市（9km）でした。北西には36の市区町村があります。この例でこの日Bだったのは北西だけなので、候補地を考えるならこの一覧が入口になります。

`prefecture_summary`の愛知県では、県の面積重心から見た方位で、北西に38、南西に12、西に9の市区町村が並びました。北・北東・東は空でした。空の方位は集計が届いていないだけのこともあり、街が無いという意味ではないと応答に書かれています。県単位は目安で、個別の判断は出発地の市区町村から行います。

## 各ツールで分かることと限界

- 暦の値（干支、節気、本命星）は計算です。ただし数分の誤差と、流派ごとの切り替えの違いがあります
- 方位と吉日の判定は、当サイトの設定（真北、天中殺モード）を前提にした解釈です。設定を変えれば結果も変わります
- 刻は時間だけを見ます。方位は見ません
- 地域情報は方位と距離、家賃の目安です。住みやすさは判定しません

統計で吉凶を証明できるかは[方位の統計的根拠](/blog/is-there-statistical-evidence-for-houi)で扱いました。判定ツールでは決められないことは[このツールで決められること・決められないこと](/blog/what-this-tool-can-and-cannot-decide)にまとめています。

## ChatGPTやClaudeから使う

このMCPは公開されていて、MCPに対応したChatGPTやClaudeなどのAIアシスタントから呼べます。接続先に`https://cloud-palette.com/api/mcp`を登録すれば、自分の生年月日と出発地で同じ手順を試せます。
