## 同じ日干が巡っても、同じ失敗が起きるとは限らない

**日干が10日で一巡することは計算できますが、失敗も10日ごとに増えるという主張は、その計算だけでは確かめられません**。[参考動画](https://youtu.be/DotHaDwToyE)では、10日・10か月・10年に一度という周期や、陰陽・五行による失敗の傾向を説明しています。これは**動画内の見解**です。日々の失敗件数を集計し、周期の有無を検定した資料は提示されていません。

本記事では、失敗しやすい人物を分類するのではなく、「繰り返している」と感じたことをどう記録するかを扱います。転職などの経験数をどう数えるかは[命式で転職回数は決まるのか](/blog/career-changes-and-destiny-chart)と分け、ここでは同じ作業での失敗の頻度に絞ります。

## 日干の10日周期と、干支全体の60日周期

十干は甲・乙・丙・丁・戊・己・庚・辛・壬・癸の順に進み、10回で戻ります。十二支も同時に一つずつ進むため、天干だけが戻っても地支は元に戻りません。[国立天文台の六十干支一覧](https://eco.mtk.nao.ac.jp/koyomi/faq/60kansi.html)と既存の暦計算で、この違いを確かめられます。

Cloud Paletteの計算では、2000年1月7日の正午の日干支は甲子です。10日後の1月17日は甲戌、20日後の1月27日は甲申となります。どちらも甲に戻りますが、子には戻っていません。干支全体が甲子へ戻るのは60日後です。「同じ日干」と「同じ日干支」は条件が違います。

また、10か月を300日、10年を3,650日と一律に置き換えることもできません。Cloud Paletteで使う月の区切りは節入りであり、月ごとの長さは固定ではありません。年には閏年もあります。日・月・年を同じ10という数字で語るときほど、何が一つ進んだのかを明示する必要があります。

## 数字の評価

(a)は暦の計算で確かめられる事実、(b)は統計等で確認できる事実、(c)は動画の解釈・経験則で根拠未提示のものです。同じ数字の中にも、計算できる部分と検証されていない意味づけがあります。

| 動画に出る数字                               | 分類と計算・確認方法                                         | 確からしさ                                                         |
| -------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------ |
| 10日に1回、10日後に次のスタート              | 日干の一巡は(a)。失敗や成長の周期としての説明は(c)           | 日干の添字に10を足し、10で割った余りは同じ。失敗率の周期は未確認   |
| 10か月に1回、10年に1回                       | 干の進行を数える部分は(a)。本人のバイオリズムとする部分は(c) | 同じ干が戻ることと同じ干支が戻ることは異なる。出来事の再現率は不明 |
| あと3日ほどでこう思うという例                | (c) 心境を予測する説明                                       | 起点と予測の成否を定めた記録がなく、精度は出せない                 |
| 陽と陰で失敗の時点が異なるという2分類        | (c) 開始後と開始前という動画の解釈                           | 2群の観測人数や失敗件数が示されていない                            |
| 五行の5、自分に嘘をつけない「1番」などの順位 | 5は分類の個数。人物傾向や順位づけは(c)                       | 比較尺度・調査対象がなく、順位は実証されていない                   |
| AとBの選択、1度試すという助言                | (c) 行動を説明する例                                         | 2択は説明上の設定。一度の結果では効果の頻度を評価できない          |
| 1日考える、翌朝に考えるという提案            | (c) 判断を待つ時間の例                                       | 一日待つことによる失敗率の変化は測定されていない                   |

この動画から(b)に置ける確認済みの失敗率は得られません。以下の率は、記録の読み方を示すためにこの記事が作った架空の計算例です。動画の実績や、五行別の統計ではありません。

## 失敗件数には、試みた回数を添える

ある10日間に送信した書類が20件あり、そのうち入力ミスを含む書類が2件だったとします。次の10日間は50件中3件でした。ミスを含む書類は2件から3件へ増えていますが、割合は2÷20＝10%から3÷50＝6%へ下がっています。

この例で「失敗が増えた」は件数については正しく、「失敗率が増えた」は正しくありません。さらに、後半の書類が簡単だったかもしれず、この数字だけで本人の能力が改善したとも決まりません。日付だけでなく、作業の種類と機会数が必要です。

| 記録欄         | 数える際の約束                                    |
| -------------- | ------------------------------------------------- |
| 作業の機会数   | 提出した書類を1件とし、作業しなかった日を区別する |
| 失敗の定義     | 入力ミスが一つでもある書類を1件とする             |
| 重複の扱い     | 同じ書類に複数のミスがあっても、この集計では1件   |
| 発見日と作業日 | 後日見つけたミスを、見つけた日の作業へ混ぜない    |
| 条件の違い     | 作業量、難しさ、確認手順の変更を併記する          |

動画で語られる「機会を逃す」「情報に流される」といった失敗像は、そのままではこの表の件数にできません。何をすれば成功だったのか、いつまでに何をしなかったら失敗なのかを先に決める必要があります。結果を見てから意味を広げると、どの出来事も周期に合わせられてしまいます。

## 周期を調べるなら、合わない日も残す

10日周期を確かめたい場合は、起点の日と観測期間を結果を見る前に決めます。途中で都合のよい起点へ動かしたり、失敗のあった日だけを拾ったりすると、公平な比較になりません。同じ日干でも何も起きなかった日、別の日干で失敗した日を同じ規則で記録します。

休日や繁忙日など、作業の機会が偏る事情も残してください。短い期間に似た並びが見つかっても、それだけで以後の失敗日を予測できるとは限りません。確認手順を増やした後に率が変わったなら、干支と同時に、実際に変えた手順も検討の対象になります。

四柱推命と九星気学は別体系です。Cloud Paletteは真北で方位を判定し、暗剣殺・五黄殺は誰にとっても凶として扱います。作業の調子や10日の周期によって方位の凶を解除しません。暦の周期と出来事の解釈の違いは、[干支併臨の数字の評価](/blog/numbers-in-kanshi-heirin)にも通じます。
