## 先に結論

- 「風水」という言葉は、**墓の位置を論じた本**に出てくるのが早い例とされます。晋の郭璞（276〜324）に仮託された『葬書』で、郭璞自身の著作かどうかは古くから疑われています
- 風水の道具である羅盤には、**針が3本**あります。「北」が1つに決まらないことを、道具の側が最初から抱えていました
- ただし3本の間隔は**固定の7.5度**です。実際の地磁気の偏角は場所ごとに違い、国内だけで実測**4.07度**の幅があります
- このサイトは**判定を真北だけで行います**。磁北は「方位磁針で測るとずれる」という注意としてしか使いません
- 方位磁針の数字をそのまま真方位として読むと、東京では方位角の**17.6% が別の八方位に落ちます**。札幌なら22.1%、那覇なら13.0%です

この記事は風水の入門ではありません。**言葉と道具がどこから来たのかを押さえたうえで、このサイトが「北」をどう決めたかを書く**ためのものです。八宅と九星気学の答えがどう割れるかは [風水（八宅）と九星気学は何が違うのか](/blog/feng-shui-and-kigaku-side-by-side) に分けてあります。

## 「風水」という言葉は、墓の本から来ている

いま「風水」と呼ばれているものは、最初から住まいの話だったわけではありません。

「風水」の語の早い用例として挙げられるのは『葬書』（『葬経』とも）です。[Wikipedia の「風水」](https://ja.wikipedia.org/wiki/%E9%A2%A8%E6%B0%B4)は、この語が晋の**郭璞に仮託された**『葬書』にあるとしています。仮託とは、本人の著作として伝えられているが実際は別人の手によるという意味です。[中文版の「葬書」](https://zh.wikipedia.org/zh-hant/%E8%91%AC%E6%9B%B8)も、後世の偽託を疑う見方を併記しています。

つまり**書名も著者も、確定した話ではありません**。ただ、語が現れる文脈は一貫しています。**墓をどこに置くか**という話です。

生きている人の家の話に重心が移るのは、そのあとです。日本の家相も、このサイトが扱う引越しの方位も、もとは葬地の選定から出た語彙を使っていることになります。

## 巒頭と理気 — 地形を読む派と、時間を読む派

風水は大きく2つに分けて説明されます。

| 呼び方       | 何を読むか                               | 道具     |
| ------------ | ---------------------------------------- | -------- |
| 巒頭（形勢） | 山と水の形。土地そのものの姿             | 目で見る |
| 理気         | 方位と暦。時間とともに変わるとされる条件 | 羅盤     |

唐代に楊筠松が形勢の側を確立したとされ、宋代以降に理気的な解釈が深まったと説明されます。**このサイトが並べている八宅は理気の側**です。生年から本命卦を出し、8つの方位に吉凶の札を割り当てます。九星気学も理気の側にあたります。

言い換えると、**このサイトは風水の半分しか触っていません**。土地の形を読む巒頭の側は扱っていません。[土地の選び方](/blog/how-to-choose-land)で地形に触れているのは、方位判断としてではなく、災害リスクや接道の話としてです。

## 羅盤には針が3本ある

理気の側で使う羅盤には、**「北」が3つ刻まれています**。

| 環   | 名   | 位置              |
| ---- | ---- | ----------------- |
| 地盤 | 正針 | 基準              |
| 天盤 | 縫針 | 正針から7.5度     |
| 人盤 | 中針 | 正針から逆に7.5度 |

[風水羅盤の解説](https://ja.wikipedia.org/wiki/%E9%A2%A8%E6%B0%B4%E7%BE%85%E7%9B%A4)によれば、3本の針は7.5度ずつずれた3通りの基準として使い分けられます。7.5度という数字は、24山（1山15度）の半分です。ずれの由来については、北極星の極距離など天文上の理由で説明されることが多く、**説は分かれます**。

ここで取りたいのは由来の当否ではありません。**道具が「北は1つではない」という前提を持っていた**という点です。磁針の指す北と、星や日影で決めた北は違う。羅盤はその差を環として抱え込んでいました。

ただし、抱え込み方は**固定値**です。7.5度は場所によって変わりません。実際の地磁気の偏角は場所ごとに違い、年ごとにも動きます。固定の環で吸収できるものではありません。

## 磁針が南を指しきらないことは、11世紀に書かれていた

ずれ自体は、ずいぶん早く記録されています。

北宋の沈括『夢溪筆談』（1086〜1093年ごろの成立とされる）は、磁針について「**常微偏東、不全南也**」と書いています。常にわずかに東に偏り、真南を指しきらない、という意味です。[中文版の「夢溪筆談」](https://zh.wikipedia.org/zh-tw/%E6%A2%A6%E6%BA%AA%E7%AD%86%E8%AB%87)はこれを磁偏角の最も早い記載とし、西欧の記録より400年ほど早いとしています。

**気付かれていなかったわけではありません**。偏角がどれだけかを場所ごとに測れるようになったのが、ずっとあとだったということです。

なお、当時の中国での偏角は東寄りでした。現在の日本では西寄りで、数字は下の表のとおりです。**偏角は土地と時代で変わります**。11世紀の記述をそのまま現在の数字として使うことはできません。

## 日本には「家相」として入り、「風水」の名は1994年から広まった

日本側の来歴は、九星気学と途中まで重なります。都城の造営や陰陽道として入ったあと、**江戸後期に家相として流行しました**。そこから大正の気学までの流れは [九星気学と方位はどこから来たのか](/blog/where-kigaku-and-houi-came-from) に書いてあります。

ここで押さえておきたいのは、**日本語の「風水」という語は新しい**ということです。[Wikipedia の「日本風水」](https://ja.wikipedia.org/wiki/%E6%97%A5%E6%9C%AC%E9%A2%A8%E6%B0%B4)は、この語が長く知られておらず、1994年の荒俣宏『風水先生』の刊行を機に大きなブームとなって広く知られるようになった、としています。

つまり日本語で「風水」と言うとき、

- **言葉**が一般に通じるようになってから、まだ30年ほど
- **中身**（理気の計算）は、千年以上の積み重ね
- **家相**という日本側の枠組みは、江戸後期から

この3つが別々の時計で動いています。流派によって答えが違う理由のひとつがここにあります。詳しくは [流派はいくつあるのか](/blog/how-many-schools-are-there) に書きました。

## このサイトは判定を真北で固定した

以上が背景です。ここから先は、このサイトの実装の話になります。

**吉凶の判定は、常に真北を基準に行います**。磁北は表示にしか使いません。理由は2つあります。

1. **記事と道具が恒久的に食い違うから**。[九星気学の方位と吉凶](/houi)は全国向けの静的なページです。読む人の場所が決まらないので、偏角を持てません。判定を磁北にすると、記事の方位と道具の方位が永久に噛み合わなくなります
2. **偏角は動くから**。真北は動きません。判定の基準が毎年ずれると、同じ引越しの評価が年をまたぐだけで変わります

そのうえで、偏角は**出発地ごとに**地磁気モデル（WMM）から引いています。**取得できないときは0**、つまり補正しません。

以前は東京の−8.2度で全国を埋めていました。**沖縄や北海道の利用者に、東京の偏角を当てていたことになります**。下の表を見れば、それが何度の誤りだったか分かります。

## 偏角を実測すると、国内で4.07度ちがう

このサイトが使っているのと同じモデルで、8都市を引きました（2026-09-12 時点）。

| 都市   | 偏角    | 方位磁針の読みをそのまま使うと別の八方位になる割合 |
| ------ | ------- | -------------------------------------------------- |
| 札幌   | −9.94度 | 22.1%                                              |
| 仙台   | −8.55度 | 19.0%                                              |
| 名古屋 | −8.16度 | 18.1%                                              |
| 大阪   | −8.16度 | 18.1%                                              |
| 広島   | −8.24度 | 18.3%                                              |
| 福岡   | −8.03度 | 17.8%                                              |
| 東京   | −7.94度 | 17.6%                                              |
| 那覇   | −5.86度 | 13.0%                                              |

負の値は**西に偏っている**ことを意味します。方位磁針の北は、真北より西を指します。

**最大差は4.07度**（札幌と那覇）。羅盤の環が持っている7.5度という固定値では、この差を吸収できません。一律の補正を当てると、必ずどこかの土地で外します。

## 境目は8本ある。だから「偏角 ÷ 45」が答えになる

上の表の右の列は、次のように出しています。

八方位に落とす境目は**8本**あります。このサイトが使う伝統区分では、北・東・南・西が30度、四隅が60度です。

```
北  345〜15     北東 15〜75
東   75〜105    南東 105〜165
南  165〜195    南西 195〜255
西  255〜285    北西 285〜345
```

偏角ぶん全体を回すと、8本の境目がそれぞれその角度だけ動きます。動いた帯に入る方位角が、隣の方位へ移ります。だから移る割合は

    8本 × 偏角 ÷ 360度 = 偏角 ÷ 45度

になります。東京の7.94度なら17.6%、札幌の9.94度なら22.1%です。

**この割合は区分の切り方によりません**。45度等分（北を337.5〜22.5度とする流儀）で同じ計算をしても、実測は同じ17.6%でした。帯の幅は違っても**境目の本数が同じ**だからです。

物件検索や市区町村の比較で「真北と磁北で方位が分かれる」印が付くのは、この帯に入った地点です。東京から探すなら、方位角が一様に散っていれば6件に1件ほどに付きます。実際の件数は物件の散らばり方で変わります。

## 混ぜずに、並べる

風水と九星気学は別の体系です。このサイトは判定に九星気学を使い、八宅は [風水（八宅）で見る8方位](/houi/fengshui) として別に引ける形にしています。物件検索では評価に入れるかどうかを選べますが、**既定は「入れない」です**。

このやり方を選んだ理由は、2つの体系が**同じ方位で違う答えを出す**ことがあるからです。八宅の吉方位は生涯変わらず4つに固定され、九星気学は年ごとに動きます。実際に割れる例は [風水（八宅）と九星気学は何が違うのか](/blog/feng-shui-and-kigaku-side-by-side) に、エンジンの実際の値で並べてあります。

道具の使い方は [使い方の案内](/guide)にまとめました。

## 注記

歴史の記述は一般に参照される説に沿っています。**年代・著者・由来は出典によって食い違います**。特に『葬書』の成立と著者、羅盤の3針の由来は、確定した話として扱えません。

偏角の数値は世界地磁気モデル（WMM）による計算値で、2026-09-12 時点のものです。**偏角は年々変化します**。現地での実測値とも差が出ます。

風水・家相・九星気学は伝統的な占術上の考え方であり、効果が科学的に確認されたものではありません。Cloud Palette は計算条件を整理する道具で、将来の出来事を保証するものではありません。方位の判定とは別に、家賃、災害リスク、契約条件、通勤時間、医療・教育環境、家族の合意を必ず確認してください。
