## 肩書が変わったあと、誰が決めるのか

**事業承継で確認したいのは、相性の良さだけでなく、どの判断を誰に渡したかです**。[参考動画](https://youtu.be/xL9-LesFcIc)では、五行の関係や陰陽の組み合わせから、会社の渡し方、前任者の言葉遣い、後継者との距離について説明しています。これは**動画内の見解**です。組み合わせ別の承継成功率を調べた統計としては扱いません。

動画には、立場が変わったことを踏まえて話すという論点があります。本記事ではそこを出発点に、後継者を生まれの分類で選ぶのではなく、業務上の決定権をどう記録するかを考えます。株式や契約の移転手続きとは別に、日常の仕事で「任せた」の意味が一致しているかを確認するための整理です。

## 関係の分類から成功率は求められない

動画は相生・相剋・同じ五行の関係を分け、受け渡す向きも重視します。ただし、図を指す「こちら」「逆」の対象を字幕だけでは追えない箇所があります。図の指示先を補って、五行別の後継者ランキングを作ることはできません。

また、「同等の能力なら」という条件で候補を比較する説明がありますが、実務で何を同等とするかは別の問いです。顧客対応の経験、商品に関する知識、判断の記録など、確認する対象を決めないまま、相性で差をつけても能力比較にはなりません。分類と実際の仕事の違いは[五行で語られる仕事の役割](/blog/five-elements-and-work-roles)でも扱っています。

## 数字の評価

(a)は暦の計算で確かめられる事実、(b)は統計等で確認できる事実、(c)は動画の解釈・経験則で根拠未提示のものです。分類の個数や仮定の人数は数えられても、結果の確率を表すわけではありません。

| 動画に出る数字                          | 分類と確認方法                            | 確からしさ                                                           |
| --------------------------------------- | ----------------------------------------- | -------------------------------------------------------------------- |
| 3つの関係、五行の5分類                  | 関係や属性の数え分け。承継への効き方は(c) | 分類数から承継成功率は計算できない                                   |
| 2人の関係、一方と他方                   | (c)で想定する当事者の数                   | 従業員や取引先を含めた関係者全体が2人という意味ではない              |
| 候補が3人、同等の能力                   | (c)の仮定例                               | 実在の候補者3人を追跡した比較ではなく、能力の測り方も未提示          |
| 逆向きの承継が潰れるという箇所の数値    | (c) 自動字幕では割合を確定できない        | 分母・件数・期間もない。推測で百分率に直さず、失敗率として採用しない |
| 1番よく伝わる、1個の注意、1回立場を確認 | (c)の強調・説明順                         | 比較実験の順位や、1回で十分という実証ではない                        |
| 陽から陰、陰から陽という2方向           | (c)として提示される受け渡しの向き         | 方向を区別することと、どちらが成功するかの検証は別                   |

本動画には(a)として検算する具体的な日付や、(b)として確認できる成功率はありません。割合を検証するには、同じ基準で数えた承継件数と失敗件数、観察期間、失敗の定義が必要です。相談に来た事例だけを数える場合も、それが承継全体を代表するかは別途確認が必要になります。

## 「任せた」を業務ごとに書き直す

次は記事独自の架空例です。ある部署の引き継ぎ対象を、顧客への回答、作業手順の変更、納期の変更、担当者の配置の4項目に分けます。前任者が「全部任せた」と考えていても、後任者は「納期だけは毎回承認が必要」と理解しているかもしれません。

| 確認欄           | 記録する内容の例                     |
| ---------------- | ------------------------------------ |
| 決める対象       | 顧客に伝える納期の変更               |
| 決定する人       | 引き継ぎ後の担当者                   |
| 相談が必要な条件 | 他部署の予定にも影響がある場合       |
| 前任者の関わり方 | 求められたときに過去の経緯を説明する |
| 見直す時点       | 最初の案件が終わったあと             |

これは一律の権限設計の推奨ではなく、認識を照合する書式です。実際に誰が決められるかは、その組織で定められた権限や取り決めを確認します。前任者の経験を聞くことと、前任者が最終判断を引き取ることは同じではありません。

仮に4項目中3項目で決定者が合意できたなら、項目数としては3÷4＝75%です。しかし「承継が75%成功した」とは言えません。残る1項目が全体に影響する可能性があり、各項目の重みもそろっていないからです。何件埋まったかと、業務が回るかを別に記録します。

## 前任者の助言と差し戻しを区別する

引き継いだあとに前任者が意見を出すときは、参考情報なのか、変更を求めているのかを明らかにします。後任者が助言だと思って進め、前任者が指示のつもりだった場合、問題は相性の判断だけでは解けません。どの発言がどの扱いだったか、具体的な案件に戻って確認できます。

振り返りには「相手が頑固だった」ではなく、「納期について誰の了承が必要か一致していなかった」と書きます。決定者が決まっていても、必要な情報が渡っていなければ判断は止まります。過去の経緯、進行中の約束、未解決の問い合わせも、権限と一緒に照合する対象です。

相手への伝え方そのものは[五行の相性と会話を分ける記事](/blog/compatibility-and-communication)を参照できます。本記事の焦点は、承継を境に判断する人が変わったかどうかです。話が通じたという感想だけで、引き継ぎが終わったとは判定しません。

四柱推命と九星気学は別体系です。Cloud Paletteは真北で方位を判定し、暗剣殺・五黄殺は誰にとっても凶として扱います。承継の相性や話し合いの進み具合は、移動の凶方位を解除する条件にはなりません。
