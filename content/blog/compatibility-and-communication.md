## 相性表を、相手への言い方の命令にしない

**五行の関係を知っても、相手に強く言うべきか、従うべきかまでは決まりません**。[参考動画](https://youtu.be/Boa-JfnGudg)では、近しい人と分かり合えないという悩みに対し、相生・相剋・同じ属性という分類から伝え方を考える説明が出てきます。分類によって言い方を変える提案は**動画内の見解**であり、親子や夫婦を比較して効果を測定した結果ではありません。

この記事では「誰と相性がよいか」という人物の選別ではなく、同じお願いでも相手への伝わり方をどう確認するかを扱います。仕事上の役割を五行で語る話は[五行で語られる仕事の役割](/blog/five-elements-and-work-roles)に分けています。

## 相生・相剋の矢印と、家庭の役割は別

動画は五行同士の関係を、相生、相剋、同じ属性に分け、関係の向きによって伝える側と受け取る側を説明しています。相生と相剋は単純な「仲良し」「仲が悪い」という日常語とは異なり、動画でも相剋を抑制してバランスを取る関係として扱っています。

ただし、矢印の向きが読めたことと、家族の責任が逆になることは別です。動画には、子が親に与える側になるという解釈もあります。これは動画内の見解であり、子どもが親を支える義務や、相手の要求を受け入れる根拠を示すものではありません。生活で誰が何を引き受けるかは、実際の年齢、能力、時間、合意を確かめる必要があります。

自動字幕では図を指す「ここ」「こちら」が多く、指している五行を文字だけで特定できない箇所があります。そのため本記事では、特定の親子の五行の組から発言例を機械的に選ぶ対応表は作りません。判別できない矢印を補って、特定の相手には上から話してよいと結論づけることも避けます。

## 数字の評価

(a)は暦の計算で確かめられる事実、(b)は統計等で確認できる事実、(c)は動画の解釈・経験則で根拠未提示のものです。分類の個数を数える作業と、会話の効果を測る作業は分けます。

| 動画に出る数字                                 | 分類と計算・確認方法                                  | 確からしさ                                                         |
| ---------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------------ |
| 五行の5、十干の10種類                          | (a) 暦で使う十干の分類は5×2＝10。十干一覧と照合できる | 人間が10種類に分類し尽くせるという部分は(c)で未検証                |
| 相生・相剋という2関係と、同じ属性を加えた3分類 | (c) 動画の説明上のまとめ方。2＋1＝3                   | 数え方は追えるが、会話の成否が3群だけで説明できるとは確認できない  |
| 隣と1個飛ばしという図の説明                    | (c) 図上の配置の読み方                                | 距離や飛ばす数は図の並べ方に依存。実際の心理的距離の測定値ではない |
| 相手を100%分かることはできないという表現       | (c) 完全な理解を求めないという助言                    | 理解度の分母・評価基準がなく、割合として測定した結果ではない       |
| 共通の目的を1つ作るという提案                  | (c) 伝え方の例                                        | 目的が一つなら必ず伝わるという成功率は未提示                       |
| 同じ属性の喧嘩も関わり方の1つという説明        | (c) 関係性に対する解釈                                | 喧嘩の回数・深刻さを測っておらず、どの対立にも当てはめられない     |
| 問い合わせる相手が10人ほどという会話           | (c) 動画末尾の受付負担に関する例                      | 調査対象人数でも相性を確かめる標本数でもない                       |
| 「1番伝えたい」という順序                      | (c) 話の重点を示す表現                                | 方法の有効性が1位だったという比較ではない                          |

十干の数と対応は[国立天文台の解説](https://eco.mtk.nao.ac.jp/koyomi/faq/60kansi.html)で確認できます。一方、この動画から(b)に分類できる会話の改善率や夫婦の一致率は確認していません。「100%ではない」からといって、残りのどこまで分かるのかを数値にすることもできません。

## 伝え方を変えるなら、お願いの中身をそろえる

動画には、宿題をしてほしいという場面で、理由や期限を伝える例、共通の目的を作る例があります。これらを自分の会話に使うときは、相性に基づく効果を確定するのではなく、相手がどこで困っていたかを聞く材料にできます。以下はこの記事独自の確認表です。

| 確認するもの   | 会話で確かめる例                                   |
| -------------- | -------------------------------------------------- |
| 依頼の内容     | 何を、どこまで終わらせてほしいのか                 |
| 期限の理解     | 今日中なのか、明日の何時までなのか                 |
| 手順の理解     | やり方が分からないのか、別の手順を考えているのか   |
| 実行できる条件 | 時間、道具、手助けが足りているか                   |
| 本人の返答     | 依頼をどう受け取ったか、何ならできると言っているか |

たとえば「何度言っても伝わらない」と感じた場面でも、期限を伝えていなかったなら、相性以前に依頼が共有されていなかった可能性があります。「明日の朝まで」と言い直した後でできたとしても、五行の分類が当たった証明にはなりません。期限を明確にしたことや、別の用事が終わったことなども候補になります。

振り返るときは、言い方を変えた点と相手の返答を残します。うまくいった会話だけでなく、同じ言い方でうまくいかなかった場面も残すと、「この属性には必ずこの言い方」という断定を避けられます。相手が断った場合も、伝わらなかったのか、理解したうえで同意しなかったのかを区別できます。

## 相性のよさを、同居や移動の判定へ持ち込まない

同じ属性なら喧嘩しても問題ない、違う属性だから分かり合えない、と本人の負担を分類だけで評価しないでください。どんな言葉や行動が困るのか、やめてほしいことが伝わっているかという実際のやり取りを確認する必要があります。

四柱推命と九星気学は別体系です。Cloud Paletteは真北で方位を判定し、暗剣殺・五黄殺は誰にとっても凶として扱います。家族同士の相性がよいという解釈で、移動先の凶を打ち消す判定は行いません。人間関係と道具の判定を分ける範囲は、[この道具で決められること・決められないこと](/blog/what-this-tool-can-and-cannot-decide)にもまとめています。
