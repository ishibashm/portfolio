## 先に結論

計算の上では、吉2盤・吉1盤・平の日も三盤吉の日と同じく年盤・月盤・日盤のどれにも凶が入っていない日で、それを引越しに使うかどうかは「凶を避けること」と「吉を取ること」のどちらを目的に置くかで考え方が分かれます。

- Cloud Palette の段階は、3 枚の盤のうち**凶が何枚か、吉が何枚か**で決まります。S（三盤吉）は 3 枚とも吉、A は 2 枚、B は 1 枚が吉で、C は 3 枚とも平です。どれも凶は 0 枚です
- 七赤金星の人（東経 135.7 度、2026 年 10 月から 1 年）で数えると、**三盤吉が 0 日なのに凶の無い日がある方位が 3 つ**ありました（東 30 日・西 34 日・南西 35 日）
- [引越しの日取りを選ぶ](/calendar)の表は、これまで三盤吉の日しか出していなかったため、この 3 方位は**表から丸ごと消えていました**。いまは S〜C の日を段階の札つきで出し、「三盤吉（S）だけ」の絞り込みで元の見え方にも戻せます
- 平の日に動いてよいかは、計算では決まりません。凶が無ければ差し支えないとする考え方もあれば、吉の盤が無ければ動く意味が薄いとする考え方もあります

## 三盤吉・吉2盤・吉1盤・平は、どう決まるのか

段階は、その日その方位について年盤・月盤・日盤の 3 枚が出す札（吉・平・凶）を数えて決まります。点数の足し引きではなく、上の段から順に当てはめる規則です。

| 段階 | 呼び名        | 条件                                                 |
| ---- | ------------- | ---------------------------------------------------- |
| X    | 五大凶殺あり  | 五黄殺・暗剣殺・破・本命殺・本命的殺のどれかが当たる |
| D    | 軽い凶のみ    | 五大凶殺ではない凶（天中殺方位・月命殺など）が当たる |
| S    | 三盤吉        | 凶が 0 枚で、3 枚とも吉                              |
| A    | 吉2盤・凶なし | 凶が 0 枚で、吉が 2 枚                               |
| B    | 吉1盤・凶なし | 凶が 0 枚で、吉が 1 枚                               |
| C    | 凶なし（平）  | 凶が 0 枚で、3 枚とも平                              |

X と D を先に見るので、**凶が 1 枚でも入れば、残りの 2 枚が吉でも A・B・C にはなりません**。凶を吉で埋め合わせない作りは[凶方位への移動を、吉が上回ることはできるのか](/blog/can-good-outweigh-a-bad-move)に書いたとおりです。土用殺の当たる方位も、最終判定では五黄殺と同じ扱いになり X に入ります。

札の意味は次のとおりです。吉は本命星と相性の良い星が回っていて凶にも当たっていない方位、平は凶ではないが吉でもない方位、凶は凶殺が当たっている方位です。このサイトは平を「凶方位ではありませんが、積極的に選ぶ理由もない方位」と説明しています。

## 1 年を数えると、段階ごとに何日あるのか

同じ人・同じ出発地で 1 年ぶんを 1 日ずつ判定し、方位ごとに段階の日数を数えました。前提は[引越しの方位はどの日で決まるのか](/blog/which-day-counts-as-moving-day)と揃えてあります。

|              |                                                  |
| ------------ | ------------------------------------------------ |
| 移動する人   | 本命星が七赤金星                                 |
| 出発地の経度 | 東経 135.7 度あたり                              |
| 期間         | 2026 年 10 月 1 日〜2027 年 9 月 30 日（365 日） |
| 天中殺       | 含めない（生年月日が要るため）                   |

結果はこうです。並びは日取りの表と同じ（三盤吉の多い順、同じなら凶の無い日の多い順）にしました。

| 方位 | S 三盤吉 | A 吉2盤 | B 吉1盤 | C 平 | 凶の無い日 |
| ---- | -------- | ------- | ------- | ---- | ---------- |
| 北西 | 38       | 48      | 6       | 0    | 92         |
| 南東 | 22       | 48      | 32      | 10   | 112        |
| 南西 | 0        | 0       | 7       | 28   | 35         |
| 西   | 0        | 11      | 20      | 3    | 34         |
| 東   | 0        | 12      | 18      | 0    | 30         |
| 北   | 0        | 0       | 0       | 0    | 0          |
| 北東 | 0        | 0       | 0       | 0    | 0          |
| 南   | 0        | 0       | 0       | 0    | 0          |

表に無い日は、すべて X でした。この前提では D の日は 1 日もありません。

**三盤吉で並べるか、凶の無い日で並べるかで、いちばん多い方位が変わります**。三盤吉なら北西（38 日）、凶の無い日なら南東（112 日）です。北・北東・南は、年盤がこの 1 年ずっと五大凶殺に当たっていて、365 日すべてが X でした。

## 三盤吉が 0 日なのに、凶の無い日がある方位はどこか

東・西・南西の 3 つです。三盤吉だけを並べる表では、この 3 方位は 1 行も出ませんでした。

| 方位 | 凶の無い日が出る期間                  | その間の年盤 | 内訳                     |
| ---- | ------------------------------------- | ------------ | ------------------------ |
| 東   | 2026 年 11 月 8 日〜2027 年 2 月 2 日 | 吉           | A 12 日・B 18 日         |
| 西   | 2026 年 10 月 1 日〜2027 年 2 月 2 日 | 平           | A 11 日・B 20 日・C 3 日 |
| 南西 | 2027 年 4 月 7 日〜9 月 30 日         | 平           | B 7 日・C 28 日          |

読み取れることは 3 つです。

**1. 西と南西は、年盤が平なので三盤吉が出ません**。三盤吉は 3 枚とも吉であることなので、年盤が平の間は条件を満たせません。年盤が上限を決める話は[方位と日取りのどちらが重いのか](/blog/direction-or-timing-which-matters)で別の人の例を数えました。

**2. 東は年盤が吉なのに、三盤吉が 0 日です**。この期間、東の月盤は一度も吉になりませんでした。年盤と日盤がそろっても、3 枚目が平なら A 止まりです。

**3. 立春で、残る方位が入れ替わります**。2027 年 2 月 4 日の立春で年盤が替わると、東は本命殺、西は本命的殺に入り、2 月 2 日が最後の日になりました（2 月 3 日は X）。逆に南西は、立春までは年盤が本命殺で、凶の無い日は立春の後にしか出ません。同じ 1 年を見ていても、前半と後半で候補の方位が違います。

南西の 35 日のうち 28 日は C（3 枚とも平）です。**この方位を候補に入れるかどうかは、平の日をどう扱うかでほぼ決まります**。

## 同じ A なら、どの盤が吉でも同じなのか

このサイトの段階は吉の枚数だけを数え、どの盤が吉かは区別しません。東の A 12 日は年盤と日盤が吉、西の A 11 日は月盤と日盤が吉で、年盤の札は違いますが、どちらも同じ A です。

B も同じです。南東の B 32 日のうち、年盤だけが吉の日が 22 日、日盤だけが吉の日が 10 日でした。

盤は切り替わる速さが違います。年盤は立春ごとに、月盤は節入りごとに、日盤は毎日替わります。引越しのように長く住む移動では**年盤と月盤を重く見て**、日盤は旅行のような短い移動で重く見る、とする説明がよく見られます。その読み方を採るなら、東の A（年盤が吉）と西の A（年盤が平）は同じ重さとは言えません。3 枚を同じように数える考え方もあり、どちらが正しいかは計算では決まりません。

日取りの表は日付ごとに**年盤・月盤・日盤の札を列で並べて**いるので、どの盤が吉なのかはそこで確かめられます。

## 平の日に動くことは、流派ではどう考えられているのか

平の日の扱いは流派や指導する人によって分かれ、計算で決まることではありません。よく見かける考え方は大きく 2 つあります。

1 つは、**凶を避けることを第一にする考え方**です。引越しは仕事や学校や契約の都合で時期が決まることが多く、まず凶の方位と凶の日を外すことが大切で、平なら差し支えないとされます。この立場では、C の日も S の日と同じく「使える日」です。

もう 1 つは、**吉を取りに行くことを目的にする考え方**です。吉方位へ動くこと自体に意味を置く立場で、平の方位へ動いても得るものは少ないとされます。この立場では、C は「避けなくてよいが、選ぶ理由も無い日」になり、A・B についても吉が年盤や月盤にあるかを重く見ることがあります。

どちらの効果も確かめる方法はありません。このサイトは段階を並べるだけで、平の日に動くことの良し悪しは決めていません。

実際に日を選ぶときは、次の順が考えやすいと思います。

1. X と D の日を外す（ここは計算で決まります）
2. 自分が動ける時期に、その方位の凶の無い日が出るかを見る
3. 出るなら、自分が拠る考え方に合わせて S〜C のどこまでを使うか決める

2 の「動ける時期」が先に決まっていて、その時期に凶の無い日が 1 日も無い場合の考え方は[引き渡しは選べない。年盤が1年塞ぐとき](/blog/year-board-blocks-a-whole-year)に書きました。

## 日取りの表では、凶の無い日がどう出るのか

[引越しの日取りを選ぶ](/calendar)の表は、年盤・月盤・日盤のどれにも凶が入らない日（S・A・B・C）を方位ごとに並べます。三盤吉が 0 日でも、凶の無い日が 1 日でもある方位は出ます。

- 方位ごとの見出しに「三盤吉 N 日」と「凶なし（吉2盤・吉1盤・平を含む）M 日」を分けて出します
- 日付の下に段階の札（S 三盤吉・A 吉2盤・凶なし・B 吉1盤・凶なし・C 凶なし（平））が付きます
- 絞り込みの「三盤吉（S）だけ」を選ぶと、S 以外の日を隠して元の見え方に戻せます
- 年盤の期限（この例の 2027 年 2 月 3 日にあたるもの）も方位ごとに出ます

生年月日を入れると、天中殺に当たる日には印が付きます。この記事の表は天中殺を含めていないので、実際に動ける日はここから減ることがあります。見出しの「天中殺で不可」と「実質」は三盤吉のうちの数です。天中殺の日を一覧から外したいときは「天中殺の日を隠す」を選んでください。

月ごとの段階の見取り図や、2 年先までの一覧は[引越し時期を分析する](/relocation/timing)で見られます。
