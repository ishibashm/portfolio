## 先に結論

**土用は「いつ動くか」に関わる期間、土用殺は「その期間にどの方位が塞がるか」という方位の話**です。

名前が似ているため同じものとして語られがちですが、効き方が違います。土用は期間そのものへの注意で、方位を選び直しても期間は変わりません。土用殺は特定の1方位だけに掛かるので、方位を変えれば避けられます。

## 土用とは何か

土用は、暦の上で五行の「土」の気が強まるとされる期間です。立春・立夏・立秋・立冬のそれぞれ直前、およそ18日間ずつ、年に4回あります。合計するとおよそ72日、**1年の約2割が土用**です。

「土用の丑の日」で夏の土用だけが有名ですが、春・秋・冬にもあります。伝統的には、この期間に土を動かすこと（基礎工事、造園、井戸掘りなど）や、転居のような大きな移動を避けるとされてきました。

このサイトでは、土用の期間を節気の日付ではなく**太陽黄経**で求めています。春土用は太陽黄経27度から45度、夏は117度から135度、秋は207度から225度、冬は297度から315度です。市販の暦とは日付が1日前後することがあります。

太陽が黄経27度や117度に達するのは1日の途中の瞬間です。どの日からどの日までを土用とするかは、「節入りの日は新しい節に属する」という暦の原則に合わせ、**日本時間のその日の終わり（23時59分59秒）時点の太陽黄経**で判定しています。日中に黄経が区切りへ入った日はその当日から土用に入り、立春・立夏・立秋・立冬を迎えた当日はすでに次の季節に入るため、その前日が土用明けになります。

### 間日（まび）という例外

土用の中にも「この日は土の気が休む」とされる**間日**があります。日の十二支で決まり、季節ごとに異なります。

| 土用   | 間日となる日の十二支 |
| ------ | -------------------- |
| 春土用 | 巳・午・酉           |
| 夏土用 | 卯・辰・申           |
| 秋土用 | 未・酉・亥           |
| 冬土用 | 寅・卯・巳           |

Cloud Paletteの判定も間日は「土用の注意の対象外」として扱い、**間日には土用殺も掛けません**。日の十二支は12日周期で一巡するため、土用の約18日間のうち、間日は3〜6日（多くの年で4〜5日）あります。

## 土用殺とは何か

土用殺は、**それぞれの土用の期間中に塞がるとされる1つの方位**です。

| 土用               | 土用殺の方位 |
| ------------------ | ------------ |
| 春土用（立夏の前） | 南東         |
| 夏土用（立秋の前） | 南西         |
| 秋土用（立冬の前） | 北西         |
| 冬土用（立春の前） | 北東         |

土用そのものが「期間全体への薄い注意」だとすると、土用殺は「その期間、この方位だけは強く避けるとされる」という濃い注意です。四隅（南東・南西・北西・北東）が季節順に塞がっていく形になっています。後天定位盤では四隅に「土」の十二支（北東に丑、南東に辰、南西に未、北西に戌）が1つずつ配されており、移り変わる季節の境目の方位がそのまま土用殺に割り当てられています。

## 五黄殺と混同しやすい

九星気学の五黄殺は、方位盤の上で五黄土星が回っている方位を大凶とする考え方です。五黄殺と暗剣殺がどう決まり、年ごとにどこへ動くかは[五黄殺と暗剣殺とはどの方位か](/blog/five-yellow-and-anken-satsu)にまとめてあります。土用殺と五黄殺はどちらも「方位の大凶」ですが、決まり方が違います。

| 観点               | 五黄殺                     | 土用殺             |
| ------------------ | -------------------------- | ------------------ |
| 何で決まるか       | 年盤・月盤・日盤の星の配置 | 土用の期間かどうか |
| 続く長さ           | その盤の周期（年・月・日） | 土用の約18日間     |
| 誰にとっても同じか | 同じ（盤で決まる）         | 同じ（暦で決まる） |
| 例外               | なし                       | 間日は対象外       |

Cloud Paletteの内部では、土用殺の方位は最終判定として五黄殺と同じ扱い（大凶）に倒しています。ただし**理由の表示は別の言葉**にしています。以前は土用殺の方位が「五黄殺」と表示される画面が残っていましたが、現在は[引越しの日取りを選ぶ](/calendar)・地図の方位表示・[方位で街を探す](/relocation/arbitrage)・[移住先を比較する](/relocation/wealth)のいずれでも「土用殺」または「土用の期間」と区別して表示します。

## 年盤・月盤・日盤が吉でも、土用殺が重なるとどう判定されるのか

年盤・月盤・日盤の3枚がすべて吉方位であっても、間日以外の土用の日にその季節の土用殺の方位へ動く場合、Cloud Paletteの総合判定では大凶（段階X）になります。土用殺は個別の盤の層を書き換えるのではなく、3枚の盤を重ねた最終判定に上書きで掛かるためです。

例として2027年の春土用（土用殺は南東）に、六白金星または七赤金星の人が**南東**（辰月は年盤・月盤とも吉）へ動く場合を比べます。

| 日付                | 日の干支 | 間日か | 南東の年・月・日盤 | 土用殺 | 南東の段階         |
| ------------------- | -------- | ------ | ------------------ | ------ | ------------------ |
| 2027年4月20日（火） | 己巳     | 間日   | 吉・吉・吉         | なし   | S（三盤吉）        |
| 2027年4月21日（水） | 庚午     | 間日   | 吉・吉・平         | なし   | A（吉2盤・凶なし） |
| 2027年4月22日（木） | 辛未     | 間日外 | 吉・吉・吉         | 南東   | X（大凶・土用殺）  |

4月22日は3枚の盤だけ見れば三盤吉ですが、間日ではないため南東に土用殺が掛かり段階Xに落ちます。間日である4月20日・21日は土用殺が外れ、段階S・Aとして残ります。また、間日でない4月22日でも、南東以外の7方位には土用殺は掛かりません。

## 「土用の期間」と「土用殺」の表示の違い

このサイトは、この2つを別の場所に出しています。

- **土用の期間** — 日付そのものへの注意。時期の分析やカレンダーで、その日のスコアを下げる理由として表示します。方位を変えても消えません
- **土用殺** — 方位への注意。その方位の判定として表示します。別の方位を選べば掛かりません

間日を除けば、期間中は必ずどこか1方位が土用殺です。ただし塞がるのは1方位だけなので、「候補の方位が土用殺に当たっていない」ことは普通にあります。期間の注意と方位の注意を分けて確認すると、選択肢を狭めすぎずに済みます。

サイトの道具で分かることと分からないことも役割が分かれています。[引越しの日取りを選ぶ](/calendar)（年別は[2027年の日取り一覧](/calendar/2027)）では土用の期間・間日・六曜・吉日と本命星別の月盤吉方位が分かりますが、生年月日ごとの天中殺や日盤の重なり、出発地からの具体的な街の方位角は分かりません。それらを重ねた日×八方位の段階（S〜X）は[引越し時期を分析する](/relocation/timing)、地図上での「土用殺の方位です」という理由表示と市区町村の絞り込みは[方位で街を探す](/relocation/arbitrage)・[移住先を比較する](/relocation/wealth)で確認できます。一方で、物件の契約条件や引越し業者の空き・料金、地域の住環境まではどのツールでも判定できません。

## 引越しの計画でどう使うか

1. まず候補日が土用の期間かどうかを[引越しの日取りを選ぶ](/calendar)または[引越し時期を分析する](/relocation/timing)で確認する
2. 期間中なら、間日に当たる日がないかを見る（間日なら期間の注意も土用殺も外れる）
3. 間日以外に動く場合は、移動の方位が土用殺（その季節の四隅の1方位）に当たっていないかを[方位で街を探す](/relocation/arbitrage)で確認する
4. どうしても期間・方位が重なる場合は、日程を間日か土用明けへずらせないか比較する
5. 候補日が絞れたら、天赦日・一粒万倍日が重なる日を[同じ段階の中で選ぶ理由](/blog/tensha-and-ichiryumanbai-for-moving-day)として使う

土用や土用殺は伝統的な暦の解釈であり、効果が科学的に確認されたものではありません。また流派によって間日の扱い（間日でも転居は避けるとするか）や、土用殺の1方位だけを避けるか期間全体を避けるか、そもそも土用殺を使うかどうかに差があります。Cloud Paletteの判定は計算条件を整理する道具であり、将来の出来事を保証するものではありません。

## 方位や暦とは別に確認すること

家賃、災害リスク、契約条件、通勤時間、医療・教育環境、家族の合意は、暦の判定とは無関係に必要な確認です。土用を避けられても、これらが不適切ならよい引越しとは限りません。
