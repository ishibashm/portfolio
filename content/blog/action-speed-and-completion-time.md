## 速いという感想には、終点が必要になる

**仕事の速さを比べるには、何を始点とし、どこまでできたら完成とするかをそろえる必要があります**。[参考動画](https://youtu.be/_lmXMrV3cdw)は、周囲の進み方に合わせて小さく始めることや、慎重に確認しながら進むことを、陰陽の人物像と結びつけて説明しています。これは**動画内の見解**であり、分類ごとの所要時間を比較した測定結果ではありません。

自分の進め方を振り返るきっかけにはできますが、生まれの分類から仕事の速度は計算できません。[十干の陰陽の比喩](/blog/ten-stems-yin-yang-metaphors)で扱った分類と優劣の違いを踏まえ、この記事では作業の時間に絞ります。転職の回数や失敗の日干周期を説明する記事とは、数える対象が異なります。

## 着手が早くても、完成が早いとは限らない

依頼を受けた時刻、最初に手を動かした時刻、使える成果物を渡した時刻は別です。次は記事独自の架空例で、動画の登場人物の実績ではありません。同じ日の9時に、同じ完成条件の資料を依頼されたとします。

| 記録                     | 進め方A | 進め方B |
| ------------------------ | ------- | ------- |
| 依頼                     | 9時     | 9時     |
| 着手                     | 9時10分 | 10時    |
| 最初の提出               | 11時    | 12時    |
| 修正を終えて受け取り完了 | 15時    | 12時    |
| 依頼から受け取り完了まで | 6時間   | 3時間   |

Aは着手まで10分、Bは60分なので、着手を待つ時間はAが短いと計算できます。しかし受け取り完了までならAは6時間、Bは3時間です。「Aのほうが速い」だけでは、何を測ったのか分かりません。この例の時間差は算術で確認できますが、早く着手することが手戻りを増やすという因果の証明ではありません。

また、9時から15時までをすべて作業時間としてはいけません。途中で別の仕事をしていたり、確認の返事を待ったりしている可能性があります。経過時間と実作業時間を分けると、本人の手順を直すのか、確認担当の待ち時間を見直すのかが変わります。

## 数字の評価

(a)は暦の計算で確かめられる事実、(b)は統計等で確認できる事実、(c)は動画の解釈・経験則で根拠未提示のものです。数字が順序や比喩に使われている場合、実測された量とは区別します。

| 動画に出る数字                             | 分類と計算・確認方法              | 確からしさ                                                                   |
| ------------------------------------------ | --------------------------------- | ---------------------------------------------------------------------------- |
| 落とし穴7選の4番目                         | (c)の説明を並べる番号             | 4番目に多い原因という頻度・順位の統計ではない                                |
| 陰陽の2分類                                | 分類の個数。行動速度への対応は(c) | 2群の人数、仕事内容、測定時間が示されていない                                |
| 小さく始める際の分数表現                   | (c) 規模を小さくする例            | 自動字幕では分母を確定できない。数値を推測せず、縮小率や推奨割合には使わない |
| 3段階ぐらいで動き出す                      | (c) 段階についての経験的説明      | 各段階の完成条件と期間がなく、3回で成果が出るとは確認できない                |
| 2歩目・3歩目・10歩、1つ目の駅、もう1回確認 | (c) 進み方の比喩                  | 歩数を日数や暦の周期へ換算する規則は提示されていない                         |
| 今日の1番、来月・再来月の1歩               | (c) 強調や今後の行動の表現        | 効果の順位・翌月の成功率を表す測定値ではない                                 |

本動画から(a)の具体的な暦計算や、(b)の確認済みの速度比較は得られません。特に「10歩」は、日干が10日で一巡することを証明するための数字ではありません。暦の10と説明の10が同じだからといって、同じ長さを表すとは扱いません。字幕で不確かな分数を、もっともらしい数字へ修正して引用することも避けます。

## 小さく始めるなら、比較する成果物をそろえる

たとえば10ページの案を作る仕事を、まず1ページの見本だけ作る仕事へ変えるとします。これは記事独自の例です。ページ数だけなら1÷10＝10%ですが、必要な作業時間が10%になるとは限りません。最初のページには資料集めや書式決めが含まれ、残りのページと同じ時間で作れるとは限らないからです。

見本を先に見せる狙いが「方向が合うか確認すること」なら、完成条件は全ページの納品ではなく、確認に必要な見本の提示です。この二つを混ぜて、以前より完成が10倍速くなったとは言えません。見本の確認後に残りを作る時間も含めて初めて、全体の所要時間を比較できます。

記録には、依頼内容、見本で確認する点、確認する担当、返答予定、最終納品の条件を添えます。最初の提出後に大きく方針が変わった場合も、その変更が早く分かった価値と、全体が早く終わったかどうかは別に評価できます。小さな着手が有用だったかを、提出の早さだけで決めないためです。

## 次の仕事に引き継ぐのは、分類よりも条件

振り返りで「自分は慎重だから遅い」とだけ書いても、次に変える手順が分かりません。「返答待ちで半日止まった」「最初に完成条件を確認できた」と書けば、次回の依頼や確認の仕方に戻れます。同じ人でも、初めての仕事と慣れた仕事では条件が違います。別々の仕事を一つの平均時間にまとめる前に、何を比較したいのかを決めます。

この記録は、速い人を選別するための得点表ではありません。依頼する側と作業する側が、どの区間を短くしたいか共有するためのものです。失敗の件数や率も併せて確認したい場合は、[日干の周期と失敗率を分けて記録する](/blog/ten-day-cycle-and-mistake-rate)で分母の扱いを説明しています。

四柱推命と九星気学は別体系です。Cloud Paletteは真北で方位を判定し、暗剣殺・五黄殺は誰にとっても凶として扱います。実行が早いこと、志を持って行動することが、凶方位を解除する条件にはなりません。動画の仕事の比喩とサイトの移動判定は分けて読みます。
