## 求めた違いを、採用後に嫌っていないか

**採用した人への違和感を考えるときは、応募時に求めた仕事と、今の評価基準を並べて確認できます**。[参考動画](https://youtu.be/7LQCDXQGIps)では、自分にない能力を求めて人を迎えたのに、実際に違うやり方をされると受け入れられなくなる、という経験談が語られます。相剋の関係を受け入れると成長につながるという説明は、**動画内の見解**です。

動画の事例から、特定の五行の人を採用すれば成果が出るとは確認できません。また、五行を同じ人数ずつそろえるという配分表も提示されていません。この記事では、相性による採否の判断ではなく、期待と評価が途中で変わっていないかを確かめる方法を扱います。五行そのものの仕事の比喩は[五行で語られる仕事の役割](/blog/five-elements-and-work-roles)に整理しています。

## 「違う」と「できていない」を別の欄に書く

たとえば、仕入れを正確に記録してほしいと依頼した後、担当者が確認のために質問を重ねるとします。「自分ならすぐ決めるのに」という感想と、「数量を間違えている」という観測は同じではありません。質問に時間がかかっても記録が正確なら、依頼の一部は満たしている可能性があります。一方、正確でも締切を過ぎて使えなければ、期限について話し合う必要があります。

ここで記録するのは、生まれ持った人物像ではなく、その仕事で合意した条件です。次の表は記事独自の架空例であり、動画のレストランの実績ではありません。

| 採用時・依頼時の期待       | 後から生まれた不満             | 照合する資料                                       |
| -------------------------- | ------------------------------ | -------------------------------------------------- |
| 仕入れ数量を正確に記録する | 質問が多く、進み方が遅く感じる | 記録の誤り、確認に必要だった情報、合意した提出時刻 |
| 自分と違う提案を出す       | 指示への異論が多い             | 提案を求めた範囲、決定済みの条件、異論の内容       |
| 担当者だけで作業を進める   | 相談が少なく、不安に感じる     | 任せた権限、相談が必要な条件、途中報告の約束       |

この照合で、相手が正しいと自動的に決まるわけではありません。求めた成果が出ていない場合もあれば、依頼した側が必要な情報を渡していない場合もあります。性格の好き嫌いから一足飛びに結論を出さず、直せる条件を探すための表です。

## 数字の評価

(a)は暦の計算で確かめられる事実、(b)は統計等で確認できる事実、(c)は動画の解釈・経験則で根拠未提示のものです。経験談の金額や期間は、計測できる形の数字でも、資料がなければ(b)の確認済み事実には置けません。

| 動画に出る数字                                 | 分類と計算・確認方法                | 確からしさ                                                                     |
| ---------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------ |
| シリーズの7番目                                | (c)の説明に付いた整理番号           | 多様性の効果の順位や大きさを表す値ではない                                     |
| 五行の5                                        | 分類名の個数。成長への意味づけは(c) | 人数比や能力の測定値ではなく、5人・各20%という配置は導けない                   |
| 1か月後の予定を2か月にする例                   | (c) 期限を調整する提案              | 月数は2÷1＝2倍だが、成果が2倍になるという計算はできない                        |
| 最初の1か月で嫌になった、まだ1か月という経験談 | (c) 個別事例の経過                  | 起算日、勤務日数、仕事の記録がなく、一般的な評価期限にはできない               |
| 具体例を1個、大学卒業まで働いたという話        | (c) 例示と経過の説明                | 1事例の紹介であり、観測総数や在籍年数は不明                                    |
| 1年ぐらいで1億円プレイヤー                     | (c) 営業に関する経験談              | 売上・利益・受注額のどれか、集計期間や資料が不明。収益の実証値として採用しない |

この動画には(a)に当たる具体的な干支計算や、(b)として確認できた採用成果の統計はありません。1億円という大きさが印象に残っても、同じ方法を試した全員の成績がなければ成功率は分かりません。給料や売上が上がったという定性的な説明から、増加率を補うこともしません。

## 期限を延ばした効果と、仕事を減らした効果

1か月を2か月に延ばす提案を検討するなら、何を同じに保ったかが大切です。以下も記事独自の架空例です。20件の整理を1か月で終える予定なら、月あたりの予定量は20件です。同じ20件を2か月に変更すると、平均予定量は10件になります。一方、期間も件数も2倍にして40件を2か月で扱うなら、月あたりは20件のままです。

前者は月あたりの予定量を減らしています。後者はそうではありません。どちらも「2か月にした」と言えますが、担当者にとっての条件は違います。しかも暦月の日数や勤務日数は同じとは限らず、月あたりの数字だけで時間あたりの負担まで確定しません。実際の比較では、作業可能な時間と、質問への返答待ちも残します。

提出が間に合ったら、それが期限の余裕によるものか、手順の習熟や情報提供の改善によるものかも区別します。一度うまくいった結果は、その条件で作業が完了した記録として使えますが、五行の相性が実証されたことにはなりません。

## 人物の評価へ広げる前に、合意を読み直す

次の仕事を依頼するときには、成果物、提出時刻、任せる範囲、途中で相談する条件を文章にします。終わった後は同じ文章を読み、満たした点と変更した点を残します。途中で目的が変わったなら、担当者の失敗として数える前に変更履歴を確認します。出生情報を加えなくても、この照合はできます。

相手への伝え方そのものは[五行の相性と身近な人との会話](/blog/compatibility-and-communication)でも扱っています。ここでの目的は、合わない人を五行で選別することではなく、自分が求めた違いを評価の段階で消していないかを確かめることです。

四柱推命と九星気学は別体系です。Cloud Paletteの方位判定は真北を基準とし、暗剣殺・五黄殺は誰にとっても凶として扱います。仕事上の相性や組織の成果を理由に、移転先の方位判定を変更することはありません。

[参謀の相性ランキングと選定条件の違い](/blog/adviser-ranking-and-selection-criteria)では、比較する数字とその条件をさらに具体的に整理しています。
