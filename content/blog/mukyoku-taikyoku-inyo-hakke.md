## 先に結論

**太極から両儀、四象、八卦へという流れは、陰と陽の組合せを段階的に増やす見方で理解できます**。ただし、無極の説明も、九星の配置も、すべてが一つの古典に同じ形で書かれているわけではありません。

『易経』は太極・両儀・四象・八卦の関係を述べます。周敦頤の『太極図説』は無極と太極の関係を論じます。そこから九星気学の盤を読むには、さらに**後天八卦の方位配置と、洛書の九つの数**を重ねて見る必要があります。

冒頭の図は、この関係を整理したものです。左側は概念と記号の組合せ、右側は方位と九星の対応です。無極から太極への矢印は説明の順序を示しており、時間の中で何かが発生したと断定するものではありません。

## 太極から両儀・四象・八卦へ、何が増えるのか

[『易経』繋辞上伝](https://ctext.org/book-of-changes/xi-ci-shang/zh)には、次の一節があります。

> 易有太極，是生両儀，両儀生四象，四象生八卦

太極から両儀が生じ、両儀から四象、四象から八卦が生じる、というつながりです。ここでは、**両儀を陰と陽、四象を太陽・少陰・少陽・太陰とする説明**で整理します。四象の解釈には幅があり、この一節自体が四つの名称を列挙しているわけではありません。

陰陽を線で表すと、陽は一本につながった線、陰は途中で切れた線になります。この線を**爻**（こう）と呼びます。下から上へ積み重ね、各段に陰か陽を選ぶと、次のようになります。

| 段階     | 線の数 | 組合せ                          |
| -------- | ------ | ------------------------------- |
| 両儀     | 1 本   | 陰・陽の 2 通り                 |
| 四象     | 2 本   | 太陽・少陰・少陽・太陰の 4 通り |
| 八卦     | 3 本   | 8 通り                          |
| 六十四卦 | 6 本   | 64 通り                         |

四象では、下から陽・陽なら太陽、陽・陰なら少陰、陰・陽なら少陽、陰・陰なら太陰です。さらに一爻を加えると八卦になります。

**各段で同じ二択を繰り返す**という意味で、二進的な構造として眺められます。八卦を上下に二つ重ねると 8 × 8 = 64 通りになり、六十四卦になります。線を一本ずつ増やすなら、8 の次は 16、32、64 です。八卦から六十四卦へは、一度の二分ではありません。

この規則性は記号の組合せとして確かめられます。それだけで自然界のすべてが同じ仕組みで動くと証明されるわけではありません。

## 無極は太極より前にあるのか

周敦頤『太極図説』の冒頭は、一般に次の形で知られています。

> 無極而太極

**無極から太極が生じる**という生成の順序として読むのか、**無極にして太極**と読み、形や限りを持たないことと根本原理であることを同時に述べていると考えるのか。ここには解釈上の問題があります。

朱熹と陸九淵の間でも、無極という語の必要性や太極との関係が論争になりました。朱熹は無極を太極とは別の先行する存在にしませんでした。ただし、この論争を「朱熹は同一説、陸九淵は時間的な生成説」と単純に二分するのも正確ではありません。

入門図では無極→太極と並べると見通しがよくなりますが、**その矢印自体が一つの解釈を含む**ことに注意が必要です。また、『易経』の先ほどの一節は太極から始まっており、その前に無極があるとは述べていません。二つの文献を合わせた説明と、それぞれの原文を区別して読むと混乱しにくくなります。

## 易経は道教の本なのか

**『易経』は儒教の経典である五経の一つです**。太極や八卦が道教でも使われるからといって、易経そのものを道教の経典と位置づけるのは適切ではありません。

一方、道教の思想的な基盤でもある[『老子』第四十二章](https://ctext.org/dao-de-jing/zh)には、次の一節があります。

> 道生一，一生二，二生三，三生萬物

道から一、二、三を経て万物へ、という生成の説明です。根源から多様なものへ展開するという点では、太極と陰陽の説明に通じる見方があります。ただし、**老子の一・二・三を、そのまま太極・両儀・四象と置き換えることはできません**。二の次が三であることも、先ほどの二倍ずつの組合せとは異なります。

太極・陰陽・八卦は、儒教と道教の両方で使われてきた概念です。共通の語彙があっても、どの文献で何を説明するために使っているかは分けて読む必要があります。

## 先天八卦と後天八卦は、どこが違うのか

八卦の記号と象（自然界になぞらえた意味）は共通でも、**方位への並べ方は一つではありません**。先天八卦は伏羲八卦、後天八卦は文王八卦とも呼ばれます。これは伝統的な呼び名であり、図をその人物が実際に作ったと確認できる、という意味ではありません。

先天八卦は乾と坤、離と坎などの対を向かい合わせにする配置です。後天八卦は『易経』説卦伝に述べられる方位関係に基づき、季節の巡りや変化を読む配置として使われます。

| 卦    | 象  | 先天八卦の方位 | 後天八卦の方位 |
| ----- | --- | -------------- | -------------- |
| 乾 ☰ | 天  | 南             | 北西           |
| 兌 ☱ | 沢  | 南東           | 西             |
| 離 ☲ | 火  | 東             | 南             |
| 震 ☳ | 雷  | 東北           | 東             |
| 巽 ☴ | 風  | 南西           | 南東           |
| 坎 ☵ | 水  | 西             | 北             |
| 艮 ☶ | 山  | 北西           | 北東           |
| 坤 ☷ | 地  | 北             | 南西           |

東北と北東は同じ方位です。たとえば乾は、先天では南、後天では北西にあります。**八卦の名称だけで方位を決めず、どちらの配置を見ているかを確認する**のが大切です。

伝統的な図には南を上に描くものがあります。この記事の図は地図と照合しやすいように**北が上、東が右**です。向きを変えて描いても、卦と方位の対応は変わりません。

## 洛書と後天八卦を重ねると、九星の定位になる

九星気学で使う定位は、**洛書の数と後天八卦の方位を対応させた配置**です。洛書は 1〜9 を三行三列に置き、縦・横・斜めの和がいずれも 15 になる魔方陣として知られています。

| 九星     | 定位 | 後天八卦       |
| -------- | ---- | -------------- |
| 一白水星 | 北   | 坎             |
| 二黒土星 | 南西 | 坤             |
| 三碧木星 | 東   | 震             |
| 四緑木星 | 南東 | 巽             |
| 五黄土星 | 中央 | 対応する卦なし |
| 六白金星 | 北西 | 乾             |
| 七赤金星 | 西   | 兌             |
| 八白土星 | 北東 | 艮             |
| 九紫火星 | 南   | 離             |

八卦は八方位、九星は中央を含む九つの位置に対応します。**八卦をさらに二分して九星ができるわけではありません**。陰陽の組合せの話から、洛書という別の数の配置を重ねる話へ移っています。

また、定位は基準となる配置です。実際の年盤・月盤などでは星の位置が移るため、一白がいつも北にあるわけではありません。数の並びと盤の動きは、[なぜ星は9つで、なぜあの並びなのか](/blog/why-nine-stars-and-that-order)で詳しく扱っています。

## 自分の本命星と方位を確かめるには

まず[本命星と吉方位の早見表](/houi)で、生年月日から自分の本命星を確認できます。そこから年ごと・月ごとの方位へ進むと、基準となる定位と、その時点で星が座る位置の違いを見比べられます。

実際の場所に照らすときは、[市区町村別の方位ページ](/houi/area)が入口になります。用語や見方が分からないときは、[AIに聞く](/ask)で、どの盤や方位を見ているのかを添えて質問してください。

陰陽に五行・干支・暦を加えた4つの土台が、四柱推命や九星気学にどう使われているかは[占いの土台は4つ](/blog/four-foundations-of-eastern-divination)で整理しました。

**九星気学の判定は参考情報です**。配置の規則が分かることと、その方位への移動が将来の結果を決めることは別です。盤の意味を理解したうえで、住まいの条件と合わせて判断するために使ってください。
