## 入力の確認と、解釈への納得は別の作業

**鑑定が自分に合わないと感じたときは、確かめられる入力・計算条件と、人物像の解釈を分けて確認できます**。[参考動画](https://youtu.be/HHcCDoUb0pA)では、説明が当てはまらない理由として生年月日の間違いや、本人の選択・育った環境などが挙げられています。

そのうち「本来の道からずれている」とする説明は**動画内の見解**です。鑑定への違和感だけを根拠に、自分の生き方が間違っていると結論づける必要はありません。入力が正しいことと、人物像の説明が自分に合うことは、別々に確かめる話です。

## まず記録を照合する

生年月日は記憶だけで修正せず、確認できる記録と照合します。出生時刻が分からない場合は、不明のまま扱うことも大切です。「この結果のほうが自分らしい」という理由で時刻を選ぶと、計算条件を確認したことにはなりません。

| 確認するもの | 記録しておきたい点                         |
| ------------ | ------------------------------------------ |
| 生年月日     | 年月日の転記違いがないか、どの記録を見たか |
| 出生時刻     | 記録された時刻か、家族の記憶か、不明か     |
| 時間帯       | 日本標準時か、海外の現地時刻か             |
| 計算対象     | 年・月・日のどの干支を比べているか         |
| 計算条件     | 年・月・日をいつ切り替える方式か           |

結果が違うサービスを比較するときも、人物像の文章だけでなく、これらの条件をそろえて見ます。年の干支と日の干支を比べていれば、同じ生年月日でも違う文字が出ることがあります。

## 日付だけの入力は出生時刻を確定しない

Cloud Paletteの干支計算では、日付だけの入力をJSTの正午の代表値として扱います。これは、正午に生まれたと推定したという意味ではありません。

年の干支は立春の瞬間、月の干支は12の節入りの瞬間、日の干支はJSTの0時で切り替えます。日付だけを指定した場合、その日の中で年や月が切り替わるなら、公開MCPの`get_kanshi`は境界の前後の候補も返します。ここで説明しているのは、この干支計算の仕様です。

たとえば既存の計算では、2026年の立春の前は年が乙巳・月が己丑、後は年が丙午・月が庚寅になります。2月4日という日付だけでは、出生が境界の前後どちらだったかは決まりません。節気時刻も計算値であり、公式暦と数分の差があり得るため、境界に近い出生はその精度も確認する必要があります。

また、同じ計算で2000年1月7日23時59分59秒の干支は甲子、翌8日0時は乙丑です。ここでは23時で日の干支を切り替えていません。別の方式と比較するときは、日付を切り替える時刻も確認してください。年・月・日の違いは[干支は60種類](/blog/sixty-kanshi-and-history)でも説明しています。

## 計算を確認しても、人物像の正しさは決まらない

入力を直して干支が変わった場合、確認できたのは計算結果の変化です。「今度の説明が合う気がする」という感想は、その先にある解釈への受け止め方です。反対に、入力も計算条件も同じなのに説明へ納得できなくても、それだけで本人の選択や育ち方が誤っていたとは言えません。

参考動画が語る生き方や環境による違いは**動画内の見解**として読み、実際の経験と照らして受け取れる範囲を考えてください。合わない説明まで自分の責任として引き受ける必要はありません。

[暦](/calendar)は年月日の干支や節気を確認する入口になります。ただし、干支の表示だけで人の性格や将来を保証するものではありません。道具に任せる範囲は[この道具で分かること・分からないこと](/blog/what-this-tool-can-and-cannot-decide)に整理しています。

四柱推命と九星気学は別体系です。出生データを確認する作業と方位判定も区別してください。Cloud Paletteの方位は真北を基準とし、暗剣殺・五黄殺は誰にとっても凶として扱います。鑑定への納得度によって、この方位の規則を変えることはありません。

## 数字の評価

(a)を暦の計算で確かめられる事実、(b)を統計等で確認できた事実、(c)を動画の解釈・経験則で根拠未提示のものとして整理します。動画の比率は、出生時刻のような計算入力とは性質が違います。

| 動画に出る数字                             | 分類と計算・確認方法                                       | 確からしさ                                                 |
| ------------------------------------------ | ---------------------------------------------------------- | ---------------------------------------------------------- |
| 願いや確信の100%、引き寄せなく生きる人は0% | (c) 心の状態や世界観の説明。測定尺度・人数・調査方法はない | 成功確率100%や例外率0%を実測した数字ではない               |
| 3段階                                      | (c) 引き寄せ・形・運びという動画独自の説明の区分           | 区分が3つあることは読めるが、効果や順序の必然性は未検証    |
| 大学3年生、10代                            | (c) 進路や教育の例に使われる学年・年代                     | その時期に鑑定すべきだという暦の条件ではない               |
| 1割ほどという教育の話                      | (c) 語尾も推測的で、対象者数・結果の定義・集計方法が未提示 | 1割＝10%という換算はできても、実際の割合としては採用しない |
| 現状維持を含む3つの状態、1番上、ゼロ地点   | (c) 会話上の分類や比喩的な順位・位置                       | 幸福度を測った得点ではなく、他人と比較する尺度にできない   |
| A・Bの2択を繰り返す例                      | (c) 選択で道が変わるという説明用の仮定                     | 現実の人生が常に2択であることや、正解率を示さない          |

動画内の数字について、統計で確認済みの(b)に分類できる割合はありません。この記事で別に示したJSTの0時・正午12時・12の節入りは、動画の成功論の数字ではなくCloud Paletteの計算条件です。24節気のうち月を切り替えるものを交互に数えると12であり、出生時刻が不明なら正午という代表値と実際の出生時刻を混同できません。

入力の誤差を分や日で記録することはできますが、解釈への違和感を何%と数えて暦の誤差へ変換する方法はありません。比較表には、計算に入れた日時と結果をまず書き、その下に感想を別欄で残すと、何を修正したのかが分かります。

同じ生年という入力から性格まで判断できるかは、[年干支の一致で分かる範囲](/blog/same-birth-year-personality)で検討しています。

願いの強さに付けられた百分率は、出生データの正確さとは別の問題です。[「100%の引き寄せ」と確率の違い](/blog/wishes-and-probability-measurement)では、気持ちの表現と件数から計算する割合を分けています。
