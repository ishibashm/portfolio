## 結果を知る前の言葉を残す

**運勢を振り返るなら、最初に何を予想していたかと、後でどう説明したかを別々に残す必要があります**。[参考動画](https://youtu.be/K3_db9wFsbw)では「自分の時計」と「天の時計」を合わせ、月のキーワードから浮かんだことを書き、起きた出来事を振り返る方法が語られます。書いたことが実現する、時計に合わない行動で結果が失われるという説明は、**動画内の見解**です。因果関係が確認された法則としては扱いません。

本記事のテーマは、記録をいつ、どの欄に書くかです。事業を始める年の選び方は[年干支と事業開始年](/blog/year-stems-and-business-start-dates)、作業の所要時間は[着手と完成の時間](/blog/action-speed-and-completion-time)で扱っています。ここでは運勢の助言を採用すべきかよりも、採用した予測を後から検討できる形にすることに絞ります。

## 事前の予測と、後の解釈は別の記録

「動き出す月」という言葉だけでは、新しい仕事を受けた場合も、準備をした場合も、予定を変えた場合も一致と読めます。自分の気持ちを表す日記としてはそれでも使えますが、予測が当たったかを数えるには、何が起きれば一致なのかが足りません。

記事独自の例として、「月末までに、自分から提案した案件の打ち合わせ日が決まる」と書くなら、日付が確定したかを後で確認できます。日付を決めるために自分が連絡したことも一緒に残します。結果が生まれた理由を運勢だけに限定せず、行動、相手の都合、当初の予定を読み返すためです。

結果が出なかったときに「動かないと決めたことが動きだった」と意味を変えるなら、それは新しい解釈欄に書きます。最初の予測を消して上書きすると、当初の言葉で確かめられなくなります。新しい解釈を考えることと、古い予測が的中したと数えることを分けます。

## 数字の評価

(a)は暦の計算で確かめられる事実、(b)は統計等で確認できる事実、(c)は動画の解釈・経験則で根拠未提示のものです。

| 動画に出る数字                       | 分類と計算・確認方法                                     | 確からしさ                                                                   |
| ------------------------------------ | -------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 2026年、2月からの1年間               | 年月の指定は(a)で境界確認が可能、活動の予測は(c)         | 本サイトの干支の年替わりは立春。2月1日に全員の活動が変わるという意味ではない |
| 2月・3月・4月、問いに出る5月         | 月の順序と差は(a)、開始・見守り・成果との対応は(c)       | 2月から4月の月番号の差は2。結果が2か月後に出る証明ではない                   |
| 書いてから3日                        | 日付差は(a)、出来事の発生との対応は(c)                   | 起算日を決めれば3日後を出せる。書いたために出来事が起きる根拠は未提示        |
| 2か月・3か月後に失う例               | (c) 仮定の結果とその説明                                 | 損失の発生率や発生時期を測定した資料ではない                                 |
| 約30年間の記録経験                   | (c) 経験談。記録の起点と全件を照合できれば期間は検証可能 | 原記録を確認していない。30年の暦周期や的中率を示す数ではない                 |
| 1個に限らない、1回の体験、毎月の案内 | 記録・体験・案内の回数の説明。効果は(c)                  | 複数書けばその分だけ検討対象も増える。成功例だけでは割合を出せない           |

(b)として確認済みの的中率や、記録による成果の改善率は得られません。「全部実現する」という主張も、事前の全記録、期限、未達の扱いを照合できないため、100%の実績としては掲載しません。金銭的な結果についても、この動画の時計の説明から予測しません。

## 暦の期限と、観測の期限をそろえる

Cloud Paletteの干支計算は、年を立春、月を12の節入りの瞬間、日を日本標準時の0時で切り替えます。動画の「3月」を検討するときも、通常の3月1日から末日までを指すのか、節月を指すのかが決まらなければ、比較する期間がそろいません。境界の詳しい説明は[出生データと解釈を分ける記事](/blog/birth-data-before-interpretation)を参照できます。

記事独自の単純な日付例では、2026年3月1日正午から3日後は3月4日正午です。経過時間なら72時間です。しかし「3日間観察する」が3月1日・2日・3日の三つの日付を含む意味なら、終了の表現が異なります。どちらを採用するか先に書く必要があり、動画の短い言葉だけから観測期限を創作しません。

## 一致しなかった予測も同じ表に残す

| 欄             | 記事独自の記入例                                     |
| -------------- | ---------------------------------------------------- |
| 記入日時と予測 | 3月1日、月末までに打ち合わせ日が決まる               |
| 観測条件       | 自分から提案した案件。日程が確定した連絡を確認する   |
| 自分の行動     | 提案を送った日と、追加連絡をした日                   |
| 結果           | 月末時点で日程未定                                   |
| 後の解釈       | 返答待ちだった。期限を延ばす場合は次の予測として書く |

仮に予測を10件書き、一致3件、不一致5件、期限前2件だったとします。全件に対する一致は3÷10＝30%、期限を迎えた8件に限れば3÷8＝37.5%です。どちらも記事独自の架空例で、動画の的中率ではありません。分母を変えた理由を併記しないと、同じ記録から違う印象を作れます。

さらに、一致した割合だけでは、何も予測しない場合や別の予測との違いは分かりません。この表は記録を比較可能にするための例であり、占術の有効性を実証したものではありません。

四柱推命と九星気学は別体系です。Cloud Paletteは真北で方位を判定し、暗剣殺・五黄殺は誰にとっても凶として扱います。日記に期待を書いたことや、予測が一度一致したことを、凶方位の解除条件にはしません。
