## 年の名前と、事業の開始条件は別に確かめる

**2028年の年干支が戊申であることは計算できますが、その年に見つけた事業案を寝かせるべきかは、干支の計算からは決まりません**。[参考動画](https://youtu.be/Rmue4BRQZOU)では、年の進行を種や根、植物の成長にたとえ、2028年頃に案が見つかった場合は待つという説明が登場します。これは**動画内の見解**です。開始年ごとの事業成績を比較した資料は提示されていません。

年の意味づけを、そのまま未来の事実として扱わないことが大切です。この記事では、事業を始める日取りの正解を提示するのではなく、年干支として確認できる範囲と、着手の判断に別途必要な情報を分けます。[干支併臨の60年と30年](/blog/numbers-in-kanshi-heirin)で扱った周期の話とは異なり、対象は具体的な開始年の判断です。

## 2024年から2028年の年干支を計算する

Cloud Paletteでは年の切り替えを立春とします。以下は境界から離れた各年3月1日正午、日本標準時での年干支です。1月1日から12月31日までを無条件に同じ年柱として扱う表ではありません。

| 計算に入れる日 | 年干支 | 天干の五行 |
| -------------- | ------ | ---------- |
| 2024年3月1日   | 甲辰   | 木         |
| 2025年3月1日   | 乙巳   | 木         |
| 2026年3月1日   | 丙午   | 火         |
| 2027年3月1日   | 丁未   | 火         |
| 2028年3月1日   | 戊申   | 土         |

計算方法は、立春を境に決めた年から4を引き、60で割った余りを甲子を0とする番号として読むものです。2024−4＝2020、2020を60で割った余りは40なので甲辰です。翌年は余り41で乙巳、2028年は余り44で戊申となります。既存の暦計算でこの表を照合しています。

甲乙を木、丙丁を火、戊己を土とする対応は[国立天文台の六十干支の解説](https://eco.mtk.nao.ac.jp/koyomi/faq/60kansi.html)でも確認できます。ただしこれは天干の分類です。2026年にすべての事業が成長する、2028年には新規事業が育たない、という経済的な結論を含んでいません。表から読めることを、その先の予測にまで広げないようにします。

## 数字の評価

(a)は暦の計算で確かめられる事実、(b)は統計等で確認できる事実、(c)は動画の解釈・経験則で根拠未提示のものです。同じ年の数字でも、年干の対応と事業への意味づけは分類が変わります。

| 動画に出る数字                                        | 分類と計算・確認方法                         | 確からしさ                                                                 |
| ----------------------------------------------------- | -------------------------------------------- | -------------------------------------------------------------------------- |
| 2024年の甲、2025年の乙                                | (a) 年干の対応。木の時代という事業解釈は(c)  | 上記の剰余計算で確認可能。経営成績の予測は確認できない                     |
| 10パターン                                            | 天干の個数は(a)で照合可能。経営者像は(c)     | 10種類あることから、人物や市場を10群で予測できるとは決まらない             |
| 2025年から2026年に根を育てる                          | 年の進行は(a)、根を育てる時期という説明は(c) | 乙巳から丙午への移行は計算可能。事業の発達段階との一致は未確認             |
| 2026年・2027年に成長する                              | 丙・丁の対応は(a)、成長の予測は(c)           | 暦で火に分類されることと売上等の増加は別の主張                             |
| 2028年頃に見つけた案を寝かせる、5年待つというやり取り | (c) 着手時期への助言                         | 何月何日を起点・終点にするか、成果指標が不明。最適な待機期間と確認できない |
| 1周、2個目、1個ずつ成立させる                         | (c) 図の順序や行動の説明                     | 図の指示先を字幕だけで確定せず、独自の年数へ換算しない                     |
| 1番よいという助言の順位                               | (c) 推奨の強調                               | 他の方法との比較資料がなく、効果の順位ではない                             |

この動画から(b)として採用できる確認済みの事業統計は得られません。5年という言葉を聞いても、開始を遅らせた企業と遅らせなかった企業の成績、対象業種や観測期間がなければ、待った効果は計算できません。「全員が同じ年にいる」ことも「全員に同じ行動が適する」ことの証拠にはなりません。

## 5年後を足しても、推奨の期限は確定しない

単純な年数の足し算なら2028＋5＝2033です。しかし、この計算だけで動画が2033年の開始を指定したとは言えません。5年間を丸ごと待つのか、年をまたぐ回数を数えるのか、図のどの位置まで待つのかを確定できないためです。字幕の「ここ」を想像で埋め、開始日を作ってはいけません。

同じ天干が戻る周期との違いも確認できます。戊の次の戊は10年後の2038年で、2033年の年干は癸です。同じ年干支の戊申が戻るのは60年後です。したがって5年待つという助言を、同じ天干や年干支へ戻るための待機と説明することはできません。待つ理由は、暦の一致とは別の解釈になります。

ここで扱うのは足し算と符号の周期です。2033年や2038年のどちらが事業に有利かを比較した結果ではありません。周期が正しく計算できても、経営上の推奨が正しくなるとは限らない点を保ちます。

## 待つ間に何を確認するのかを言葉にする

着手を保留するときには、「年が変わるまで」だけでなく、何が確認できれば次へ進むかを記録できます。次の表は記事独自の整理例です。動画の方法の効果を実証したものでも、資金の投入を勧めるものでもありません。

| 確認したい条件             | 残す記録                                     | 見直すきっかけ                   |
| -------------------------- | -------------------------------------------- | -------------------------------- |
| 誰のどの困り事に応える案か | 想定する利用場面と、実際に聞けた内容を分ける | 想定と異なる要望が見つかったとき |
| 何がまだ不明か             | 未確認の仕様や実施条件を列挙する             | 必要な情報が得られたとき         |
| どこまで試すか             | 確認する範囲と完成条件を決める               | その範囲の確認が終わったとき     |
| 保留の理由は何か           | 暦への解釈と、現実の未解決条件を別欄にする   | 保留理由の一つが解消したとき     |

何も確認せずに待つことと、分からない点を調べながら保留することでは、次に判断するときの情報が違います。逆に条件が整っていないまま「成長の年だから」と進めても、暦が不足情報を埋めるわけではありません。年の名前を記録するなら、実際に変わった条件も並べて残します。

四柱推命と九星気学は別体系です。Cloud Paletteは真北で方位を判定し、暗剣殺・五黄殺は誰にとっても凶として扱います。事業に良い年という動画の解釈で、移転の凶方位は打ち消しません。計算と判断の範囲については[この道具で決められること、決められないこと](/blog/what-this-tool-can-and-cannot-decide)も参照してください。
