## 先に結論

Cloud Paletteの**「平穏」は、吉方位ではありません。**五黄殺や暗剣殺などの凶が当たっていない、というだけの状態です。

吉と判定されるのは「大吉方位」と「吉方位」だけで、平穏はその手前にあります。

## 6つの段階

方位の評価には次の段階があります。

| 表示 | 意味 |
| --- | --- |
| 大吉方位 | 吉。もっとも強い |
| 吉方位 | 吉 |
| **平穏** | **凶が当たっていないだけ。吉ではない** |
| 注意（引越当日） | 長期では吉だが、移動する当日に干渉がある |
| 凶 | 二次凶が当たっている |
| 大凶 | 五大凶殺が当たっている |

九星気学では、八方位のうち吉方位になるのは本命星と相性のよい星が回座した方位だけで、たいていの方位は「どちらでもない」に落ちます。**平穏が多いのは正常**です。

## 「吉」と「平」が画面で食い違っていた

以前、[物件を方位で探す](/relocation/arbitrage)と[移住先の地域を比べる](/relocation/wealth)だけが平穏を「吉方位」と表示していました。同じ方位が[本命星と吉方位を調べる](/houi)の記事では「平」と出るため、どちらが正しいのか分からない状態でした。

判定の本体は最初から「大吉・吉だけを吉とする」で一貫していて、誤っていたのは表示の言葉です。現在は`src/lib/directionLabels.ts`という1つの対応表からすべての画面が日本語を引いています。

## 「平穏なら引越してよいか」

これは解釈が分かれるところです。

- **吉方位でなければ動かない**という立場では、平穏は待つ理由になります
- **凶方位を避ければ十分**という立場では、平穏は問題になりません

Cloud Paletteはどちらかに決めません。**凶が当たっていないという事実**を出すだけで、それを許容するかは利用者が決めます。

期限のある引越しでは、吉方位が空くのを待てないことがよくあります。その場合の考え方は[凶方位しか選べないときにどうするか](/blog/when-you-cannot-avoid-a-bad-direction)にまとめました。

## 現実の条件は別に確認する

方位の判定とは別に、家賃、災害リスク、契約条件、通勤時間、医療・教育環境、家族の合意を確認する必要があります。

九星気学は伝統的な占術上の考え方であり、効果が科学的に確認されたものではありません。Cloud Paletteは計算条件を整理する道具で、将来の出来事を保証するものではありません。
