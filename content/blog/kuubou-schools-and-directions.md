## 空亡を計算することと、凶と解釈することは別

**空亡（天中殺）という言葉を見ただけで、その期間は何もできないと決める必要はありません**。どの柱から求めるか、年・月・日のどこまで見るか、行動を控える時期と見るかなど、流派によって扱いが異なります。ここでは、Cloud Paletteの干支表示で使う日柱由来の二支と、参考動画で紹介される見方を説明します。すべての流派の対応表ではありません。

## 六十干支の6つの旬から空亡二支はどう決まるのか

[六十干支](/blog/sixty-kanshi-and-history)を甲から癸までの10日ずつに区切ると、それぞれの組には十二支のうち二支が入りません。例えば甲子から癸酉までの組では、戌と亥が含まれません。この組に属する日柱について、当サイトの計算は戌亥を空亡として返します。

六十干支（番号0〜59）を6つの旬に分けた一覧と、旬の始まりの干支・終わりの干支・空亡二支は次のとおりです。

| 旬の名称 | 干支番号 | 旬の始まりの干支 | 旬の終わりの干支 | 空亡二支 |
| -------- | -------- | ---------------- | ---------------- | -------- |
| 甲子旬   | 0〜9     | 甲子（0）        | 癸酉（9）        | 戌・亥   |
| 甲戌旬   | 10〜19   | 甲戌（10）       | 癸未（19）       | 申・酉   |
| 甲申旬   | 20〜29   | 甲申（20）       | 癸巳（29）       | 午・未   |
| 甲午旬   | 30〜39   | 甲午（30）       | 癸卯（39）       | 辰・巳   |
| 甲辰旬   | 40〜49   | 甲辰（40）       | 癸丑（49）       | 寅・卯   |
| 甲寅旬   | 50〜59   | 甲寅（50）       | 癸亥（59）       | 子・丑   |

これは**干支の組み合わせから二支を求める規則**です。その人が不幸になるという観測結果ではありません。[本命星の早見](/houi)の生年月日入力欄や、[MCP](/mcp)で公開している干支の道具は日柱から二支を返し、出生時刻がある場合も日の切り替えはJSTの0時とします。23時で翌日とする扱いや出生地による真太陽時補正は、このツールには採用していません。

## 生まれ日の干支から空亡二支はどう求めるのか

生年月日から日柱の干支と空亡二支を求める計算は、基準日の甲子（2000年1月7日・番号0）からの日数差を60で割った余り（0〜59の干支番号）を出し、10で割った商（0〜5の旬番号）を上の表に当てる4手順で行います。

1. **基準日（2000年1月7日＝甲子・番号0）からの日数差を出す**：JSTの暦日で生年月日と2000年1月7日の差を計算します（過去日は負の数）。
2. **日数差を60で割った余りから日柱の干支番号（0〜59）を出す**：負の余りには60を足して0〜59に揃えます。番号を10で割った余りが十干（0＝甲〜9＝癸）、12で割った余りが十二支（0＝子〜11＝亥）です。
3. **干支番号を10で割った商（切り捨て）から旬と空亡二支を決める**：商0は戌・亥、1は申・酉、2は午・未、3は辰・巳、4は寅・卯、5は子・丑です。
4. **節入り当日は年柱・月柱・本命星の境界を別に確認する**：日柱はJST0時区切りですが、年柱と本命星は立春、月柱は各月の節入りの瞬間で切り替わります。

サイトの実装で計算した具体例は次の2つです。

- **例1：1988年8月18日生まれ**：2000年1月7日からの差は−4,159日（−70×60＋41）で干支番号は**41**。10で割った余り1（乙）と12で割った余り5（巳）から日柱は**乙巳**、10で割った商4（甲辰旬）から空亡二支は**寅・卯**です（年柱は戊辰、月柱は庚申、古典の本命星は三碧木星）。
- **例2：1985年2月4日生まれ（立春当日）**：差−5,450日を60で割った余りは**10**で日柱は**甲戌**、商1（甲戌旬）から日柱の空亡二支は**申・酉**です。日柱は同日内なら時刻によらず甲戌ですが、立春時刻（サイトの計算値で6時12分ごろ、JST）の前後で年柱・月柱・本命星が分かれるため、[本命星の早見](/houi)は時刻が分からないとき立春前（年柱甲子・月柱丁丑・七赤金星）と立春後（年柱乙丑・月柱戊寅・六白金星）の両候補を併記します。

## 空亡の評価はなぜ流派によって分かれるのか

六十干支から余る二支を取り出す手順は共通でも、**どの柱から空亡を引くか**と**余った二支の期間をどう意味づけるか**が体系や流派ごとに異なるため、同じ生年月日でも異なる評価が出ます。

| 分かれる観点   | 流派による違い                                                                               | Cloud Paletteでの扱い                                                                                 |
| -------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 基準にする柱   | 日柱から出す主流のほか、年柱から出す年空亡や四柱相互で見る立場がある                         | 日柱由来の二支を表示（[本命星の早見](/houi)・[天中殺の時期確認](/houi/tenchusatsu)・MCPの干支の道具） |
| 見る時間単位   | 年（12年に2年）・月（12か月に2か月）・日（12日に2日）のどこまで見るか                        | 「天中殺の扱い」5段階（厳格／年天中殺は除く／日のみ／弱める／使わない）                               |
| 期間の意味づけ | 作用が弱まる（四柱推命の古典）、新規の始動を慎む（算命学）、転換・挑戦期と読む立場に分かれる | 初期設定は「弱める（禁止しない）」。出来事の予言はしない                                              |
| 方位への適用   | 時期としてのみ扱う立場と、二支の方角を「空亡方位」として避ける立場がある                     | 観点切り替えで九星のみの判定と天中殺を含む総合判定を分離                                              |

たとえば例2（1985年2月4日生まれ・日柱甲戌）は、日柱基準なら「申・酉」ですが、年柱（甲子または乙丑、どちらも甲子旬）から年空亡をとる流派では「戌・亥」になります。呼び名や大殺界との違いは[天中殺と大殺界の違いは何か](/blog/tenchusatsu-names-and-schools)に整理しています。

## 五黄殺・暗剣殺はどう決まり、空亡と何が違うのか

**空亡は四柱推命などで扱う干支の体系で、当サイトの九星気学の方位凶殺とは別体系です**。「空亡を挑戦の時期と見る」という見解から、「暗剣殺や五黄殺の方位へ移動しても吉になる」とは導けません。

九星気学の五黄殺と暗剣殺は、干支の余りではなく、九星盤（年盤・月盤・日盤）の中宮に入った星から定まる**五黄土星の位置**と、その正反対にあたる**対冲**の方位で決まります。中宮の星（1〜9）ごとの五黄殺・暗剣殺と、年盤（2026〜2034年）・月盤（2026〜2027年の節月）の対応は次のとおりです。

| 盤の中宮 | 五黄の位置（五黄殺） | 五黄の対冲（暗剣殺） | 年盤（立春区切り） | 月盤（2026〜2027年の節月）       |
| -------- | -------------------- | -------------------- | ------------------ | -------------------------------- |
| 一白水星 | 南                   | 北                   | 2026年             | 2026年9月節・2027年6月節         |
| 九紫火星 | 北                   | 南                   | 2027年             | 2026年10月節・2027年7月節        |
| 八白土星 | 南西                 | 北東                 | 2028年             | 2026年2月節・11月節・2027年8月節 |
| 七赤金星 | 東                   | 西                   | 2029年             | 2026年3月節・12月節・2027年9月節 |
| 六白金星 | 南東                 | 北西                 | 2030年             | 2026年4月節・2027年1月節・10月節 |
| 五黄土星 | なし（中宮）         | なし                 | 2031年             | 2026年5月節・2027年2月節・11月節 |
| 四緑木星 | 北西                 | 南東                 | 2032年             | 2026年6月節・2027年3月節・12月節 |
| 三碧木星 | 西                   | 東                   | 2033年             | 2026年7月節・2027年4月節         |
| 二黒土星 | 北東                 | 南西                 | 2034年             | 2026年8月節・2027年5月節         |

このサイトの方位判定は、**暗剣殺・五黄殺を誰にとっても凶**として扱います（[五黄殺と暗剣殺とはどの方位か](/blog/five-yellow-and-anken-satsu)）。これはサイトの方位判定上の方針で、現実の被害を断定する言葉ではありません。空亡について別の流派の見解を紹介しても、この方位凶殺の扱いは変わりません。

サイトの総合判定には天中殺を重ねる設定もあります。天中殺をどの範囲で考慮するかと、五黄殺・暗剣殺がその盤にあるかは別の条件です。[天中殺と吉方位](/blog/tenchusatsu-and-lucky-directions)と[方位判定に天中殺は必要か](/blog/houi-and-tenchusatsu)もあわせて確認してください。

## 引越しの判定に、空亡を混ぜない

空亡の二支は、十干が一周するあいだに十二支が二つ余る、という暦の余りです。甲子から癸酉までの組に戌と亥が無い、という上の例は、その余りを日柱に当てたものです。余りがあることと、その二日に引っ越してはならないことは、別の文です。

方位の凶は別の表です。暗剣殺と五黄殺は、空亡がどの支でも、本命星がどれでも、凶として外します。動画が空亡を挑戦の時期と読んでいても、その読みで暗剣殺の方位が吉に変わることはありません。サイトの総合判定で天中殺を重ねる設定を入れても、五黄殺と暗剣殺がその盤にあるかどうかは、空亡とは別に決まります。

順番としては、先に方位の頁で年盤と、動く月の月盤を見ます。空亡を見るなら、そのあとで「いつ」の側の注記として置きます。空亡の期間に方位の答えを書き換えない、というのが、二つの体系を混ぜないときの手順です。

出発地も別に置きます。同じ吉方位でも、海や山でその方角に街が無い県と、平野が続く県では、選べる市区町村の数が違います。空亡の二支は全国共通の暦の余りで、その土地の形では変わりません。土地の側は市区町村の頁、暦の余りは空亡の計算、方位の凶は暗剣殺と五黄殺、と三つを一つの結論に畳まないでください。

サイトの各道具で分かる範囲も分かれています。[本命星の早見](/houi)では本命星・年盤と月盤の吉凶・年月日の干支と日柱の空亡二支が、[天中殺の時期確認](/houi/tenchusatsu)では今後36節月の天中殺月が、[占いの観点を日付と方位で比べる](/houi/fortune-compare)では九星・天中殺・干支・暦注の並列比較が、[方位で街を探す](/relocation/arbitrage)・[引越し時期を分析する](/relocation/timing)では真北基準の八方位と「天中殺の扱い」5段階の切り替えが分かります。一方、どの流派の解釈が唯一正しいかや、引越し後の出来事はどの道具でも決められません。

## 結果を見るときに確認すること

- どの柱から空亡を求めているか。[本命星の早見](/houi)とMCPの干支の道具は日柱から求めます。
- 年・月・日の切り替えと時刻帯は何か。このサイトの干支表示は立春・節入り・JST0時が基準です（節気時刻は太陽黄経の計算値で公式暦と数分の差が出る場合があり、方位判定は真北基準です）。
- 計算結果と、その流派による吉凶の解釈が分けて書かれているか。九星気学・四柱推命・算命学は伝統的な占術上の考え方で、効果は科学的に確認されていません。

[丙午と出生数](/blog/what-is-hinoeuma)にも通じますが、暦の名前だけで人の性格や将来を決めつけないことが大切です。引越しと天中殺の期間を扱った[天中殺に引っ越ししても大丈夫か](/blog/moving-during-tenchusatsu)と、[天中殺という言葉の来歴](/blog/tenchusatsu-origin-and-what-not-to-do)も確認してください。[本命星の早見](/houi)や[暦](/calendar)は、条件を確認するために使ってください。
