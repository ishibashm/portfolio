## 人数が具体的でも、予測が確かとは限らない

**転機の前に必ず3人が現れるという説明は、暦の計算で確かめられる法則ではありません**。[参考動画](https://youtu.be/Y7sICU27lec)は、認めてくれる人、生き方の変更を促す人、背中を押す人という役割を挙げています。この説明は**動画内の見解**で、出現する人数や時期について検証できる集計は提示されていません。

ここで扱うテーマは、人生が何年周期で変わるかではなく、人との出会いを予兆として読むときに何を確認するかです。周期の話は既存の[干支併臨の60年と30年](/blog/numbers-in-kanshi-heirin)で整理しています。3人を探し当てることを、新しい仕事や引越しの開始条件にする必要はありません。

## 三つの役割と三人の人数を分ける

動画の説明を役割として読むと、これまでの行動を認める言葉、新しい方法の提案、実行への後押しという違いがあります。ただし、一人が三つの役割を果たすことも、同じ役割を複数の人が果たすことも考えられます。「役割が三つ」という整理だけでは「必ず三人」という人数は導けません。

動画内の振り返りでも、二人は思い当たるが残りの一人はすぐには分からないというやり取りがあります。これは人数の法則が確認された証拠としては扱えません。該当する人が足りなければ探し続け、思い当たれば的中とする方法では、説明が外れた場合を判定できなくなるからです。

一方で、誰の助言が役に立ったのかを書き出すことはできます。その際は「運命の人物だった」と結論づける前に、実際の提案内容と自分がした行動を残します。感謝と、予測の検証は別々に扱えます。

## 数字の評価

(a)は暦の計算で確かめられる事実、(b)は統計等で確認できた事実、(c)は動画の解釈・経験則で根拠未提示の数字です。例示の年齢も、視聴者全員の予定表にはできません。

| 動画に出る数字                     | 分類と計算・確認方法                                                                | 確からしさ                                               |
| ---------------------------------- | ----------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 3人・3つのサイン                   | (c) 役割の分類と人数の予測。対象者数と出現率は未提示                                | 三つの役割が必ず別々の三人になる根拠は確認できない       |
| 1年半〜2年前                       | (c) 出会いが始まる期間。18〜24か月への換算は可能                                    | 転機の判定日や観察開始日がなく、予測精度は算出不能       |
| 30年ごと、15・45・75歳、一生に3回  | (c) 転機の周期と例。45−15＝30、75−45＝30                                            | 差の計算は正しいが、その年齢に出来事が起きる証拠ではない |
| 25歳・35歳、50歳前後、あと5年      | (c) 人によって時期が違うという例・体験談                                            | 個別の計算条件が不足し、読者の転機の算出には使えない     |
| 47歳から44〜45歳を振り返る2〜3年前 | (c) 体験談。47−45＝2、47−44＝3                                                      | 年齢差は整合するが、誕生日や出来事の日付は未確認         |
| 思い当たる2人と残り1人             | (c) 会話中の自己申告。2＋1＝3                                                       | 3人すべての出現を確認した観察記録ではない                |
| 小学校の6年間、20歳の成人式の例    | 制度や開催条件の確認が必要な数字。動画の比喩として扱い、(b)の制度解説には採用しない | 個人の転機の回数や年齢を決める資料にはならない           |

この動画の予兆について、(a)の暦による保証や(b)の確認済み出現率はありません。引き算や月数への換算ができることと、人生の出来事を予測できることを区別します。

## 後から合わせる前に、記録の条件を決める

たとえば仕事を変えるか考えているなら、相談した日、相手から実際に提案されたこと、自分がどう受け取ったかを別欄に書けます。後で内容を書き換えず、続きの出来事を追記する形にすると、当初の期待と結果を区別しやすくなります。

| 記録する欄       | 書く内容の例                                         |
| ---------------- | ---------------------------------------------------- |
| 出会いの事実     | 日付、初対面か以前からの知人か、相談した経緯         |
| 言葉と受け止め方 | 実際の提案を短く記録し、自分の解釈を別に書く         |
| 行動             | 何を調べ、何を試し、何を保留したか                   |
| 結果             | 自分で決めた確認日に、変わった点と変わらない点を残す |

これはこの記事が提案する記録方法で、動画の鑑定手順ではありません。三人という数に合わせるために、普段の知人を急な出会いとして数え直すことは避けます。仕事の内容や環境が変わらなかった場合も残しておくと、印象的な一致だけを拾う読み方から離れられます。

記録をつけても、助言が原因で転機が起きたことまで直ちに証明できるわけではありません。ただ、提案を受けて実行したことが分かれば、次の相談で具体的な条件を話せます。「最後の一人が現れないから動けない」という待ち方より、確認すべき条件を自分で決められます。

## 出会いの意味と移動の条件

四柱推命と九星気学は別体系です。Cloud Paletteの方位判定は真北が基準で、暗剣殺・五黄殺は誰にとっても凶として扱います。背中を押してくれた人がいたことを理由に、凶方位の扱いを変更しません。

相談が引越しにつながるなら、日取りや住居の条件を具体的に比較します。[引越しの日取りで見る順序](/blog/what-is-hidori-for-moving)も確認し、出会いの人数と契約・移動の判断を切り分けてください。
