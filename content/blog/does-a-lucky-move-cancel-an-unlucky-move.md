## 先に結論

このサイトの判定では、**75日後の吉方位への移動が、最初の凶方位への移動を遡って相殺するとは判定しません**。

75日という条件が変えるのは、**次の移動をどこから測るか**です。最初の移動の吉凶判定を削除したり、後の吉判定と足し引きしたりする処理ではありません。

「凶作用が相殺されるか」は流派によって見解が分かれる解釈の領域です。このサイトではそこを断定せず、各移動の起点・方位・時期を分けて表示します。

## 75日で起点が移る計算規則と日数表

Cloud Paletteの[引越し先を試算する](/relocation/simulator)では、移動先が次の移動の起点（太極）になるかどうかを2つの条件で判定しています。

1. **目的区分が「長期移住」であること**。短期旅行は何日滞在しても起点を動かしません
2. **次の移動日までの滞在日数が75日以上であること**。出発日の差が75日以上なら移動先が新しい起点になり、74日以下なら元の起点のままです

月の日数は28・30・31日と異なるため、「約2か月半」の目算では74日と75日の境目がずれます。2027年（平年）の主な移動日について、実装どおりに暦日の差を計算すると次のとおりです。

| 1回目の移動日 | 74日後（起点はA） | 75日後（起点はBへ） | 90日後（追加初期値） |
| ------------- | ----------------- | ------------------- | -------------------- |
| 2027-02-01    | 2027-04-16        | **2027-04-17**      | 2027-05-02           |
| 2027-03-01    | 2027-05-14        | **2027-05-15**      | 2027-05-30           |
| 2027-04-01    | 2027-06-14        | **2027-06-15**      | 2027-06-30           |
| 2027-05-01    | 2027-07-14        | **2027-07-15**      | 2027-07-30           |
| 2027-07-01    | 2027-09-13        | **2027-09-14**      | 2027-09-29           |
| 2027-10-01    | 2027-12-14        | **2027-12-15**      | 2027-12-30           |

2027年4月1日にAからBへ移った場合、6月14日に次へ動くと74日間で1日足りず、6月15日以降の移動からBが新しい起点になります。契約日・搬入日・寝泊まり開始日の扱いは[引越しの吉凶は、どの日で決まるのか](/blog/which-day-counts-as-moving-day)で整理しています。

## AからB、75日後にBからCへ移る場合

次のような移動を考えます。

1. A（元の住まい）からBへ移る。Aから見たBは凶方位
2. Bに75日以上住む
3. BからCへ移る。Bから見たCは吉方位

Cloud Paletteの扱いは次のとおりです。

| 移動  | 計測する起点 | 判定                           |
| ----- | ------------ | ------------------------------ |
| A → B | A            | Aから見たBの方位と移動日で判定 |
| B → C | B            | Bから見たCの方位と移動日で判定 |

Bに75日以上滞在したため、2回目の起点はBになります。しかし、1回目の「AからBへ凶方位で移った」という記録はそのまま残ります。後の吉を前の凶と足し引きしない理由は[凶方位への移動を、吉が上回ることはできるのか](/blog/can-good-outweigh-a-bad-move)でも層ごとの独立性とあわせて説明しています。

2027年4月1日にAからBへ動いたとして、滞在日数や目的区分を変えた場合の起点は次のとおりです。

| ケース               | 1回目（A→B）の条件    | 2回目の移動日（滞在） | 2回目（B→C）の起点 | 3回目（C→D）の起点                      |
| -------------------- | --------------------- | --------------------- | ------------------ | --------------------------------------- |
| ① 75日以上・長期移住 | 2027-04-01 / 長期移住 | 2027-06-15（75日）    | **B**（新拠点）    | Cが75日以上ならC、未満なら**B**         |
| ② 75日未満・長期移住 | 2027-04-01 / 長期移住 | 2027-06-14（74日）    | **A**（元拠点）    | Cが75日以上ならC、未満なら**A**         |
| ③ 75日以上・短期旅行 | 2027-04-01 / 短期旅行 | 2027-06-30（90日）    | **A**（起点不動）  | Cが長期移住75日以上ならC、未満なら**A** |

ケース①で2027年6月15日にBからCへ移り、40日後の7月25日にCからDへ動いた場合、Cの滞在は40日間（75日未満）なので、3回目（C→D）の起点は**B**から測ります。

## 起点が変われば、元の家から見た方位も変わるのか

ここは混同しやすいところです。

BからCへの移動が吉方位でも、AからCを見た方位は、まだAからBと同じ方位の扇形に入っていることがあります。2回目の移動距離が短ければ、地図上では横へ少しずれただけで、元の起点Aから見た方向はほとんど変わらないためです。元の家から見た方位が動かないときの読み方は[「元の家から見ると、今も同じ凶方位のまま」をどう解釈するか](/blog/direction-seen-from-the-original-home)に分けて書きました。

Aを京都市下京区（北緯34.9858度・東経135.7588度）、Bを名古屋市中区（北緯35.1815度・東経136.9064度）、Cを愛知県刈谷市（北緯34.9893度・東経137.0021度）として、真北基準の方位角と伝統区分の八方位（四正30度・四隅60度）を計算すると次のようになります。

| 区間                   | 方位角  | 直線距離 | 八方位（範囲）         | 使われる条件                                   |
| ---------------------- | ------- | -------- | ---------------------- | ---------------------------------------------- |
| A（京都）→ B（名古屋） | 77.9度  | 106.7km  | **東**（75〜105度）    | 1回目の移動の判定                              |
| B（名古屋）→ C（刈谷） | 157.8度 | 23.1km   | **南東**（105〜165度） | Bに長期移住で**75日以上**滞在後の2回目         |
| A（京都）→ C（刈谷）   | 89.4度  | 113.3km  | **東**（75〜105度）    | Bが**75日未満**の2回目、およびAから見たCの方角 |

つまり、Bに75日以上住んでからCへ移った場合、同時に次の2つが成立します。

- 2回目は、新しい起点Bから見て吉方位（Bから南東・157.8度）
- 現在地Cは、元の起点Aから見ると最初と同じ方位（Aから東・89.4度）

逆に、Bの滞在が74日以下でCへ動いた場合は起点が移らないため、2回目自体がAから見た**東**（89.4度）として判定されます。これは占術上の解釈ではなく、位置関係として確認できる事実です。[引越し先を試算する](/relocation/simulator)では、各段階をその時点の有効な起点から計算します。距離と角度の関係は[引越しの距離は方位の吉凶にどれくらい関係するのか](/blog/how-much-does-distance-matter)も参照してください。

## 仮吉方・方違えとは同じ話？

仮住まいを挟んで移動の起点を変える方法は、「仮吉方」「方違え」などと呼ばれます。ただし、考え方の中心は**最初から経由地を含めて移動を組み立てること**です。

「いったん凶方位へ移り、あとからどこかの吉方位へ移れば自動的に帳消しになる」という意味ではありません。たとえば京都市下京区から名古屋市中区（東・77.9度）が凶方位の年に、最初から経由地に福井県敦賀市周辺（方位角20.0度・**北東**・78.1km）を選び、75日以上の滞在後に敦賀市周辺から名古屋市中区（方位角123.5度・**南東**・92.8km）へ移るのが迂回（仮吉方）です。この場合は1回目も2回目も凶方位を避けています。

少なくとも、次を別々に確認する必要があります。

- Aから仮住まいBへの移動
- Bで起点が移るだけの滞在が成立しているか
- Bから最終地点Cへの移動
- それぞれの移動日が、採用する判定規則に合うか
- 元の家へ戻って宿泊するなど、滞在の連続性をどう扱う流派か

75日という日数自体にも、45日・60日・75日・90日など異なる説があります。位置の太極と家の太極を分ける説や、外泊で日数の数え直しになるとする説もあります。たとえば、75日以上連続して滞在し、戻る移動も改めて判定する立場があります。[応用九星気学・現代風水研究所の解説](https://www.take-hope.com/kyusei/contents/016.html)はその一例です。これは公的・科学的な基準ではなく、一流派の説明として参照してください。

## Cloud Paletteで確認できること

[引越し先を試算する](/relocation/simulator)では、複数段階の移動を登録できます。

- 滞在が75日未満なら、次の移動も以前の起点から測る
- 長期移住として75日以上滞在したら、その場所を次の起点にする
- 各移動について、方位と時期の判定を個別に表示する

75日未満の移動では「滞在が75日未満のため、この移動後の拠点（太極）は元の場所のまま動きません」と表示され、次も元の拠点から計算されます。Bに75日以上住んで次の移動日を探す場合は、Bを出発地にして[引越し時期を分析する](/relocation/timing)や[引越しの日取りを選ぶ](/calendar)で吉日を一覧でき、年盤・月盤は[本命星と吉方位を調べる](/houi)で確認できます。

画面は計算上の関係を整理する道具です。「相殺されたから安全」「凶作用が必ず起こる」といった出来事の予測は行いません。

## 判断するときのチェックリスト

1. **各移動を一本ずつ分ける**。「A→B」と「B→C」を混ぜず、別の移動として書き出します
2. **それぞれの出発地と到着地を確認する**。5km未満では方位がぶれやすいため、距離と方位角を地図で確かめます
3. **滞在日数から、次の計測起点を確認する**。長期移住で75日以上なら移動先が次の起点になり、74日以下や短期旅行では前の起点が残ります
4. **方位だけでなく移動日も確認する**。年盤・月盤・日盤のどの層が吉または凶かを段階ごとに見ます
5. **元の起点から見た最終地点の方向も地図で確認する**。必要ならA基準とB基準の両方で凶にならない候補を探します
6. **採用する流派の規則を決め、途中で混ぜない**。太極が移る日数や元の家の方角を見るかを先に決めます

九星気学や仮吉方は伝統的な占術上の考え方であり、効果が科学的に確認されたものではありません。契約費用、二重家賃、通勤、健康、家族の都合など、現実の条件を優先したうえで判断材料の一つとしてお使いください。
