## 相談相手を探す前に、求める応答を言葉にする

**話を聞いてほしいときと、具体的な案を比べたいときでは、相手に求めることが違います**。[参考動画](https://youtu.be/FLNNv-Ykiso)では、落ち込んだときに話を聞く相手と、仕事で助言を受ける相手を五行の関係で分けています。特定の属性に話せば楽になるという説明は、**動画内の見解**です。相談の効果を比較した統計としては扱いません。

動画は女性の人間関係を題材にしていますが、性別や五行から「この人は感情的」「この人は話を聞けない」と個人を判定する根拠は示されていません。本記事では属性別の相談先一覧を作らず、相談する側と受ける側で目的を確認する方法に絞ります。親子や夫婦への伝え方は[五行の相性と会話](/blog/compatibility-and-communication)で別に扱っています。

## 共感と助言を、同じ成功条件にしない

動画には、まず話を聞いてもらい、その後に行動へ進むという順序の説明があります。この順序を全員への処方にはしませんが、相談の途中で目的が変わることを確認する問いにはできます。「今日は解決案より、何があったか聞いてほしい」「最後に選択肢を一緒に比べてほしい」と伝える例です。これは記事独自の整理です。

相手が具体策を出したのに満足できなかった場合も、直ちに相性が悪い証拠にはなりません。そもそも助言を求めていたのか、事情を説明する時間が足りたのか、提案を実行できる条件がそろっていたのかを分けて振り返れます。逆に、聞いてもらって安心したことと、提案が実行可能であることも別です。

相談内容を詳しく話す前には、相手に時間があるか、何を話してよいかも確認します。動画の五行の関係を知ったから、本人の希望を聞かずに私的な話をしてよいという結論にはなりません。「何でも話せる」という印象と、実際に受け止められる範囲は別に確かめたい点です。

## 数字の評価

(a)は暦の計算で確かめられる事実、(b)は統計等で確認できる事実、(c)は動画の解釈・経験則で根拠未提示のものです。分類図の数え方は確認できますが、図の距離は相談効果の測定値ではありません。

| 動画に出る数字             | 分類と計算・確認方法                    | 確からしさ                                                     |
| -------------------------- | --------------------------------------- | -------------------------------------------------------------- |
| 木火土金水の5分類          | 分類の定義。相談相手との対応は(c)       | 5項目と数えることはできるが、5種類の心理を実証した意味ではない |
| 隣同士、1個飛ばし          | 図の配置の数え方。向きと相性の評価は(c) | 間の項目を一つ飛ばすという意味で、相談の成功確率ではない       |
| 自分を0地点へ戻す          | (c) 気持ちを立て直す比喩                | 測定尺度・単位・基準値がなく、心理状態の実測ではない           |
| 1回試す、もう1回仕切り直す | (c) 行動を促す表現                      | 1回の経験から全員への効果や再現率は求められない                |
| 1人の相手をめぐる例        | (c) 関係を説明する例                    | 調査人数や母集団を示す数字ではない                             |

この動画から(a)の暦日・周期の検算に相当する数字や、(b)の確認済みの相談効果は得られません。字幕にある「ほとんど」「多い」という表現にも、対象人数や比較群がありません。女性一般、あるいは特定の五行全員の傾向として百分率に置き換えることはできません。図を指す語の対象が不明瞭な箇所も、推測で相談先の表に直しません。

## 相談の記録は、満足の理由を分けて残す

次は記事独自の架空例です。相談を4回行い、3回で「希望した応答が得られた」と本人が記録したなら、3÷4＝75%です。ただし、これはその4回についての本人の評価の割合です。五行の相性が75%当たったという数字ではありません。

| 残す項目       | 記入例                                   |
| -------------- | ---------------------------------------- |
| 話す前の希望   | 事情を最後まで聞いてほしい               |
| 相手との合意   | 今日は話を聞き、案の比較は別の機会にする |
| 実際の応答     | 最後まで聞いたあと、確認の質問があった   |
| 話した後の評価 | 希望に合った。まだ判断は決めていない     |

同じ人との4回なのか、別々の4人なのかでも記録の意味は違います。話題や時間が違えば、属性だけを原因として比較できません。また、回答のない回を除いて都合のよい割合だけを出すと、何を数えたのか分からなくなります。未評価の回は未評価として残すのが、この記録例の前提です。

次の相談で目的を変える場合は、前の記録を修正するのではなく、新しい希望を書きます。聞いてもらった後に案を求めたくなったなら、その変化自体を記録できます。「相性がよいから何も言わなくても伝わる」と期待するより、何を頼んだかが残る形です。ただし、この方法自体の改善効果を実験で確認した記事ではありません。

## 方位の判定には持ち込まない

相談相手への安心感を、移動先の吉凶へ読み替えることはしません。四柱推命と九星気学は別体系です。Cloud Paletteは真北で方位を判定し、暗剣殺・五黄殺は誰にとっても凶として扱います。相談して気持ちが楽になったことも、その方位の凶が解除された証拠にはなりません。分類で決められる範囲と実際の経験を分けて読むことが、この動画を生活の問いへ取り入れる際の前提です。
