## 陽と陰を能力の順位にしない

**十干の陽と陰は、人物の優劣を示す点数ではありません**。[参考動画](https://youtu.be/gXnkY9IOD5U)では、陽を号令する側、陰を実際につかむ側にたとえ、陰を弱いものと見る理解を外すよう説明しています。この役割づけは**動画内の見解**です。

「陽だからリーダーに向く」「陰だから補助に回る」といった職務の割り当てまで、十干の分類から確定するわけではありません。この記事では、暦の符号として確認できる対応と、人の働き方に重ねた比喩を分けます。

## 五行を二つずつに分けた十干

十干は甲・乙・丙・丁・戊・己・庚・辛・壬・癸の十個です。五行との対応や日本式の読み方は、[国立天文台の六十干支の解説](https://eco.mtk.nao.ac.jp/koyomi/faq/60kansi.html)で確認できます。

| 五行 | 陽の干         | 陰の干         |
| ---- | -------------- | -------------- |
| 木   | 甲（きのえ）   | 乙（きのと）   |
| 火   | 丙（ひのえ）   | 丁（ひのと）   |
| 土   | 戊（つちのえ） | 己（つちのと） |
| 金   | 庚（かのえ）   | 辛（かのと）   |
| 水   | 壬（みずのえ） | 癸（みずのと） |

この対応表は伝統的な分類の説明です。「甲の人が実際にどんな行動をするか」という予測の証拠ではありません。十干と十二支から六十干支を作る仕組みは、[干支は60種類](/blog/sixty-kanshi-and-history)で説明しています。

## 甲乙・丙丁・戊己はどうたとえられているか

参考動画が中心に扱うのは、十干のうち甲・乙・丙・丁・戊・己です。以下の人物像はすべて**動画内の見解**であり、各干の人に必ず当てはまる性格ではありません。

甲では、兜のように威厳を見せることが語られます。一方、乙では、草花や蔦のイメージから、小さな工夫で人の心をつかみ、周囲との関わりの中で育つ姿が示されます。同じ木でも、目立ち方や関わり方を変えて説明しているわけです。

丙は太陽のように暗いところを照らす働き、丁は灯火のように人の暮らしや心を照らし続ける働きに重ねられています。ここでの大きさの違いを、そのまま仕事の価値の大小と読む必要はありません。

戊は山や大地、己は畑にたとえられます。動画は戊に腰を据える姿勢を、己に何を育てたいかを明確にする姿勢を勧めています。ただし「山は動かない」という比喩を、人が転職や引越しをしてはいけないという禁止へ広げることはできません。移動したら災いが起こるという因果関係も、この記事では事実として扱いません。

## 覚える比喩と、人を評価する根拠を分ける

自然物のイメージは、慣れない漢字の違いを覚える助けとして使えます。しかし、比喩から思いついた人物像を、相手の実際の言動より優先すると、分類に合わない面を見落としてしまいます。

たとえば「畑」という言葉から育成を連想したなら、育てたいものや必要な支援を書き出すことはできます。それは比喩をきっかけにした自分の整理であり、生年月日がその仕事への適性を証明したことにはなりません。仕事の役割を考える使い方は、[五行で語られる仕事の役割](/blog/five-elements-and-work-roles)も参考になります。

四柱推命の十干の人物像と、九星気学の方位判定は別体系です。Cloud Paletteは真北で方位を判定し、暗剣殺・五黄殺を誰にとっても凶として扱います。陰陽や自然物の比喩によって、その規則を変更するものではありません。

## 数字の評価

(a)は暦の分類・計算で確認できる数字、(b)は統計等で確認できた事実、(c)は動画の解釈・経験則で根拠未提示の数字です。表の分類が正しいことを、人物像の正しさへ広げないようにします。

| 動画に出る数字                  | 分類と計算・確認方法                                                      | 確からしさ                                                          |
| ------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 五行の5、陰陽の2、十干の10      | (a) 対応表の5行をそれぞれ2つに分け、5×2＝10                               | 分類の個数として確認できる                                          |
| 物事はすべて2つの組だという説明 | (c) 陰陽を伝える世界観。反例の扱いや対象範囲は未提示                      | 5×2の計算から、世の中の全事象には一般化できない                     |
| 2024年                          | (a) 立春以後の節年では(2024−4) mod 60＝40。甲子を0とすると甲辰            | 年干が甲であることは確認できる。土の経営者が活躍するという部分は(c) |
| 社員が3000人ほどという例        | (c) 個人の事例としての言及。会社・集計時点・人数の範囲を照合できない      | 土の陰の干と組織規模の関係は未検証                                  |
| 冒頭の3000年                    | 歴史の起点と史料が必要だが、動画では算定根拠を確認できず(b)には採用しない | 十干による人物評価の精度を示す数字ではない                          |
| 1本を多数作るという説明         | (c) アイデアを展開する比喩。生産数や売上の予測値ではない                  | 数量的な効果は評価できない                                          |

年干支の計算例はCloud Paletteの暦ロジックと同じ剰余を使っています。1月1日から立春までを無条件に甲辰とする計算ではありません。暦の区切りを確かめたい場合は[出生データと解釈を分ける確認手順](/blog/birth-data-before-interpretation)を参照してください。

この動画で確認できるのは分類と比喩の説明で、統計で裏づけられた(b)の職務適性や成功率は確認していません。社員数の大きい会社を紹介できても、同じ干で小さい会社や事業をやめた人を含めなければ、分類と成果の関係を測れません。数字が大きい事例ほど、人数の事実確認と、その原因を十干に求める解釈を切り分ける必要があります。
