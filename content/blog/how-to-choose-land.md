## 先に結論

- 土地の値段は**感覚では読めません**。全国の「土地のみ」の成約 45 万件で、㎡単価の中央値は**約 5.7 万円**。ただし都道府県で桁が変わります
- 都市部の住宅購入は、実態として**ほぼ土地の買い物**です。土地と建物を一括で買った成約のうち、価格に占める建物代の割合は、中央値で**東京都 17%**・大阪府 29%。秋田県では 48% とほぼ半々になります
- 同じ広さで値段が違う理由の大半は、**用途地域**（そこに何が建てられるか）と**接道**（道路にどう接しているか）で説明できます。どちらも公的に定められていて、自分で確かめられます
- 値段の基準は 2 つあります。**地価公示**（国の鑑定による標準地の価格）と**成約価格**（実際に売買が成立した額）。役割が違うので、両方を見ます
- 災害リスクは印象で判断せず、**国のハザードマップ**で確かめます。確認は無料です

この記事は不動産の制度とデータの話です。方位の吉凶には触れません（それはこのサイトの他のページの仕事です）。個別の土地の法的な判定や購入の最終判断は、宅地建物取引士や建築士など資格を持つ専門家に確認してください。ここで書くのは、**専門家に相談する前に自分で確かめられること**です。

## 1. まず「相場の地図」を頭に入れる

国土交通省は、不動産の**成約価格**（売り出し価格ではなく、実際に取引が成立した額）を公開しています。Cloud Palette はこのデータを毎晩集計しています。2026 年 8 月時点の全国の姿はこうです。

| 取引の種類         | 成約件数     | ㎡単価の中央値 |
| ------------------ | ------------ | -------------- |
| 宅地（土地のみ）   | 約 45.0 万件 | 約 5.7 万円    |
| 宅地（土地と建物） | 約 89.7 万件 | 約 16.5 万円   |
| 中古マンション等   | 約 70.9 万件 | 約 45.0 万円   |

ここで大事なのは絶対値ではなく、**順序と桁**です。土地のみ < 土地と建物 < マンション、という順序は「同じ 1 ㎡でも、上に何が載っているか・どこまで使える状態か」で値段が変わることを示しています。更地の 1 ㎡は、建物付きの 1 ㎡より安く、専有部分として完成しているマンションの 1 ㎡より大きく安い。**土地を買うとは、この差額ぶんの仕事（建てる・整える）を自分で引き受けること**です。

平均ではなく中央値を使う理由は[家賃相場の記事](/blog/how-we-analyze-the-rental-market)と同じです。不動産の価格分布は右に大きく歪んでいて、平均は一部の高額取引に引っ張られます。

## 2. 都市部の住宅購入は「土地の買い物」

土地と建物を一括で買った成約には、価格のうち建物代がいくらだったかの内訳があります。その割合（建物比率）の中央値を都道府県で並べると、はっきりした構造が出ます。

| 都道府県 | 建物比率の中央値 |
| -------- | ---------------- |
| 東京都   | 17%              |
| 京都府   | 25%              |
| 大阪府   | 29%              |
| 愛知県   | 37%              |
| 北海道   | 38%              |
| 島根県   | 46%              |
| 秋田県   | 48%              |

東京で 4,000 万円の中古戸建てを買うと、中央値で見ればそのうち**3,300 万円以上が土地代**です。逆に秋田では価格のほぼ半分が建物代。つまり同じ「家を買う」でも、都市部では土地の見極めが価格のほとんどを決め、地方では建物の状態の見極めが同じくらい効きます。**自分の買い物がどちらの型なのかを先に知る**と、調べる力の配分を間違えません。

この集計は[購入相場の分析](/relocation/purchase)で都道府県ごとに見られます。

## 3. 同じ広さで値段が違う理由 — 用途地域と接道

隣り合った同じ広さの土地で値段が倍違う、ということが実際にあります。理由の多くは 2 つの公的な仕組みで説明できます。

### 用途地域 — そこに何が建てられるか

都市計画法は市街地を 13 種類の**用途地域**に分けています。第一種低層住居専用地域なら高い建物や店舗は建てられず、商業地域なら大きな建物が建てられます。建てられる床面積の上限（容積率）も用途地域で決まるので、**同じ 100 ㎡でも「その上に作れるもの」が違い、それが値段の差になります**。

静かな住宅地が欲しい人にとっては、一種低層の「制限の強さ」はそのまま住環境の保証です。逆に、将来の建て替えで床を増やしたい人には制約になります。どちらが良いかは目的次第で、**値段が高い用途地域が自分にとって良い土地とは限りません**。

用途地域は市区町村が公開しており、Cloud Palette でも[物件検索の地図](/relocation/arbitrage)に用途地域レイヤーを重ねて色で確認できます。

### 接道 — 道路にどう接しているか

建築基準法は、幅 4m 以上の道路に 2m 以上接していない土地には、原則として建物を建てられないと定めています（接道義務）。これを満たさない土地は**再建築不可**と呼ばれ、いま建物が建っていても、建て替えができません。相場より目立って安い土地には、この種の理由があることが多い。

- 前面の道が 4m 未満なら、建て替え時に敷地を後退させる（**セットバック**）ぶん、使える面積が減ります
- 道路に見えても**私道**のことがあり、掘削や通行に他人の承諾が要る場合があります

これらは登記や役所の窓口（建築指導課など）で確認できる事実で、印象や広告の文言ではなく**制度で決まっている**ことです。安さには理由があり、その理由は調べれば分かります。

## 4. 値段の基準は 2 つある — 地価公示と成約価格

土地の値段を調べると、2 種類の数字に出会います。

- **地価公示** — 国が毎年 1 月 1 日時点で、選ばれた標準地について不動産鑑定士の評価で出す価格。地点は限られますが、条件が統一されていて**年ごとの比較に強い**
- **成約価格** — 実際の取引で成立した額。件数は多いものの、個々の事情（急いで売った、隣人が買った）が混ざるので、**1 件ではなく分布で見る**

売り出し価格（広告に出ている額）はこのどちらでもなく、売り主の希望です。相場観を作るなら、地価公示で「基準の地点」を押さえ、成約価格の分布で「実際はどの幅で取引されているか」を見る、という順序が実務的です。[購入相場の分析](/relocation/purchase)では、成約の㎡単価を同じ県の地価公示と並べて出しています。

## 5. 安全は印象ではなく公的情報で

「高台だから安心」「昔からの住宅地だから大丈夫」という印象は、当たることも外れることもあります。確かめる手段は公的に用意されています。

- **重ねるハザードマップ**（国土交通省）— 洪水・土砂・高潮・津波の想定区域を住所で確認できます
- **地盤情報** — 各自治体のボーリングデータや、地形分類（旧河道・埋立地など）が公開されています
- 2020 年から、不動産取引の際に**水害ハザードマップの説明が義務化**されています。説明を受ける前に自分で見ておくと、その場で質問できます

ここで大事なのは、想定区域に入っている＝買ってはいけない、ではないことです。**リスクの種類と程度を知ったうえで、価格や保険と突き合わせて判断する**ための材料です。

## 6. 手順にすると

1. [購入相場の分析](/relocation/purchase)で、その県の㎡単価の分布と建物比率を見て、自分の買い物が「土地型」か「建物型」かを知る
2. 候補地の**用途地域**を確認する（[物件検索の地図](/relocation/arbitrage)のレイヤー、または市区町村の都市計画図）
3. **接道**を確認する。前面道路の幅・接している長さ・公道か私道か。怪しければ役所の建築指導課へ
4. **地価公示**の近い標準地と、周辺の**成約価格**の分布を見て、提示価格がどの位置にあるかを測る
5. **ハザードマップ**で災害の想定を確認する
6. ここまでの材料を持って、宅地建物取引士・建築士に個別の確認を依頼する

方位を気にする方は、この手順で候補を絞ったあとに[方位の判定](/houi)を重ねてください。順序を逆にする（方位で絞ってから制度を確認する）と、再建築不可のような取り返しのつかない見落としが起きやすくなります。**制度とデータの確認が先、方位はそのあと**——これがこのサイトとしての推奨です。

数字は 2026 年 8 月時点の集計で、出典は国土交通省の不動産情報ライブラリ（成約価格情報・地価公示）です。集計は毎晩更新されるため、最新の値は各ツールのページで確認してください。
