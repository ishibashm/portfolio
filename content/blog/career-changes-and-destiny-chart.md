## 残りの転職回数を引き算で決めない

**命式の説明に職業の数が出てきても、それを達成すべき転職回数として扱うことはできません**。[参考動画](https://youtu.be/weNURXURiNI)では、目的に向けて複数の職業を経験する人もいるという話の中で、五つのうち三つを終え、あと二つほど変わるという例が語られます。これは**動画内の見解**で、全員に五つの職業が必要だという意味でも、将来の転職を確認した統計でもありません。

この記事が扱うのは、職業上の経験を何回と数えるかという問題です。五行別の適職や能力の分類は[五行で語られる仕事の役割](/blog/five-elements-and-work-roles)で扱っており、ここでは仕事の変更をどう振り返るかに絞ります。

## 職業数・会社数・転職回数は別々に数える

同じ会社に勤めたまま営業から企画に移れば、勤務先は変わらなくても役割は変わります。会社を変えて同じ仕事を続ける場合は、役割が似ていても勤務先は変わります。副業を同時にしている人なら、職業を時間順に一つずつ経験したとも限りません。

仮に五つの会社へ順に勤めたなら、最初の入社を除いた会社間の移動は四回です。「五社勤務」と「五回転職」は一致しません。さらに、職業を五つ経験することと五社に勤めることの間にも一対一の対応はありません。数字の前に、何を一件として数えるのかを決める必要があります。

動画は、続かないことを一律に悪いと見るのではなく、その人の進む過程として読む立場を示しています。この受け止め方は**動画内の見解**として紹介できますが、仕事をやめるべきか、あと何回変更すべきかは、その説明だけでは決まりません。

## 数字の評価

(a)は暦の計算で確かめられる事実、(b)は統計等で確認できた事実、(c)は動画の解釈・経験則で根拠未提示のものです。この動画の例には、計算の形をしていても前提を確認できない数字があります。

| 動画に出る数字                               | 分類と計算・確認方法                     | 確からしさ                                                      |
| -------------------------------------------- | ---------------------------------------- | --------------------------------------------------------------- |
| 職業の5パターン、経験済み3、残り2            | (c) 説明上の例。5−3＝2という算術は正しい | 必要な総数が5である根拠と数え方がなく、予測の残数としては未検証 |
| 3日で迷う、3日坊主                           | (c) 続けるか迷う様子の例・慣用表現       | 72時間後に判断が変わると測定した結果ではない                    |
| 3歩進み2歩戻るという比喩                     | (c) 試行錯誤を説明する表現               | 行動量や達成率を定量化したものではない                          |
| 現在45歳、人生の3分の1ほどという例           | (c) 人生を地図に見立てる説明             | 年齢と人生の進捗に共通の分母はない。寿命を逆算できない          |
| 1年生から6年生                               | (c) 成長しても本人であり続けるという比喩 | 学年の差を職業変更の必要回数に換算できない                      |
| 対処するか特徴として生かすかという二つの方向 | (c) 助言の整理                           | 現実の選択肢が必ず二つで尽きるとは確認できない                  |

(a)に当たる暦の周期と、(b)に当たる確認済みの転職統計は、この動画の数字からは得られません。算術として検算できる5−3＝2も、暦が定めた残り回数ではありません。最初の5が経験則なら、引き算後の2も将来の事実としては確定しません。

## 自分の経験を数える表を作る

職歴を整理するときは、会社を移った回数だけでなく、実際に担当した仕事を期間ごとに書く方法があります。以下はこの記事独自の記録案で、命式の計算表ではありません。

| 項目             | 確認する内容                                 |
| ---------------- | -------------------------------------------- |
| 勤務先と期間     | 入社・退職や異動を、記録のある年月で確認する |
| 担当した役割     | 同じ肩書きでも変わった作業や責任を書く       |
| 身についたこと   | 自分でできるようになったことを具体例で残す   |
| 続けたい条件     | 時間、場所、人との関わり方、担当範囲を分ける |
| 変更を考える理由 | 次に得たい経験と、今困っていることを分ける   |

たとえば二社に勤め、そのうち一社で三種類の役割を担当した人なら、会社数だけでは経験の幅を表せません。逆に、肩書きを変えても日々の仕事がほぼ同じなら、役割の数だけを増やして説明することにも限界があります。何を数えた数字なのかを横に書くと、職歴を相談する相手にも伝わりやすくなります。

この表を使う目的は、所定の回数へ近づくことではありません。今の環境で試せることと、環境を変えなければ難しいことを区別するためです。新しい業務の担当、学習、異動の相談などで確認できる部分があるなら、その結果を見て次の選択を考えられます。

## 長い期間の説明でも、結果を確認する基準が必要

動画は四柱推命を長い時間軸の地図にたとえます。しかし、期間が長いから正確だとは限りません。変化があれば予測どおり、変化がなければ準備中、とどちらも当たりにできる説明では、精度を確かめにくくなります。仕事の計画には、何をいつ確認するかという自分の基準を持たせてください。

四柱推命と九星気学は別体系です。転職に伴って住まいを変える場合も、命式の職業数から吉方位は計算しません。Cloud Paletteは真北を基準とし、暗剣殺・五黄殺は誰にとっても凶として扱います。仕事の経験と方位の規則を分ける範囲は、[九星気学以外の評価基準](/blog/other-systems-beyond-kigaku)も参照できます。

日々の仕事で同じ失敗が続くと感じる場合は、[10日周期と失敗率の記録方法](/blog/ten-day-cycle-and-mistake-rate)を参照してください。回数に加えて、作業の機会数をそろえる例を扱っています。
