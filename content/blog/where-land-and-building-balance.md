## 先に結論

- 家の総額のうち建物代が占める割合（建物比率）を、直近の成約から市区町村ごとに推計しました。**0.4〜0.6（土地と建物にほぼ半々）をこの記事では「バランス帯」と呼びます**
- **東京都では、バランス帯に入る取引は 3.9% しかありません**。港区の建物比率の中央値は 0.034 — 価格のほぼ全部が土地です。神奈川 9.6%、京都 13.2%、大阪 19.0% と、大都市圏はどこも低い
- 県単位でバランス帯の割合が高いのは**大分（31.5%）・愛知（31.4%）・鹿児島（30.5%）・宮城（29.6%）**。ただし最も高い県でも 3 割。**半々の配分は、実はどこでも少数派**です
- 都市圏の通勤県の中にも、**総額の中央値 1,000 万円前後でバランス帯**の街があります。千葉の外房（茂原・東金・いすみ）、大阪の泉南（阪南・泉南）、奈良の郡部（平群・三郷）、兵庫の播磨（高砂・加古川）など
- 逆の極（建物比率 0.6 超）は土地の市場価値がほぼ残らない街で、**買うときは安いが、売るときは建物の劣化がそのまま資産の劣化**になります

数字はすべて 2021 年以降の成約（国土交通省の不動産情報ライブラリ）を当サイトが集計したもので、2026 年 8 月時点の値です。建物比率は**成約データに含まれる内訳ではなく、当サイトの推計**です（方法は後述）。個別の購入判断は宅地建物取引士など資格を持つ専門家に確認してください。

## 「バランスよく作れる」を数字で定義する

土地と建物を一括で買った成約 1 件ごとに、価格のうち建物代がいくらだったかを推計できます。方法は金融機関の積算評価と同じ考え方です。

- 建物の推定額 = 延床面積 × 構造別の再調達単価（木造 15 万円/㎡、RC 20 万円/㎡ など）× 築年数による残存割合
- 建物比率 = 建物の推定額 ÷ 成約総額（0 = 全部土地代、1 = 全部建物代）

これは**推計であって、取引で開示された内訳ではありません**。それでも数十万件を並べると、市場の構造ははっきり出ます。

建物比率が 0.5 に近い街は、**その土地の値段と、その上に建つ建物の値段が釣り合っている**街です。総額 2,000 万円なら土地に 1,000 万・建物に 1,000 万。新しく建てる場合に引き直すと、土地代に予算を食われて建物を削る（都心型）ことも、建物にしか値が付かず土地が資産にならない（過疎型）こともない、という位置です。

## 県で見る — 半々はどこでも少数派

直近の成約のうち、バランス帯（0.4〜0.6）に入る割合の上位と下位です。

| -------- | ---------------- | ---------------- | ------------ |
| 大分県   | 31.5%            | 0.47             | 2,100 万円   |
| 愛知県   | 31.4%            | 0.36             | 3,200 万円   |
| 鹿児島県 | 30.5%            | 0.49             | 1,600 万円   |
| 宮城県   | 29.6%            | 0.37             | 2,700 万円   |
| …        |                  |                  |              |
| 大阪府   | 19.0%            | 0.29             | 2,500 万円   |
| 京都府   | 13.2%            | 0.24             | 2,500 万円   |
| 神奈川県 | 9.6%             | 0.23             | 4,000 万円   |
| 東京都   | **3.9%**         | **0.16**         | 5,300 万円   |

2 つ読み取れます。ひとつは、**大都市圏ほど配分が土地に傾く**こと。東京の中古戸建て市場では、96% の取引が「半々」から外れていて、そのほとんどが土地側に寄っています。もうひとつは、**最上位の県でも 3 割**しかないこと。バランスの取れた配分は、探さないと出会えない少数派です。

愛知が面白い位置にいます。中央値では土地寄り（0.36）なのに、バランス帯の割合は全国 2 位。名古屋の都心と、半々で買える郊外が県内に同居していて、**県内の選び分けで配分を変えられる**構造です。

共通するのは、**大都市の中心から 1 時間前後の縁**です。千葉なら外房、大阪なら泉南、奈良なら西部の郡部、兵庫なら播磨。中心への近さを一段譲ると、土地の値段が「建物と同じくらい」まで下がる線があり、この表はその線の上にある街です。

注意もあります。この表の中央値は**中古の戸建て市場**の値です。これから新築する場合の土地代の目安には、同じ街の「宅地（土地のみ)」の相場を別に確認してください（[購入相場の分析](/relocation/purchase)で県別に見られます）。また、成約が新しい建売に偏っている街は建物比率が高めに出ます。

## 両極の読み方 — 安さの意味が違う

分布の両端は、リスクの種類を教えてくれます。

**土地の極**（建物比率が低い街）: 港区 0.034・渋谷区 0.051・世田谷区 0.090。港区の総額の中央値は 3.7 億円で、そのうち建物の推計はわずか 3%。ここで家を買うことは、実質的に**土地という資産を買って、その上の建物はおまけ**です。建物にお金を掛けても、売るときの価格にはほとんど反映されません。

**建物の極**（建物比率が高い街）: 岩見沢市 0.83（総額中央値 500 万円）・小樽市 0.73・室蘭市 0.68・大牟田市 0.63。総額は安いのですが、**価格のほとんどが「建物の残存価値」**で、土地には市場価値がほぼ残っていません。建物は年々劣化するので、この構成は**買った瞬間から資産が目減りしていく**構成でもあります。住むための買い物としては合理的でも、資産としては土地の極と正反対の弱さを持ちます。

バランス帯の意味はここで効きます。**土地が資産として残り、かつ建物にも予算を回せる**——両極の弱点をどちらも避けられる帯だから、探す価値があります。

## 使い方

1. [購入相場の分析](/relocation/purchase)で、候補の県の建物比率と㎡単価を見る
2. この記事の表にある街、または同じ条件（中心から 1 時間前後の縁）の街で候補を作る
3. 候補地の用途地域・接道・ハザードを確認する（手順は[土地の選び方](/blog/how-to-choose-land)に書きました）
4. 個別の土地の判定は宅地建物取引士・建築士へ

方位を重ねたい方は、候補が絞れたあとに[方位の判定](/houi)を。制度とデータの確認が先、方位はそのあと、という順序は[前の記事](/blog/how-to-choose-land)と同じです。

## この分析の限界

- 建物比率は積算評価による**推計**です。実際の売り主・買い主の認識とは違うことがあります
- 中古の成約から出した値であり、**新築の見積もりではありません**
- 市区町村の中でも駅前と外れでは配分が大きく違います。中央値は入口として使い、個別の検討は地点ごとに
- 成約件数の少ない街は載せていません（県別は全件、街別は 200 件以上）

数字の出典は国土交通省 不動産情報ライブラリ（成約価格情報）、集計は当サイト（2021 年以降の成約、2026 年 8 月時点）。推計式の詳細と単価表の出典はサイトの公開リポジトリに記載しています。
