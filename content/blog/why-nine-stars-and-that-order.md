## 先に結論

九星気学の数字は、占いのために作られた記号ではありません。もとは**三行三列の魔方陣**です。

```
4 9 2
3 5 7
8 1 6
```

縦・横・斜めのどの列を足しても **15** になります。この並びを中国では**洛書**と呼び、そこに方位を割り当てたものを**九宮**と呼びました。九星気学の盤は、この配置をそのまま使っています。

つまり「一白は北」「五黄は中央」といった対応は、後から誰かが決めた語呂ではなく、**先に数の配置があって、そこに意味が乗った**という順序で成り立っています。

この記事は、その順序を追うものです。**当たるかどうかの話ではありません**。自分が見ている盤が何でできているかを知ると、流派によって答えが違う理由も見当が付きます。

## 1. 先にあったのは数の並び

洛書は「川から現れた亀の甲羅の模様」という伝説とともに語られますが、伝説の真偽とは別に、**三行三列の魔方陣そのものは数学的な対象**です。1 から 9 を一度ずつ使って縦横斜めの和を等しくする並べ方は、**回転と反転を同じものと数えれば 1 通りしかありません**。

これは確かめられます。すべての並べ方は 9! = 362,880 通りですが、条件を満たすのは 8 通りで、その 8 通りは互いに回転か鏡像の関係にあります。**選択の余地がない**ということです。

| 性質                       | 値           |
| -------------------------- | ------------ |
| 1〜9 の並べ方              | 362,880 通り |
| 和が等しくなる並べ方       | 8 通り       |
| 回転・反転を同一視した種類 | 1 種類       |
| どの列の和も               | 15           |

「なぜこの並びなのか」に対する最初の答えは、**それしかないから**です。中央が 5 になるのも選んだ結果ではありません。三行三列の魔方陣では、**中央の数は必ず全体の平均になる**ため、1〜9 なら 5 に決まります。

## 2. そこに方位が乗った

数の配置に八方位を当てたものが九宮です。中央を除く 8 つの数がそれぞれ方角を持ちます。

| 数  | 方位 |
| --- | ---- |
| 一  | 北   |
| 二  | 南西 |
| 三  | 東   |
| 四  | 南東 |
| 五  | 中央 |
| 六  | 北西 |
| 七  | 西   |
| 八  | 北東 |
| 九  | 南   |

この対応は**後天定位**（後天八卦の配置）と呼ばれます。上下が逆に見えるかもしれませんが、東アジアの伝統的な図では**南を上に描く**のが普通で、現代の地図と天地が反対です。九星の盤を初めて見たときに違和感があるのは、たいていこの向きの違いによるものです。

ここで押さえておきたいのは、**数が先で、方位は後**という順序です。1 から 9 の配置が決まっていて、そこに方角が結び付けられました。逆ではありません。

## 3. 色と五行はさらに後から乗った

「一白水星」「二黒土星」のような呼び名は、数に**色**と**五行**を重ねたものです。

| 星   | 色  | 五行 |
| ---- | --- | ---- |
| 一白 | 白  | 水   |
| 二黒 | 黒  | 土   |
| 三碧 | 碧  | 木   |
| 四緑 | 緑  | 木   |
| 五黄 | 黄  | 土   |
| 六白 | 白  | 金   |
| 七赤 | 赤  | 金   |
| 八白 | 白  | 土   |
| 九紫 | 紫  | 火   |

**層が 3 枚あります**。数の配置、方位の割り当て、色と五行の対応です。それぞれ由来が違い、加わった時期も違います。流派によって答えが分かれるとき、食い違っているのはたいてい一番上の層（意味の解釈）で、一番下の層（数の配置）はどの流派でも共通しています。

## 4. なぜ五黄だけ扱いが違うのか

五黄は中央にあります。中央には方角がありません。それなのに、実際の盤では五黄が北や東に来ます。

これは**盤が回るから**です。中央に入る星は年ごとに変わり、五黄も中央から出て八方位のどこかに座ります。そのとき五黄が座った方位を**五黄殺**、その正反対を**暗剣殺**と呼びます。

五黄が特別扱いされる理由を、体系の内側の言葉ではなく構造として言えば、次のようになります。

- 本来は中央、つまり**方角を持たない位置に属する星**である
- 中央は他の 8 つと性質が違い、対になる方位を持たない
- その星が方位に出てくること自体が、配置としては例外にあたる

**これは「五黄が危険な力を持っている」という説明ではありません**。中央にあるはずのものが外に出た、という位置関係の話です。ここを取り違えると、五黄殺だけが特別に恐ろしいものとして独り歩きします。

## 5. 盤はなぜ逆に回るのか

年盤では、中央に入る星が**毎年ひとつずつ減ります**。

| 年     | 中央の星 |
| ------ | -------- |
| ある年 | 九紫     |
| 翌年   | 八白     |
| その次 | 七赤     |

一に達したら九へ戻ります。**増えるのではなく減る**のがこの体系の決まりで、月盤も同じ向きに動きます（月盤は年によって始まりの星が変わります）。

数を減らす向きに動かすことを**逆行**と呼びます。なぜ逆かについては体系の内側でいくつかの説明が語られますが、**実務上は「そう定められている」以上のことは確かめられません**。この記事で言えるのは、9 で一巡すること、そして中央の星が決まれば残り 8 つの位置も自動的に決まることです。

つまり、年盤は**中央の星ひとつで全体が定まります**。九星気学の判定が「その年の中央が何か」から始まるのは、この構造によります。

## 6. 何が確かめられて、何が確かめられないか

歴史の話をするときに、事実と解釈を混ぜないほうが安全です。

**確かめられること**

1. 三行三列の魔方陣は、回転と反転を除けば 1 種類しかない
2. 中央が 5 になるのは、和が等しくなる条件からの帰結である
3. 中央の星が決まれば、残り 8 方位の配置は一意に決まる
4. 数の配置・方位・色と五行は、それぞれ別の層である

**確かめられないこと**

1. なぜ逆行なのか
2. なぜその方位が吉で、別の方位が凶なのか
3. その配置が現実の出来事とどう対応するのか

このサイトの判定は 1〜4 の構造をそのまま計算しているだけで、**吉凶の意味づけそのものを検証してはいません**。方位の吉凶が統計的に確かめられているかについては、[別の記事](/blog/is-there-statistical-evidence-for-houi)で扱っています。

## 7. 数字の並びを知っておくと何が変わるか

実用としては、次の 2 つが読みやすくなります。

**流派の違いがどの層の話か分かる**。本命星の求め方や年の境目で答えが割れるのは、数の配置ではなく**入口**、つまりどの日から新しい年と数えるかが違うからです。盤そのものはどの流派でも同じ形をしています。

**五黄殺と暗剣殺が必ず正反対にある理由が分かる**。暗剣殺は五黄の対面と定義されているので、位置関係として常に 180 度離れます。覚える必要はなく、盤を見れば分かります。

制度としての歴史、つまり**誰がこの判断を担っていたか**は、[国の役所から民間の占いになるまで](/blog/where-kigaku-and-houi-came-from)にまとめてあります。この記事が扱ったのは数の側、あちらが扱ったのは人の側です。

実際に自分の年の盤を見るには、[本命星と吉方位の早見表](/houi)が使えます。九星気学とは別の流派である八宅の見方は、[風水（八宅）で自分の吉方位を調べる](/houi/fengshui)に分けてあります。
