## 疲れたという感想だけで、天職から外れたと決めない

**仕事に納得していることと、疲れを感じないことは同じ条件ではありません**。[参考動画](https://youtu.be/amGsrWOyX5U)では、命式を人生の図面にたとえ、図面に合う仕事なら楽しく、疲れないという説明がされています。この対応関係は**動画内の見解**であり、疲れを使って適職を判定できるという実証結果ではありません。

動画には、本人が仕事の意味をつかんだ年齢を振り返る場面もあります。ただし、その一例から「同じ年齢で天職に出会う」「週末を楽しみにしていたら仕事が間違っている」と一般化はできません。この記事では、職業を変える回数ではなく、今の仕事を評価するときに異なる感想を混ぜない方法を考えます。

## 「200%」は的中率の測定値ではない

動画では命式に書かれた内容への強い確信を「200%」と表現しています。これは語り手の確信を強調する言い方として読み、鑑定の的中率には変換しません。何件を対象に、何を正解とし、誰が採点したかという資料が付いていないためです。

一つの予測に正解か不正解のどちらか一つを付ける集計なら、正解数は対象数を超えません。対象が10件なら最大は10÷10＝100%です。200%という言葉が出ても、普通の的中率の2倍の精度があるとは言えません。一方、目標に対する達成率なら200%という値はあり得るため、百分率という記号だけで意味を決めることもできません。

「何に対する何の割合か」を先に確かめる。この順序を守るだけで、強い言い方を測定データと取り違えずに読めます。運勢の予測を実際に記録する場合は、[予測と結果を別欄に残す読み方](/blog/prediction-journal-before-and-after)も参照してください。

## 数字の評価

分類は、(a)暦の計算で確かめられる事実、(b)統計等で確認できる事実、(c)動画の解釈・経験則で根拠未提示のものです。告知の数字も含め、字幕で確認できる主な数値を分けます。

| 動画に出る数字                 | 分類と計算・確認方法                                            | 確からしさ                                                       |
| ------------------------------ | --------------------------------------------------------------- | ---------------------------------------------------------------- |
| 年・月・日・時の4つの柱        | (a)に関わる命式の構成数。各柱の干支は出生条件と計算規則が必要   | 4欄という構成と、それが仕事・家庭・晩年を表すという(c)の解釈は別 |
| 45という年齢の振り返り         | (c) 出演者個人の経験談。時点の資料や比較対象は未提示            | 一般的な適職発見年齢や、転機の計算結果にはできない               |
| 200%書かれた通りという表現     | (c) 確信の強調。的中数÷対象数を計算する資料なし                 | 確認済みの的中率ではない                                         |
| 何千年という歴史の長さ         | (b)で検証すべき歴史的数量だが未確認                             | 起点・対象の技法・史料が不明で、具体的な年数へ直さない           |
| 2025年7月4日、参加2名、観覧5名 | (b)で確認する対象の告知情報。動画内の募集枠で、開催実績は未確認 | 2＋5＝7は枠の合計にすぎず、参加者数や成功例数ではない            |

(b)として確認済みの「命式に合った仕事では疲れない人の割合」は得られません。募集人数を鑑定の効果の標本数に流用したり、古さを精度の証明にしたりしないことが大切です。四柱の数から職業の正解数も計算できません。

## 納得した日と、疲れた日を別々に数える例

以下は動画の実績ではなく、読み方を示すための架空の10勤務日の記録です。仕事の内容に納得したか、その日の終わりに疲れを感じたかを別々に記入したとします。これは診断票でも標準化された尺度でもありません。

| 記録した組み合わせ           | 日数 |
| ---------------------------- | ---- |
| 納得した・疲れた             | 6日  |
| 納得した・疲れなかった       | 2日  |
| 納得しなかった・疲れた       | 1日  |
| 納得しなかった・疲れなかった | 1日  |

合計は6＋2＋1＋1＝10日です。納得した日は8日で80%、疲れた日は7日で70%です。同じ記録の中で両方の割合が高くても、計算の矛盾はありません。納得と疲れは別の質問への回答だからです。「疲れた7日」をそのまま「向いていない7日」に置き換えると、元の記録と異なる判定を加えることになります。

この10日分で天職かどうか、疲れの原因は何かを判定することもできません。作業内容、時間、本人の言葉を残しておけば、少なくとも「すべて楽しくなかった」という後からの一括評価と、その日に書いた感想との違いを確認できます。

## 仕事のどの部分に納得しているかまで戻る

仕事名だけでは、顧客への説明、資料の整理、予定の調整といった中身が見えません。同じ職業を続けていても、納得して取り組める作業と、目的が分からない作業を分けて書くことはできます。本人が「人の役に立てた」と感じた場面も、何をして誰からどんな返答があったかまで残すと、抽象的な人物像より具体的になります。

たとえば「説明資料を作る仕事が好き」と書いた横に、「目的の確認に時間がかかった」と書いても構いません。好きか嫌いかの一軸で全体を判定せず、次回に確認したい条件を取り出せます。作業時間を比較するなら、[着手・完成・手戻りを分ける記録](/blog/action-speed-and-completion-time)のように、どの時点からどこまでを数えたかもそろえます。

この記録は適職を保証する方法ではなく、動画の比喩と自分の経験を照合する材料です。本人の感想を、命式の説明に合うように修正する必要はありません。

## Cloud Paletteの方位判定とは分けて読む

四柱推命は九星気学とは別体系です。Cloud Paletteは方位を真北で判定し、暗剣殺・五黄殺は誰にとっても凶として扱います。仕事への納得や命式の解釈で、その判定を解除しません。

命式を振り返りのきっかけにしても、仕事の条件や自分の記録は別に確認できます。「200%」という確信の強さを、自分がどう感じたかより上に置く必要はありません。
