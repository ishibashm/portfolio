## 先に結論

**吉方位は「どちらへ移るか」、天中殺は「いつ動くか」を見るもの**です。

そのため、吉方位と天中殺は反対語ではありません。「吉方位だから天中殺ではない」「天中殺だから全方位が凶方位」という関係でもありません。

同じ引越しについて、方位の判定と期間の判定が同時に存在します。

## そもそも別の系統の考え方

Cloud Paletteで扱う吉方位は、主に九星気学の方位盤を使います。出発地から到着地への方位を出し、生年月日と移動日に応じた年盤・月盤・日盤を重ねます。

一方、天中殺は算命学で使われる言葉で、四柱推命では近い干支の概念を空亡と呼びます。呼び名が体系ごとに違う事情と、大殺界との対応は[天中殺と大殺界の違いは何か](/blog/tenchusatsu-names-and-schools)に書きました。九星気学の五黄殺・暗剣殺・歳破などとは、もともと別系統です。

Cloud Paletteは、利用者が両方を一つの画面で確認できるように重ねています。これは**異なる判定を組み合わせたサイト独自のモデル**であり、すべての流派に共通する唯一の作法ではありません。

## 違いを表にすると

| 観点                  | 吉方位                         | 天中殺・空亡                         |
| --------------------- | ------------------------------ | ------------------------------------ |
| 主に見るもの          | 移動する方向                   | 移動する時期                         |
| 変わる条件            | 出発地・到着地・日付・生年月日 | 生年月日と対象期間                   |
| 目的地を変えると      | 判定が変わりうる               | 期間自体は変わらない                 |
| 起点を変えると        | 方位が変わりうる               | 期間自体は変わらない                 |
| Cloud Paletteでの扱い | 年盤・月盤・日盤の方位を評価   | 設定に応じて禁止、弱化、または不使用 |

天中殺の期間中に目的地を東から西へ変えても、「天中殺の期間である」という判定は変わりません。反対に、同じ日でも目的地を変えれば方位の吉凶は変わります。

## 起こりうる4つの組み合わせ

方位と期間を分ければ、次の4通りがあります。

| 方位 | 期間           | どう読むか                                               |
| ---- | -------------- | -------------------------------------------------------- |
| 吉   | 天中殺ではない | 方位・期間とも採用規則上は通る                           |
| 吉   | 天中殺         | 方位は吉。ただし期間をどう扱うかは設定次第               |
| 凶   | 天中殺ではない | 時期を変えなくても、目的地や起点の変更で方位が変わりうる |
| 凶   | 天中殺         | 方位と期間の両方に注意点がある                           |

「天中殺中でも吉方位ならよいか」については、占術家や流派によって説明が分かれます。天中殺中の吉方位移動を状況別に解説する立場もあります。[優しい四柱推命の解説](https://sup.andyou.jp/shicyusuimei/tencyusatsu/tencyusatsu-life/tencyusatsu-hikkosi/)も、複数の状況を分けて扱っています。これは公的・科学的な基準ではなく、一つの解釈例です。

## 具体例：1985年10月12日生まれで本命星と天中殺を計算するとどうなるのか

九星気学の本命星は「立春で区切った生まれ年」から、天中殺（空亡）は「生まれた日の六十干支（日柱）」から算出するため、同じ生年月日でも参照する暦の単位が異なります。

**1985年10月12日生まれ**をサイトの実装で計算すると、次のようになります。

- **本命星**：立春（太陽黄経315度）を過ぎているため節年は1985年（乙丑）で、九星気学では**六白金星**です。立春前の1985年1月15日生まれなら前年（1984年・甲子）扱いで七赤金星になります。
- **天中殺（空亡）**：甲子の日である2000年1月7日からの日数差（−5,200日）を60で割った余りから、日柱は番号20の**甲申**です。甲申〜癸巳の旬（番号20〜29）で余る2支は**午・未**なので**午未天中殺**となります。
- **2026年・2027年の対比**：六白金星の年盤では、2026年（中宮：一白水星）は**東・北西**が吉方位で南（五黄殺）・北（暗剣殺・歳破・本命殺）が凶方位、2027年（中宮：九紫火星）は**南東・西・北西**が吉方位で北（五黄殺）・南（暗剣殺）・北東（歳破・本命的殺）・南西（本命殺）が凶方位です。一方、午未天中殺は**2026年2月4日の立春から2028年2月4日の立春前まで2年間が年天中殺**（毎年6月節の午月・7月節の未月は月天中殺）です。2026年に北西へ移る計画は、上の表の「方位は吉・期間は天中殺」の実例にあたります。

なお、2日前の**1985年10月10日生まれ**は同じ1985年節年なので本命星も吉方位も同じ**六白金星**ですが、日柱が番号18の**壬午**（甲戌〜癸未の旬）になるため**申酉天中殺**（年天中殺は**2028年・2029年**）に変わります。

## サイトの /houi と /houi/tenchusatsu では表示がどう違うのか

Cloud Paletteでは、方角を調べる[吉方位早見表（/houi）](/houi)と、時期を調べる[天中殺の引越し・時期確認（/houi/tenchusatsu）](/houi/tenchusatsu)で画面の役割を分けています。

- **[吉方位早見表（/houi）](/houi)**：生まれ年から9つの本命星を引き、年盤の八方位の吉凶と月別ページ、[エリア別の方位と相場](/houi/area)への導線を出します。生年月日入力欄では立春前の繰り下げ判定と年月日柱の干支・空亡2支も確認できますが、今後3年間の天中殺月の一覧はこの早見表には載りません。
- **[天中殺の時期確認（/houi/tenchusatsu）](/houi/tenchusatsu)**：生年月日から日柱と6グループ（子丑〜戌亥）を出し、現在の節年・節月の判定と**今後3年間（36か月分）の節月別早見表**を表示します。本命星や八方位の吉凶、移転先の街の方角はこの画面には出ません。

どちらの画面も、出るのは暦の計算結果です。引越し後の出来事の予測は出しません。

## このサイトでは扱いを5つから選べる

解釈を一つに固定しないため、このサイトの判定には「天中殺の扱い」の設定が5つあります。

| 設定                 | サイト内での扱い                                       |
| -------------------- | ------------------------------------------------------ |
| 厳格（年・月・日）   | いずれかが空亡なら移転不可。最も慎重な扱い             |
| 年天中殺は除く       | 月・日の空亡だけを移転不可にする                       |
| 日のみ               | 日の空亡だけを移転不可にする                           |
| 弱める（禁止しない） | 吉も凶も作用を弱く見積もり、移転は禁止しない。初期設定 |
| 使わない             | 天中殺を外し、九星気学の方位だけで見る                 |

転勤など、本人の意思だけでは避けにくい移動として登録した場合は、禁止せず影響を弱める扱いもあります。

初期設定は「弱める（禁止しない）」です。以前は「厳格」が初期設定で、年天中殺を含めるため該当する2年間は目的地を変えても移転不可の表示が続くことがありました。2026年11月から、天中殺の日でも方位の吉凶は出したうえで「天中殺なので吉凶の力は弱め」と添える扱いを初期設定にしています。「厳格」も選べますが、唯一の正解という意味ではありません。方位と時期のどちらが先に決まるかという順序の話は[方位と日取りのどちらが重いのか](/blog/direction-or-timing-which-matters)にまとめてあります。

## どの設定を選べばよい？

サイトが特定の流派を利用者に決めることはできません。次の順で選ぶと混乱しにくくなります。

1. 相談している専門家や学んでいる流派があれば、その規則に合わせる
2. 九星気学だけを見たいなら「使わない」を選ぶ
3. 空亡を禁止ではなく作用の弱まりと考えるなら「弱める」を選ぶ
4. 判断がつかず慎重に見たい場合は、「厳格」に切り替えて比較材料として使う
5. 一度選んだ設定は、候補同士を比較している途中で変えない

[方位で街を探す](/relocation/arbitrage)の「天中殺の扱い」で設定を切り替えると、[引越し時期を分析する](/relocation/timing)もその共有設定を読み、どの日が除外されるかを表示します。[引越しの日取りを選ぶ](/calendar)では、日取りを出す条件として画面内で個別に選択します。

## 天中殺と吉方位はどういう手順で分けて確かめるのか

引越しの候補地と時期を同時に動かすと条件が混ざりやすいため、先に「期間（天中殺）」と「採用する設定」を固定してから「方角（九星気学）」と「現地の街」を順に絞ります。

1. **[天中殺の時期確認（/houi/tenchusatsu）](/houi/tenchusatsu)で空亡2支と期間を控える**：生年月日を入れ、予定している節年（立春〜翌立春前）や節月（節入り〜次の節入り前）が天中殺に重なるかを確認します。
2. **重なる場合の「天中殺の扱い」を先に1つ決める**：上の5つの設定のうちどれを採るか、また転勤など他動的な移動として扱うかを先に固定します。
3. **[吉方位早見表（/houi）](/houi)で本命星と年盤・月盤の方位を見る**：全員共通の凶方位（五黄殺・暗剣殺・歳破／月破）と自分の本命殺・本命的殺を除き、残る吉方位や凶のない方位を控えます。
4. **出発地から真北でその方角に街があるかを見る**：[エリア別の方位と相場](/houi/area)や[方位で街を探す](/relocation/arbitrage)で、現住所から真北基準で候補の方角にある市区町村と家賃相場を確認します。
5. **[引越し時期を分析する](/relocation/timing)や[引越しの日取りを選ぶ](/calendar)で移動日を絞る**：手順2の設定を変えずに、候補の方位が開く月や日取り（六曜・天赦日・一粒万倍日・土用の間日など）を照らし合わせます。

## 計算の前提と流派差で注意すべき点は何か

暦の境目や測り方の前提がずれると、同じ生年月日や目的地でも別の判定に見えることがあります。Cloud Paletteでは次の基準で計算を統一しています。

- **年・月・日の境目（日本標準時）**：年は太陽黄経315度の立春、月は30度ごとの節入り（毎月4〜8日ごろ）、日柱は0時で切り替えます。立春や節入り当日の生まれで時刻不明な場合は[吉方位早見表（/houi）](/houi)で0時と23時59分の両候補を併記します。23時（子の刻）で翌日とする流派や真太陽時補正は日柱の空亡判定には使っていません。
- **方位は真北・観点の切り替えも可能**：判定はすべて地図と同じ真北基準です（方位磁針の磁北は、日本国内ではおおむね西へ5〜10度ずれます）。また、[方位で街を探す](/relocation/arbitrage)の観点切り替えで「本命星＋環境方位」や「本命星のみ」を選べば、天中殺の方位も期間も外して九星気学の盤だけで比較できます。

## 吉方位なら、住まいの現実の問題も解決するのか

方位や天中殺の判定とは別に、家賃、災害リスク、契約条件、通勤時間、医療・教育環境、家族の合意を確認する必要があります。方位が吉でも、これらの条件が不適切ならよい住まいとは限りません。

九星気学・算命学・四柱推命は伝統的な占術上の考え方であり、効果が科学的に確認されたものではありません。Cloud Paletteは計算条件を整理する道具で、将来の出来事を保証するものではありません。
