## 先に結論

**正確な数は、誰にも数えられません**。

流派には登録制度がなく、名乗るのに免許も要りません。師弟の分派は今も続いていて、**数えた瞬間に増えます**。それでも大きな系統で区切ると、この記事で数えた範囲では**日本に 4 系統**（気学・方鑑学・暦・算命学と四柱推命）、**日本の外に 6 体系**（風水・奇門遁甲・択日・ヴァーストゥ・ジオマンシー・アストロカートグラフィー）が並びます。

この記事で押さえたいのは数そのものではなく、「**流派が違うと、どこの答えが変わるのか**」です。そこが分かると、サイトや本ごとに判定が食い違ったときに、どちらが壊れているのかを慌てて探さずに済みます。

## なぜ数えられないのか

流派に登録制度や統一された名簿がなく、大正期に成立した気学からも師弟の分派が続いており、さらに体系どうしの境界も曖昧という 3 つの理由があるためです。

1. **登録制度がない**。国家資格でも業界団体の統一名簿でもなく、名乗った人の数だけ流派がある
2. **分派が続いている**。[九星気学の歴史](/blog/where-kigaku-and-houi-came-from)で書いた通り、現在の気学は大正 13 年に園田真次郎が名づけたもので、その弟子筋からさらに多くの会派が分かれた
3. **境界が曖昧**。同じ名前で規則が違う、違う名前で規則がほぼ同じ、という例が珍しくない（天中殺・大殺界・空亡がその例。[流派ごとの対応表](/blog/tenchusatsu-names-and-schools)）

「世界に流派はいくつあるか」への正直な答えは、**大きな系統なら十数、流派単位なら数百とも言われるが、確かめようがない**、です。

## 日本の中の系統

| 系統                     | 何を見るか                   | 補足                                         |
| ------------------------ | ---------------------------- | -------------------------------------------- |
| 気学（園田系の諸会派）   | 九星の年盤・月盤・日盤と方位 | 現在「九星気学」と呼ばれるものの主流         |
| 方鑑学の系統             | 九星と方位                   | 江戸期の松浦琴鶴らの流れ。気学の母体         |
| 暦の系統（高島易断など） | 暦注・易                     | 方位専門ではなく、暦の出版を通じて広まった   |
| 算命学・四柱推命         | 生年月日時と時期             | 方位ではなく**時期**を見る。天中殺はこちら側 |

同じ「九星」を使う流派の間でも、**本命星の求め方、年月の境目、何盤まで見るか、距離の扱い**が割れます。どこが割れるかの一覧は[九星気学の歴史](/blog/where-kigaku-and-houi-came-from)に書きました。

## 世界の体系

方位や場所の吉凶を扱う体系は、日本の外にもあります。**互いに独立して生まれ、規則に互換性はありません**。

| 地域                   | 体系                       | 主に何を見るか                                       |
| ---------------------- | -------------------------- | ---------------------------------------------------- |
| 中国                   | 風水（巒頭派・理気派）     | 土地と建物。理気派の中に八宅派・玄空飛星派などの分派 |
| 中国                   | 奇門遁甲                   | 時刻ごとの方位盤。短期の行動の向き                   |
| 中国                   | 択日（日選び）             | 行事の日取り                                         |
| インド                 | ヴァーストゥ・シャーストラ | 建物の設計と向き                                     |
| ヨーロッパ・イスラム圏 | ジオマンシー（土占い）     | 方位そのものではなく、土地や問いの吉凶               |
| 現代の欧米             | アストロカートグラフィー   | 出生図と土地の対応。20 世紀後半に考案                |

並べて分かるのは、**「方位の吉凶」は一枚岩の伝統ではない**ということです。

- **風水**：地形を見る**巒頭派**と、方位盤で読む**理気派**に分かれます。理気派でも、生年と性別から本命卦を出し8方位（45度×8）を東四命・西四命に分ける**八宅派**と、建築期と坐向を羅盤の**二十四山**（15度×24）で測る**玄空飛星派**では入力も角度も異なります（[風水と九星気学の違い](/blog/feng-shui-and-kigaku-side-by-side)）。
- **奇門遁甲**：十干・八門・九星・八神で盤を組み、主に約2時間ごとの**時盤**で移動の向きを見ます。置閏法・拆補法や回転式・飛宮式などの流派差があります。
- **ヴァーストゥ・シャーストラ**：インドの伝統建築体系で、敷地や建物を8方位と中央（ブラフマスタン）の9区画に分け、五大元素との対応から配置や向きを定めます。

風水は場所を見て、九星気学は人と移動を見て、奇門遁甲は時刻を見る。**問いの立て方からして違います**。それぞれが何を見ているかは[九星気学以外の評価基準。四柱推命・風水・奇門遁甲は何を見ているのか](/blog/other-systems-beyond-kigaku)で分けています。

そして、**どの体系が正しいかを決める上位の審判はどこにもありません**。体系同士は互いを参照せずに成立していて、答えが食い違っても、どちらかが反則をしているわけではありません。

## 流派が違うと、どこが変わるか

引越しの実務で効いてくる違いは、年の区切り、月の節入り、八方位の角度、太極が移る滞在日数、真北と磁北、重ねる凶殺や暦注という計算条件に集約されます。

1. **本命星**が変わる（求め方と年の境目の違い）
2. **方位の吉凶**が変わる（扇形の角度、真北か磁北か、何盤を重く見るか、吉神・凶神の採用範囲）
3. **時期の禁止**が変わる（節入りの扱い、滞在日数、天中殺やどの暦注を使うか）
4. **そもそも見る対象**が変わる（人か、場所か、時刻か）

別のサイトや鑑定と答えが食い違ったときは、**この 4 つのどこで違っているのか**を確かめるのが早道です。多くの場合、計算間違いではなく採っている規則が違います。

立春（黄経315度）は2026年が2月4日05時01分、2027年が2月4日10時46分、2028年が2月4日16時31分、2029年が2月3日22時20分（日本時間）です。立春当日の節入り前（例：2000年2月4日12時生まれ）は、0時区切りなら九紫火星、節入り時刻区切りの Cloud Palette では前年の**一白水星**になります。

また、伝統区分（30度/60度）と45度等分は8か所の境目が各7.5度ずれるため、全周360度のうち**60度ぶん（6分の1）**で方位が割れます（真北から20度は伝統区分で**北東**、45度等分で**北**）。さらに磁北基準と比べると、東京付近では磁北が真北よりおよそ8度西にずれるため、真北から10度の地点は真北基準なら**北**（345〜15度）、磁北基準なら約18度で**北東**（15〜75度）に移ります（[地磁気と方位盤の関係](/blog/geomagnetism-and-honmei-star)）。

## Cloud Palette はどの立場か

このサイトは、**方位を九星気学の三盤（古典の記述を基準にした算出）、時期を六曜・天赦日・一粒万倍日・土用・天中殺**で見ています。奇門遁甲・ヴァーストゥは使っていません（風水は八宅のみ別枠で併記可）。どの規則を採っているかは[使い方ガイド](/guide)に明示しています。

方位と時期を一つの画面に並べるのは**異なる体系を組み合わせたサイト独自のモデル**であり、すべての流派に共通する作法ではありません。学んでいる流派や相談している専門家がいる場合は、そちらの規則を優先してください。

## 自分の流派とサイトの設定はどう照らし合わせるか

本命星の境目、天中殺や凶殺の重ね方、方位の角度と北の基準、仮住まいの滞在日数の 4 点を順に確認すると、設定で合わせられる部分と読み替えが要る部分を切り分けられます。

1. **本命星と立春の境目を確かめる**：[本命星と吉方位を調べる](/houi)に生年月日を入れます。元日区切りの流派で1月〜立春前の生まれなら1年後の星を見ます。立春当日生まれは0時と23時59分の2つの星が出るため、「0時区切り」か「節入り時刻区切り」かで選びます。時盤は[今日の吉方位](/houi/today)で見られます。
2. **天中殺（空亡）と見る層を切り替える**：天中殺を重ねない流派なら、[引越しの日取りを選ぶ](/calendar)・[引越し時期を分析する](/relocation/timing)・[方位で街を探す](/relocation/arbitrage)の「天中殺の扱い」を「**使わない**」にします。空亡を禁忌とする流派なら「**厳格（年・月・日）**」や「**年天中殺は除く**」を選びます。空亡の時期は[天中殺を調べる](/houi/tenchusatsu)で引けます。
3. **角度区分と磁北のずれを確認する**：[移住先の地域を比べる](/relocation/wealth)や[方位で街を探す](/relocation/arbitrage)では、「節切り暦モデル（古典盤）」が**四正30度・四隅60度**、「天体軌道モデル」が**45度等分**に対応します。判定は真北で行うため、磁北基準の流派では境界付近の偏角の注意表示で読み替えます。5km未満は一覧から除かれます。
4. **八宅風水の併記と75日の滞在前提を確認する**：八宅も見る場合は[/houi](/houi)の八宅早見や[引越し先を試算する](/relocation/simulator)の「風水（八宅）でも見る」を開きます。複数段階の移動は「長期移住で**75日以上**滞在すると起点が移る」固定規則（[75日後の移動と相殺の考え方](/blog/does-a-lucky-move-cancel-an-unlucky-move)）で計算するため、45日・60日・90日説の流派では日数を手元で読み替えてください。

## 注記

九星気学・風水・奇門遁甲などは伝統的な考え方であり、効果が科学的に確認されたものではありません。Cloud Palette は計算条件を整理する道具で、将来の出来事を保証するものではありません。方位や時期の判定とは別に、家賃、災害リスク、契約条件、通勤時間、医療・教育環境、家族の合意を必ず確認してください。
