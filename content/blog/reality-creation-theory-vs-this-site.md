## 先に結論

さとうみつろう氏の理論とこのサイトは、**「方位」「時刻」「地磁気」という同じ言葉を使っています**。けれども、**その言葉でやっていることは別物です**。

氏の理論は、方位と時刻を選んで移動することで地球の回転や磁場と「同調」し、無数にある可能性の中から望む現実を「確定させる」と説きます。このサイトは、**九星気学の規則に沿って方位と日取りの条件を計算し、家賃や通勤時間と並べて比較できる形にする道具**です。効果の仕組みを説明していませんし、現実が変わるとも書いていません。

以下では、理論を 5 つの要素に分け、それぞれについて「実在する研究や事実」「そこからの独自の飛躍」「このサイトの扱い」を切り分けます。**理論を否定するためではなく、読む側が混ぜずに受け取れるようにするため**です。

## 理論はどう組み立てられているのか

手元のメモをもとに要約すると、氏の理論は次の 5 段で構成されています。

| 段             | 主張の要点                                                                                                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 世界観         | 過去・未来・あらゆる選択肢は「4次元」にすでに完成していて、意識はどのコマを体験するか選んでいるだけ                                    |
| 脳科学         | 意識が決めたと感じる 0.38 秒前に脳は動き始めている。自由意志は後付けの解釈                                                             |
| 物理・磁性     | 方位移動は地球の自転に伴う遠心力・求心力の「スピン」を取り込む行為。時刻の指定が要る。特定の方位と時刻で採った土や水は磁場の情報を保つ |
| 生体・波動     | 脳や網膜の磁気受容体が微小な磁場の変化を感じ、脳波を変える。疑いというノイズが信号を打ち消すので、感謝や冬至の「ゼロ状態」で下げる     |
| 形のフラクタル | 地球の磁気圏は太陽風で引き伸ばされて人間の形をしており、地球上の生命が人型になったのはその縮小                                         |

結論部では、これらを合わせて「冬至などのゼロポイントで脳波のノイズを下げ、自分の固有振動数に合う特定時刻・特定方位へ移動して地球のスピン磁場と同調し、土や水を触媒に、望む現実を確定させる技術」とまとめられています。

構造として見ると、**古典的な方位術（奇門遁甲）の実践に、量子力学・脳科学・地球物理の語彙で説明を与えたもの**と言えます。

## どこまでが実在する研究で、どこからが飛躍なのか

理論を読み解くうえでいちばん大事なのはここです。**引かれている研究の多くは実在します**。ただし、研究が示していることと、理論が結論づけていることの間には距離があります。

### 0.38 秒の法則

ベンジャミン・リベットが 1983 年に報告した実験は実在します。指を動かそうと「意識した」時刻より **0.3〜0.5 秒ほど前から、脳の準備電位が立ち上がっていた**という結果です。

ただし、これを「自由意志は幻」と読むかどうかは、その後 40 年にわたって争われています。準備電位は決定の合図ではなく、ゆらぎが閾値を越えた瞬間を後から切り出しているだけだ、という再解釈（2012 年のシュルガーらの確率的蓄積モデル）も有力です。**実験は事実、解釈は未決着**、というのが公平な要約です。

### 方位と「スピン」

地球が自転しているのも、それに伴う遠心力があるのも事実です。しかし物理学の標準的な説明では、**遠心力の大きさは緯度だけで決まり、東西南北のどちらへ歩いても変わりません**。「左回転で拡張、右回転で収縮」という向きの選び分けは、自転の物理からは出てきません。

「2025 年のエネルギーポイントは西南西（約 255 度）」という数字は、歳徳神の方位、いわゆる**恵方**と一致します。2025 年（乙巳）の恵方は庚の方位で、西南西やや西の 255 度です。これは暦の規則で決まる値であり、地球物理の測定値ではありません。なお同じ規則で**2026 年（丙午）の恵方は丙の方位、南南東やや南の 165 度**に移ります。

### 時刻と磁気圏

地球の磁気圏が太陽風によって昼側で押し縮められ、夜側に長く伸びているのは事実です。太陽風の変化で地磁気が刻々と揺れることも、Kp 指数として毎日観測されています。

けれども、**磁気嵐で方位磁針の向きが変わる量は、日本では多くの場合 1 度に満たず**、方位の吉凶を分ける 45 度の区切りに影響する大きさではありません。「目的の並行世界と位相を合わせるために時刻の指定が要る」という部分は、磁気圏の観測から導かれるものではなく、理論の側の前提です。

補足すると、メモで「バンアレン帯の歪み」とされている現象は、正確には磁気圏全体の変形です。バンアレン帯はその内側にある放射線帯で、別の概念です。

### 土と水の記憶

岩石や土が生成時の磁場の向きを記録すること（残留磁気）は、古地磁気学という確立した分野の基礎です。大陸移動の証拠もここから出ています。

一方、**水が情報を保持するという主張は、1988 年に _Nature_ 誌に載った実験が追試で再現されず、以後も肯定的な再現が得られていません**。「コヒーレントドメイン」は一部の理論物理学者が提案した仮説で、主流の物理学には採り入れられていません。土の残留磁気は事実ですが、「それを手元に置くと場のエネルギーと同調しやすくなる」という部分は、残留磁気の研究からは出てきません。

### 脳の磁気受容と「ノイズ」

渡り鳥がクリプトクロムというタンパク質で地磁気を感じているという仮説は、活発に研究されています。人間の脳にマグネタイト（磁鉄鉱）の粒子があることも報告されています。2019 年には、回転磁場に対して人の脳波（アルファ波）が変化したという実験も発表されました。

ただし、**人間が磁場の変化を「感じて」行動を変えているという結論には、まだ再現と検証が足りていません**。さらに、「疑いという脳波のノイズが信号を打ち消す」「感謝でノイズが下がる」という部分は、脳波の研究とは対応していません。**信じない人には効かない、という構造は、外れた場合の説明が最初から用意されているということでもあります**。この構造については[方位や九星に統計的な裏づけはあるのか](/blog/is-there-statistical-evidence-for-houi)で詳しく書きました。

### 磁気圏の「人型」

太陽風で変形した磁気圏の断面図が、見ようによっては人のシルエットに見える、という着想だと理解しています。**着想としては面白いのですが、生命の形の由来を説明する仮説としては、検証の手がかりがありません**。メモにも「独自仮説」と明記されています。

## このサイトは、同じ言葉で何をしているのか

ここからが本題です。このサイトにも**方位、時刻、地磁気、冬至はすべて出てきます**。混同されやすいので、要素ごとに並べます。

| 理論の要素             | このサイトの扱い                                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 4 次元・観測者         | 扱っていません。世界観の話で、計算の対象ではありません                                                                                 |
| 方位（遠心力・求心力） | 方位は**真北**を基準に、出発地から見た大圏方位角を八方位に切って判定します。自転や磁場の取り込みは想定していません                     |
| 時刻の指定             | 年盤・月盤・日盤の三盤を合成して日ごとの段階を出します。時盤も計算していますが、磁気圏との位相合わせではなく暦の規則です               |
| 土と水の記憶           | 扱っていません                                                                                                                         |
| 脳波・磁気受容         | Kp 指数や地磁気の値を参考として表示しています。**方位の吉凶の判定には一切入れていません**                                              |
| 固有振動数と干渉       | 九星気学の規則どおり、生年月日から本命星を出し、方位の星との相性（五行の相生・相剋）で吉凶を分けます。「波の干渉」とは呼びません       |
| 冬至のゼロ状態         | 冬至と夏至は、九星気学でも日盤の巡り（陽遁・陰遁）が入れ替わる節目です。切り替えの基準として使うだけで、心の状態とは結びつけていません |

### 磁北ではなく真北で判定する理由

理論では地磁気が主役ですが、このサイトは**磁北を判定に使いません**。理由は 2 つあります。

1. 方位の記事（[九星気学の方位と吉凶](/houi)）は全国向けの静的な頁で、場所ごとに違う偏角を持てません。判定を磁北にすると、記事と道具の答えが恒久的に食い違います
2. 磁北は場所と年で動きます。日本では真北から西へ 5〜10 度ほどずれていて、東京と沖縄でも違います

そのため判定は真北で行い、**「方位磁針で測るとこれだけずれる」という注意としてだけ**磁北を表示しています。理論のように磁場を積極的に使う立場とは、方向が逆です。

### 「天文モード」は理論と何が違うのか

このサイトには、盤の切り替えを暦ではなく天体の位置で決める「木星黄経（物理）」という選択肢があります。年盤を木星の黄経で、日盤の陽遁・陰遁を至点（太陽黄経 270 度と 90 度）で、時盤を地方恒星時で回します。

見た目は理論に近づきますが、**やっていることは「盤を回す時計を暦から天文に替える」だけ**です。星の配置は九星気学の規則のまま、盤が動く瞬間の決め方だけが違います。地球の自転が何かを取り込む、という主張はここにもありません。どちらの基準を使うかは[使い方ガイド](/guide)に書いています。

## それでも重なっている部分はあるのか

あります。**「いつ、どちらへ」を決めるという問いの立て方そのもの**です。

奇門遁甲が時刻ごとの方位盤で短期の行動を決めるのに対し、九星気学は年・月・日の盤で引越しのような長期の移動を決めます。問いの粒度は違いますが、どちらも「方位と時刻の組み合わせを、生まれ持った星との相性で評価する」という古典の枠組みの上にあります。体系ごとの違いは[流派はいくつあるのか](/blog/how-many-schools-are-there)と[九星気学以外の評価基準](/blog/other-systems-beyond-kigaku)にまとめました。

氏の理論が独自なのは、この古典の枠組みに**現代科学の語彙で仕組みを与えようとした点**です。このサイトはその逆を選んでいます。**仕組みを説明しない。規則を明示し、計算し、検証できる条件と並べる**。どちらが正しいかではなく、何を約束していて何を約束していないかの違いです。

## 読むときに気をつけたいこと

理論を読んで「科学的に裏づけられた方位術」と受け取ってしまうと、判断を誤ります。整理すると次のとおりです。

1. **引用されている研究は多くが実在する**。リベットの実験、磁気圏の変形、残留磁気、鳥の磁気受容
2. **研究が示す範囲と、理論の結論の間には飛躍がある**。遠心力は方位で変わらない。水の記憶は再現されていない。人の磁気受容はまだ確認の途中
3. **「疑うと効かない」という構造は、検証を受け付けない**
4. **このサイトも方位・時刻・地磁気を扱うが、仕組みの主張はしていない**。判定は九星気学の規則で、地磁気は参考表示

引越しは、方位とは別に**確かめられる条件**で大部分が決まります。家賃、通勤時間、災害リスク、契約条件。[物件を方位で探す](/relocation/arbitrage)が方位と家賃を同じ表に出しているのは、性質の違う 2 つの情報を、同じ重さで扱わないためです。理論を参考にする場合も、その並べ方は変わりません。

## まとめ

1. さとうみつろう氏の理論は、奇門遁甲の実践に量子力学・脳科学・地球物理の語彙で説明を与えたもの
2. 引用される研究の多くは実在するが、そこから「望む現実を確定させる技術」への飛躍は研究の側からは出てこない
3. 遠心力は方位で変わらず、磁気嵐で磁針が動く量は 1 度未満、水の記憶は再現されていない
4. このサイトは同じ「方位・時刻・地磁気」を扱うが、判定は真北と九星気学の規則で行い、地磁気は参考表示にとどめている
5. 天文モードも「盤を回す時計」を替えているだけで、仕組みの主張ではない
6. 何を約束していて何を約束していないか、を分けて読む
