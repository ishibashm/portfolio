# Phase Interference Diagnosis & Tactical Map Refinement

ユーザーからのご指摘に基づき、判定ロジックの優先度設定の修正、分かりにくい表記（黄色と赤の重複、固有波長など）の改善、目的地の分かりやすい設定（Google Maps検索等）を実装します。

## Proposed Changes

### 1. `Phase Interference Diagnosis` (優先度と色の統一)

現在マップ側は紫(生体)・赤(物理)に分かれていますが、診断（Diagnostics）テーブル側が旧仕様のままであり、これが大きな混乱の原因となっています。完全に同期させます。

#### [MODIFY] `src/components/SolarTimeClock.tsx`
- **Priority Label:** `( 優先度: 🟥 物理的ノイズ > 🟪 生体ノイズ > 🟨 警告(天中殺等) > 🟩 最適化 > 🟦 通常 )` に統一します。
- **Color Sync:** Diagnosticsテーブル内の `NOISE_HONMEI`, `NOISE_TEKI` (自律神経・生体波長に関するノイズ) を `text-amber-500` から `text-purple-500` に修正します。
- **セクションの概念整理 (ご質問の「時間と空間の分け方」への回答):**
  - 現在の表示は **X軸: 時間(Year/Month/Day) × Y軸: 空間(N, NE, E...)** のマトリクスとなっています。
  - さらに、Z軸として **「物理フェーズ (天体引力: 🟥)」 ⇔ 「生体フェーズ (自律神経: 🟪)」** という概念が存在しています。
  - 診断パネル内に、単なる「時間と空間」だけでなく「物理と生体のどちらのレイヤーで干渉が起きているか（TYPE I / TYPE II）」を明示するセクション（表示）を組み込みます。

### 2. Tactical Map Legend / 凡例の修正

マップ上に存在するが説明が足りていない「緑」「黄色」のゾーンの説明を追加し、用語を分かりやすく整理します。

#### [MODIFY] `src/components/TacticalMagneticMap.tsx`
- **「緑 (OPTIMAL)」の追加:** 「波長が完全にシンクロする最適化エリア（滅多に出現しない希少なゾーン）」としての解説追加。
- **「黄色 (WARNING)」の追加:** 「天中殺や月交点といった構造的バグ・特異点。長時間滞在は非推奨」の解説追加。
- **「固有波長」の解説:** ハードウェアInit(生年月日による初期設定である本命星の波長)の事であることを明記。
- 凡例でも `🟪 生体ノイズ` と `🟨 バグノイズ` の色の被りがないように説明を強化します。

### 3. Destination (目的地の指定) のUX改善と Google Maps 対応

現状の Lat/Lon 直打ちは分かりにくいため、以下の改善を加えます。

#### [MODIFY] `src/components/SolarTimeClock.tsx`
- **Action Intent の解説強化:** 「交渉・拡張（ビジネス）」なら○○の星を避ける、「休息」なら○○を避ける、となぜこれをわざわざ選択するのかを画面上に端的に数行で追記します。
- **Google Maps 検索・URL解析の導入:**
  - `Lat(緯度) / Lon(経度)` 横に検索窓を追加。
  - OpenStreetMap Nominatim API を用いた **地名検索（「東京」「大阪」など）** 機能を自前で実装。
  - **Google MapsのURLを貼り付けたら**自動でLat/Lonを抽出するパーサーを追加（例: `@34.6937,135.5022,15z`などを含むURLなら自動でセット）。
