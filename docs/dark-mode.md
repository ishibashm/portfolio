# ダークモード

ヘッダーのアイコン（広い画面ではサイドバー上部）を押すと、ライト → ダーク → 自動の順に切り替わる。ボタンの読み上げ名とツールチップに現在と次の設定を表示する。初回は自動。設定は端末の `localStorage` の `theme` に保存される。

`src/lib/theme.ts` のスクリプトをルートの `<head>` で同期実行する。描画と React の初期化より先に `html` の `.dark`、`data-theme`、`color-scheme` を設定する。自動では `matchMedia` の変更をその場で反映する。HTML のテーマ属性だけ hydration 警告を抑え、ボタンの初期 HTML はサーバーとクライアントで揃える。

## 配色

しるべの紺の羽織と金の縁取りに合わせ、操作やリンクに使っていたローズと青紫を勝色に統一した。`globals.css` のライト／ダークの変数から Tailwind、しるべの吹き出し、SVG の検索範囲線、統計グラフに適用する。

| 役割                 | ライト                                                               | ダーク                                                               |
| -------------------- | -------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 地色                 | ページ `#FAF7F2`、カード `#FFFFFF`、補助面 `#F2EDE4`、罫線 `#DDD6CA` | ページ `#151722`、カード `#1E2130`、補助面 `#262A3C`、罫線 `#383E56` |
| 文字                 | 本文・見出し `#171C2B`、補足 `#4D5568`                               | 本文・見出し `#F3EFE8`、補足 `#B2B8CA`                               |
| 主アクセント（勝色） | `#1E3A6E`、淡面 `#EBF0FA`、ボタン文字 `#FFFFFF`                      | `#8CB4FF`、淡面 `#212D48`、ボタン文字 `#151722`                      |
| 副アクセント（金）   | `#8A6216`、淡面 `#FBF5E6`、装飾 `#C9A54A`                            | `#DFB968`、淡面 `#31291D`                                            |

吉凶の判定色は独立した配色として扱う。`TIER_FILL` は `master` と同じ値で、方位の扇形や風水の評価図では既存の塗り色を使用する。ダークでは、D（凶寄り）の判定文字に橙（`orange-400`）、バッジ面に同じ橙の不透明度 15% を使う。金はブランドの副アクセント、X の判定は赤系で表示する。地図タイルは地図の明暗設定に従う。検索範囲は勝色の細い破線で示す。

市場グラフは勝色を主線とし、比較線と補助面に同系色の明度差を使う。参照線・グリッドは補足文字や罫線と同系統の色を使う。

## コントラスト

sRGB の相対輝度から `(明るい色の輝度 + 0.05) / (暗い色の輝度 + 0.05)` を計算した。WCAG AA は本文 4.5:1、大きい文字と識別に必要な UI・図の要素は 3:1。表は指定色同士の比率で、地図タイル上の比率は地点とタイルの明暗で変わる。 [文字の基準](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)・[UI・図の基準](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

| 前景／背景                             |  ライト |  ダーク |
| -------------------------------------- | ------: | ------: |
| 本文／ページ                           | 15.88:1 | 15.56:1 |
| 見出し・しるべの本文／カード           | 16.97:1 | 13.93:1 |
| 補足文字／カード                       |  7.46:1 |  8.06:1 |
| 勝色リンク／ページ                     | 10.42:1 |  8.57:1 |
| 勝色リンク・しるべのリンク／勝色の淡面 |  9.75:1 |  6.58:1 |
| 勝色ボタンの文字／ボタン面             | 11.14:1 |  8.57:1 |
| 勝色の選択状態・フォーカス線／カード   | 11.14:1 |  7.67:1 |
| 金の文字／ページ                       |  5.12:1 |  9.58:1 |
| 金の文字／カード                       |  5.47:1 |  8.57:1 |
| 金の文字・しるべの名札／金の淡面       |  5.03:1 |  7.69:1 |
| 吉の文字／吉の淡面                     |  6.49:1 |  9.01:1 |
| 凶の文字／凶の淡面                     |  6.68:1 |  7.03:1 |
| 引用の本文／勝色の淡面                 | 14.85:1 | 11.95:1 |
| 市場グラフの比較線／カード             |  5.06:1 |  4.60:1 |

ダークの D の判定文字は、カードに対して 6.71:1、ページ地色に対して 7.50:1。橙 15% のバッジ面を重ねると、カード上では 5.23:1、ページ地色上では 5.91:1。

## 確認範囲

- Chrome でトップ、`/houi`、引越し4画面、ブログ一覧と記事、404、しるべの吹き出しを撮影。画像は `/workspace/dark-mode/after/`。
- ローカルの本番ビルドでは、ブログ一覧・記事とも既存の Markdown フォールバックを表示した。DB 上のコンテンツとコメントは確認範囲外。
- `wealth` の実データ、`arbitrage` の物件・地点のポップアップ、`simulator` の入力後の結果は初期状態を中心に確認した。地図の一部の操作パネルとポップアップには明色の面が残る。

`/annai` の地色・カード・ステップ・入力・結果と、`/ask` の停止案内・会話用 UI をテーマ変数に移行した。

`/mcp`、暦（一覧・年別・月別）、ガイド（一覧・記事）、`/kensho`、都道府県（一覧・県別）、年盤・月盤と、各画面で使うカードや入力欄もテーマ変数に移行した。

### 配色が残る箇所

- 地図の操作パネルやポップアップの一部（ホームや移住比較など）。タイル・衛星写真は対象外。
- テレメトリーの系列と磁気地図のレイヤー・凡例（`TelemetryChart.tsx`、`MagneticMapInner.tsx`）。
- LINE などの外部連携（`LineFriendLink.tsx` など）と、既存のブログ記事の図版。

## 2026-11-24 追記

プロフィール・アカウント、引越し時期分析と引越し関連ページ、方位比較、管理画面、エラー画面などの背景・カード・入力をテーマトークンに統一した。引越し時期分析は layout とページ本体を同じ `bg-background` の配下に置き、途中で白いグラデーションへ切り替わらないようにした。`/mcp` のコード例が狭い幅ではみ出す問題も、カードとコードに `min-w-0` と折り返しを入れて直した。エラー画面はテーマ設定が外れたときにもダークを当てる。
