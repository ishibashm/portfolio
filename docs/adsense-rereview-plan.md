## 残作業（再審査の前に）

1. **固有文の増補（いちばん効く）。**市区町村のリードが 200 字に満たない 29 頁を、地理の構造が分かる長さまで足す。短いブログ（例: `/blog/houi-and-tenchusatsu` など 2000 字未満の 5 本）も、既存の一次情報の範囲で厚くする。事実の無い文章は足さない。
   2026-11-12 の続きで、29 頁と短い記事 5 本に固有の本文を足した。文字数は英数字・仮名漢字に中黒・長音・々を足した数で、加筆前は 155〜199 字、加筆後は 300 字以上。頁ごとの前後は PR の本文に書いた。
2. **都道府県の解説の点検。**一部に、2026 年 9 月に止めた物件掲載の集計を前提にした言い方が残っている。公表統計の説明に揃える。数字の約束は書かない。
   同じ続きで、物件スキャナーや「巡回が広がる」前提の文を外し、家賃は住宅・土地統計調査、方位の一覧は巡回を止めた時点の市区町村、と書き分けた。熊本・宮城の区の高低と、高知・長崎・鹿児島・長野の市町数は、手元の統計と方位一覧に合わせて直した。前後の文は PR の本文に書いた。

## 再審査を出すタイミング

次をすべて満たしてから、**本人が** AdSense 管理画面で再審査を出す。この PR を出しただけ、マージしただけでは出さない。

1. この PR が master に入り、本番に出ている。
2. 残作業の 1 と 2 を、少なくとも最短の市区町村群と、古い「掲載」表現のある県頁で済ませている。
3. 本番のサイトマップに `/houi/pref` と `/editorial` が載り、内頁の HTML からプライバシーポリシーへ辿れることを、人が確認している。
4. 反映から数日〜2 週間程度、再クロールの余地を置いている。同じ内容で何度も申請しない。

支払い情報の案内は管理画面に出ていたが、再審査の申請そのものではない。住所確認の待ちは見当たらなかった。
