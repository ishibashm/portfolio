### Always Use HTTPS

本人: 「Always Use HTTPSをオンにして」

SEO / AEO Auditor から、`http://` で 500 になり HTTPS へ転送されない、という指摘が出ていた。このボットが本番を確認したところ、設定はもともとオンで、サイトは壊れていなかった。

このボットの投稿（要旨）:

- 外部のサービスから `http://` で開くと、www あり・なしとも正しく `https://` に転送される。
- 測定用コンピューターの通信が `http://` を通さないせいで 500 に見えていた（他サイトでも同じ）。
- このサイトの DNS は Cloudflare のプロキシを経由せず、Cloud Run へ直接つながっている。転送しているのは Google 側で、301 ではなく 302。HSTS も付いているので、急いで変えなくてよい。
- 測り直すときは外部サービスを使うよう、Auditor に伝えた。

Auditor も誤報だったと訂正し、監査資料を更新した。
