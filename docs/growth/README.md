# サイト改善・成長フレームワーク

cloud-palette.com の流入（検索、AI の引用、共有、サイト内の戻り）と、審査通過後の広告収益を、実行のたびに同じ手順で見る。第三者のサイトは見ない。脆弱性の探索もしない。

マージとデプロイはしない。`master` への反映は、所有者が PR を見てから。

## 役割

| 役割                     | 見ること                                                                                            |
| ------------------------ | --------------------------------------------------------------------------------------------------- |
| Auditor                  | 頁、canonical、openGraph、llms.txt、MCP の道具、記事と地域頁の厚み。本番は自サイトの少数の URL だけ |
| Growth                   | 題名がまだ無い検索意図、共通の共有画像、動画から道具へ戻す動線                                      |
| Monetization             | AdSense の審査前の阻害、通過後の枠、審査前に置ける紹介                                              |
| Planner                  | 影響と工数の得点。自動で適用してよい項目は空                                                        |
| Content / Design / Media | 記事の骨子、共有画像の指示、30 秒の構成。ファイルは作らない                                         |
| Builder                  | 差分の提案だけ。リポジトリは書き換えない                                                            |
| Verifier                 | マージ禁止、識別子の除去、自サイト以外へ出ないこと                                                  |

文章の補足だけ、設定した言語モデルに頼める。指摘の一覧はコードが作る。モデルが指摘を上書きすることはない。

## 実行

```bash
npm run growth -- --stamp 2026-11-18
npm run growth -- --live --stamp 2026-11-18
npm run growth -- --provider openai
```

`--merge` `--deploy` `--apply` は終了コード 2 で止まる。

鍵は環境変数だけ（`growth.config.json` の `apiKeyEnv`）。ファイルには書かない。鍵が無いときは heuristic の文章だけになる。

出力は `docs/growth/runs/<日付>/report.md` と `report.json`。広告のパブリッシャー ID、アフィリエイトの計測パラメータ、メールアドレスは落とす。

`adsenseReview` は所有者が管理画面で見た状態を書く。コードからは「通過した」と推定しない。既定は `not-passed`。

## 定期実行

`.github/workflows/growth-framework.yml` にスケジュールは無い。手動実行も、リポジトリ変数 `GROWTH_FRAMEWORK_ENABLED` が `true` でない限り始まらない。始まっても成果物を上げるだけで、`master` へは送らない。

## この仕組みがやらないこと

- 判定のしきい値を変える
- 再審査の申請
- 空の広告枠を出す
- 生年月日、住所、命式をレポートに書く
- 楽天の掲載を風水以外へ広げる、DMM FX を足す
