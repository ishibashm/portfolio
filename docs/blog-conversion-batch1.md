順番は Search Console の3か月分（2026-07-05〜10-04）の表示回数・掲載順位・クリックから決めた。

## スライド

- `scripts/blog/slides_v27_batch1.py`（`python3 scripts/blog/slides_v27_batch1.py [slug ...]`）。
  v27 のエンジン `scripts/blog/slides_v27.py` はそのまま import して使い、変更していない。
  （このブランチの `slides_v27.py` は PR #1691 と同じ内容。どちらが先に入っても衝突しない）
- 追加したもの
  - シリーズ札に任意のシリーズ名（「本命的殺」「60年説」「距離と方位」）とトピックを入れる `BSlide`
  - 切り抜きのゴミ取り：背景のフラッドフィルは v27 と同じ。そのあと不透明部分の小さな連結成分（JPEG ノイズ）を捨て、
    外接矩形を人物に合わせる。人物が画像の中央寄りにいても、端に正しく寄せられる
  - パレットにブランド色（朱・青緑・藍・アイボリーなど）を必ず残す量子化。v27 と同じく 96→84→72 色で 300KB 以下。
    メディアンカットだけだと、星雲に色数を取られて朱が茶色にくすむため
- 描く数字はすべて、記事本文に同じ文字列があることを `assert` で確かめてから描く
- イラスト：`scripts/blog/assets/<slug>/{cover,slide-1..4}.jpg`。初代 案内役「しるべ」（オリジナル・AI生成、
  無地の藍背景、実在の人物や商標なし）。ポーズと小道具の指示文は記事の内容に合わせて1枚ずつ書いた

## 動画（このリポジトリには入れない）

- VOICEVOX:玄野武宏（ノーマル・話速1.0）、1行ずつ合成。BGM はコードで合成したオリジナル曲
- 読みは動画ごとの置換（字幕は原文のまま）。ユーザー辞書は変えない。
  エンジンが2つに割るアクセント句（本命的殺・年盤・四隅）は、合成前に1句へまとめ直す
- `youtubeId` / `videoUploadDate` / `videoDuration` と `::youtube` は、公開後に動画IDが決まってから記事に足す
