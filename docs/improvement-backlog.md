## 3. 九星気学についての整理（実装ではなく前提の共有）

「東へ凶方位で移動 → 75 日 → 吉方位へ移動」で、最初の凶は相殺されるのか、という問い。

**流派で言うことが違う領域なので、サイトとして断定的に書かない。**
確実に言えるのは幾何のほうだけ。

### 第 2 移動が短いと、元の起点から見た方位は変わらない

京都を起点に計算した実測値。

```
東  30km → 南東  10km : 元の起点から E   ← まだ東の扇形の中
東  80km → 南東  30km : 元の起点から E   ← 同上
東 200km → 南東  80km : 元の起点から E   ← 同上
東  80km → 南東  80km : 元の起点から SE
東  10km → 南東  10km : 元の起点から SE
```

目安として、**第 2 移動が第 1 移動の 1.5 倍程度ないと扇形を出ない。**

75 日で基点が移る規則（実装済み）は「**次の移動をどこから測るか**」を決めるだけで、
「元の起点から見てどこにいるか」は別の話。ここを混同すると、
「吉方位へ動いたはずが、元の起点から見るとまだ凶方位の中」が起こる。

### 画面に出すとしたら

**提案：シミュレータで「元の起点から見た現在地の方位」を併記する。**
基点は移っても、元の起点からの方位は消えないという事実だけを示す。
相殺されるかどうかの解釈には踏み込まない。

これなら流派の判断をサイトが下さずに済み、利用者は自分の流派で解釈できる。

### 訂正 — #258 の説明は誤りだった

#258「サイトマップに認証を掛けていたのをやめる」の本文に

> `/sitemap.xml` を取りに来ただけで updateSession が走り、1 回ごとに
> Supabase の getUser() へネットワーク往復が入る

と書いたが、**これは誤り。**`utils/supabase/middleware.ts` には既に番人がある。

```ts
// On public routes without auth cookies, skip remote auth network call
if (!requiresAuthentication && !isLoginPage && !hasAuthCookie) {
  return supabaseResponse;
}
```

クローラは Cookie を持たず `/sitemap.xml` は保護対象でもないので、**往復は起きていない。**
#258 の変更自体（公開ファイルに middleware を通さない）は妥当だが、**取得失敗の
原因の説明にはなっていない。**同じ勘違いを繰り返さないため、番人の存在をここに残す。

### 残っている有力な原因 — コールドスタート

```
--min-instances=0   ← 待機インスタンスなし。途切れると毎回起動から
--memory=512Mi
--cpu=1
```

## 8. `finalVectors` の型が八方位しか埋めていないのに CENTER を約束している

`calculateVectorCollision` / `filterCollisionByMode` の戻り値は

src/app/api/relocation/export/route.ts(402)
src/app/api/relocation/history/route.ts(315)

を引数に持っている。`VectorCollision` に寄せれば一緒に消える。

### なぜ #536 で直さなかったか

1 PR = 1〜3 ファイルに収まらない（6 ファイル）。型だけの整理と、

2. **地図に `doyouSatsuDirection` を渡す。**`MagneticMapInner` の
   `layers` prop は 4 つの層しか受け取っていないので、そこに 1 つ足す。

3. 物件検索の `maxAstroFactor` も同じ。`targetDetails.doyouPenalty < 0`

## 13. `/houi/area/39205` の 404 を受け入れる（2026-08-25 に判断）

Search Console の 404 一覧（2026-08-24 書き出し）に
`/houi/area/39205`（高知県土佐清水市）が残っている。最終クロールは
2026-08-22。

`src/data/areaDirections.json` の**直近 8 版すべてに存在しない**。
掲載が閾値に満たなくなって落ちたまま、戻っていない。

#533 の引き継ぎは「**前回のファイルにあったもの**を残す」仕組みなので、
**それ以前に落ちた市区町村は戻らない。**39205 には引き継ぐ数字自体が
残っていないので、復活させるならデータ無しの状態で描くことになる。

### 受け入れる理由

- この頁は #379 で **noindex** にしてある。索引から失うものが無い
- 数字の無い相場の頁を出すのは、**404 より悪い**。「相場が分からない」
  ことを「相場のページがある」形で見せることになる
- 恒久的に直すなら「**一度公開した code の台帳**」を別に持って、
  落ちても枠だけ残す作りが要る。1,000 件規模の URL を永久に維持する
  約束になるので、noindex の頁のためにやることではない

### もし気が変わったら

台帳を持つより、**落ちた市区町村は都道府県の頁へ 301 で寄せる**ほうが
筋がよい。URL は生き、中身は必ずある。ただし都道府県の頁が要る。
