# OpenCodeとGLM 4.7で無課金コーディングエージェント体験

OpenCodeというオープンソースのコーディングエージェントから、GLM 4.7が無料で、しかもアカウント登録もなしで試せたので、やってみました。
コーディングエージェント、便利そうだけど課金がすごそうだし・・・と思ってた人も気軽に試せます。

## インストール

インストールは [GitHub](https://github.com/sst/opencode) のほうにパッケージ管理ツールでのインストール方法が並んでるので、好きなものを。

```bash
# Package managers
npm i -g opencode-ai@latest        # or bun/pnpm/yarn
brew install opencode              # macOS and Linux
mise use -g github:sst/opencode # Any OS
```

## 起動

プロジェクト用のフォルダを作って、そこで `opencode` コマンドで実行します。

## GLM-4.7に接続

`/models` コマンドを使って接続モデルを選びます。
`GLM-4.7 OpenCode Zen` がFreeであるので、これを選びます。

## TODO管理アプリを作ってもらう

ということで、Spring BootでのTODO管理アプリを作ってもらいましょう。

> Spring Bootでtodo管理アプリを作って。
> Spring MVC でテンプレートにthymeleafを使って。
> DBはH2でアクセスにはSpring JDBC を。

エンターキーを押すと、AIが動き出し、コードを書き始めます。
出来上がったら「実行して」と言うだけで、Spring Bootが起動します。

## 実行結果

`localhost:8080/todos` にアクセスすると、指定通りTODOアプリができていました。
しかし、Addボタンを押すとエラーが発生。

### 修正してもらう

エラーが出ている状態でAIに任せると、ログを見て修正を始めてくれます。
ポートが競合している場合は、プロセスをキルする指示なども必要ですが、基本的には自律的に動きます。

## デザインをかわいく

「デザインがかわいくないから、もっとかわいくできない？」と指示を出すと、即座にCSSとコードを修正。
クリスマスカラーのかわいらしいデザインに変更されました。

## まとめ

アカウント登録不要で、ここまで強力なコーディングエージェントを体験できるのは驚きです。無課金で試してみたい方はぜひ `OpenCode` と `GLM 4.7` の組み合わせを試してみてください。
