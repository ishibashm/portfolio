# 第1部：`/relocation/arbitrage` 物件を方位で探す

## 1. この画面は何をするところか

**このサイトの主力画面です。** 賃貸物件を「引越しの方位が良いか」と「相場より安いか」の
両方から同時に絞り込みます。

画面の説明文：

> 今住んでいる場所から見た方位の吉凶と、同じ地域の家賃相場からの割安度をあわせて並べます。凶方位の物件は下に送ります。

## 2. 画面の構成

```
┌──────────────────────────────────────────────────────────┐
│ 見出し「物件を方位で探す」   物件データ最終取込 [再スキャン]│
├──────────────────────────────────────────────────────────┤
│ ⚠ 出発地を設定してください（未設定のときだけ出る）          │
├───────────────────────┬──────────────────────────────────┤
│ 左サイドバー（条件）    │  右：地図                        │
│  ┌──────────────────┐ │                                  │
│  │条件(N) 表示範囲内:N件│ │   物件のピンが並ぶ               │
│  │      [一覧を表示]  │ │                                  │
│  └──────────────────┘ │                                  │
│  ① スキャン地域と計算方式│                                  │
│  ② 絞り込みフィルター   │                                  │
│  ③ 同行者・合流する人   │                                  │
│  ④ 評価軸の重み        │                                  │
│  ⑤ 最強の物件 TOP 5    │                                  │
└───────────────────────┴──────────────────────────────────┘
```

①〜⑤はすべて見出しを押して開閉できます。初期状態は閉じており、閉じたままでも
検索範囲、適用条件数、同行人数、重みプリセット、TOP 5 の件数が見出し右側に表示されます。

**左サイドバーには2つの表示モードがあります。**

| モード           | 内容                       | 切り替え             |
| ---------------- | -------------------------- | -------------------- |
| 絞込画面（初期） | 上の①〜⑤                   | 「絞込に戻る」ボタン |
| 物件リスト       | 検索結果のカード一覧 or 表 | 「一覧を表示」ボタン |

> **重要な制限**：「一覧を表示」ボタンは、**地図に写っている物件が100件以下のときしか出ません**。
> 101件以上のときは代わりに「※100件以下で一覧表示可能」という文字が出るだけで、一覧に切り替えられません。
> **地図をズームインして件数を減らす必要があります。** これは仕様です。

**画面幅による違い**

| 幅                               | レイアウト                                                                   |
| -------------------------------- | ---------------------------------------------------------------------------- |
| 1024px未満（スマホ・タブレット） | **条件が上、地図が下の縦積み**。条件①〜⑤は閉じた状態から必要な項目だけ開ける |
| 1024px以上                       | 左3割が条件、右7割が地図                                                     |
| 1024px以上＋一覧＋表             | 左右5割ずつ                                                                  |

## 3. 最初にやること：出発地の設定

**この画面は、出発地（今住んでいる場所）を設定しないと何も検索しません。**

未設定のときは、画面上部に警告が出て検索が止まります。

```
出発地を設定してください
吉方位は「今お住まいの場所から見てどの向きか」で決まります。
…スキャンを停止しています。左の「出発地座標」から現在の
お住まいを指定してください。
```

> **テストの起点**：新しいブラウザ（設定が空の状態）でこの画面を開くと、**必ずこの警告が出るのが正常**です。
> 「何も表示されない」と報告する前に、出発地が入っているか確認してください。

## 4. 【条件①】スキャン地域と計算方式

| ラベル                               | 種類                  | 選択肢                                                                                                                                                                                                                  | 初期値                           |
| ------------------------------------ | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| 検索範囲                             | プルダウン            | 「範囲を限定しない（地図に見えている範囲）」／「出発地から50km以内に絞る」／**実際に物件データが載っている都道府県**。都道府県は固定一覧ではなく `src/data/prefecturesWithData.json` から作られ、取り込みが進むと増える | **範囲を限定しない**             |
| 生年月日 (吉方位用)                  | 日付＋時刻            | —                                                                                                                                                                                                                       | `1988-11-25T04:26`（保存値優先） |
| 出発地座標（現在のお住まい）         | 数字2つ（緯度・経度） | 上限下限なし                                                                                                                                                                                                            | **空（未設定）**                 |
| 出生地座標（天体ライン用）           | 数字2つ               | 上限下限なし                                                                                                                                                                                                            | 34.3952 / 132.4482（広島）       |
| 方位盤の計算レイヤー                 | プルダウン            | 年盤（長期・引越し向き）／月盤（中期・旅行向き）／日盤（短期・出張向き）／総合ベクトル（全レイヤー統合）                                                                                                                | **年盤**                         |
| 真北を使用（無効時は磁北補正）       | チェック              | —                                                                                                                                                                                                                       | **オフ（＝磁北を使う）**         |
| 月相タイミング補正（日単位 +/-10点） | チェック              | —                                                                                                                                                                                                                       | **オン**                         |

- 都道府県を選ぶと、**地図の中心がその県へ移動**し、その県全体を検索します。
- 「範囲を限定しない」が初期値です。**半径や県で削らず、地図に見えている矩形だけを検索します**（見えている範囲＝検索範囲）。初回表示は出発地を中心にズームした状態から始まります。
- ズームを10未満に引くと**俯瞰**になります。俯瞰では物件の検索は走らず、県別の色分けと**掲載数の数字だけ**が出ます（数字は毎晩の集計による静的データで、リアルタイムではありません）。ズームインすると、そのとき見えている範囲だけを検索して物件が表示されます。
- かつて存在した「全国45万行を検索して十数秒待つ」経路は、この俯瞰への置き換えで**廃止**されました。どの操作でも十数秒待ちは発生しません。
- 一時期は初期値を「出発地から50km」にしていましたが、圏外の物件が最初から存在しないように見えるため戻しました。50km に絞りたいときは明示的に選べます。
- 検索範囲は保存されます。
- 地図をズームして表示領域で絞る場合も、選択中の50kmまたは都道府県の条件は解除されません。
- 座標欄の横の「地図で検索」ボタンで、地図から場所を選べます。
- **出生地座標を空にすると、太陽・金星・木星のラインによる加点が効かなくなります。**

> **報告対象になり得る点**：「月相タイミング補正」だけは**保存されません**。
> ページを再読み込みすると必ずオンに戻ります。他の設定は保存されます。

**画面に無いが内部で使われている設定**（テストでは変更できません）

- 取得件数：500件で固定
- 同じ部屋の重複掲載のまとめ：常に有効
- 掲載からの経過日数：30日以内

## 5. 【条件②】絞り込みフィルター

### 5-0. スマート検索と条件チップ（2026-08-09 追加）

パネルの先頭に**スマート検索**の入力欄があります。1行で複数条件をまとめて書けます。

```
例: 姫路 2LDK 8万円以下 徒歩10分 築15年以内 北東 吉方位のみ
```

- 家賃（8万円以下・6〜8万）、間取り（2LDK・ワンルーム）、駅徒歩、築年数（築15年以内・新築・築浅）、広さ（30㎡以上）、方位（北東、南側）、吉凶（吉方位のみ・大吉のみ・凶を除外）を解釈し、**個別のフィルタに展開**します。解釈は端末内で即時に行われます
- 解釈されなかった語は物件名・住所の検索語になります（空白区切りは AND）
- 定型表現が1つも無い純粋な文章（「静かで広めの部屋」など）はサーバの AI 解釈に回します。**AI が構成されていない環境ではキーワード検索になるだけ**で、エラーにはなりません
- 適用中の条件は**チップ**として並び、× で個別に外せます。手で入れた条件も同じチップに出ます
- 地名の「西宮」「東広島」を方位の西・東と誤認しないこと（テスト済み）

### 5-1. 物件の詳細パネル（2026-08-09 追加）

物件カード・表の行・TOP5 をクリックすると、**サイドバー最上部に詳細パネル**が開き、地図がその物件へ寄って**紫のリング**で強調されます。

- 内容: 家賃（管理費込み・㎡単価）、間取り/広さ/築年数/階/駅徒歩/掲載社数、出発地からの方位と距離、全評価軸の内訳バー、掲載元へのリンク
- × で閉じる。**絞り込みを変えても選択中の詳細は消えない**（読んでいる途中で消えるのは不親切なので意図的）

| ラベル            | 種類       | 選択肢                                                 | 初期値       |
| ----------------- | ---------- | ------------------------------------------------------ | ------------ |
| 物件名・住所検索  | 文字入力   | 部分一致                                               | 空           |
| 吉凶ステータス    | プルダウン | 全ステータス / OPTIMAL (大吉) / SAFE (吉) / NOISE (凶) | 全ステータス |
| 方位で絞る        | プルダウン | 全方位 / 北 / 北東 / 東 / 南東 / 南 / 南西 / 西 / 北西 | 全方位       |
| 総家賃上限 (万円) | 数字       | —                                                      | 空           |
| 築年数上限 (年)   | 数字       | —                                                      | **5**        |
| 駅徒歩上限 (分)   | 数字       | —                                                      | 空           |
| 専有面積下限 (㎡) | 数字       | —                                                      | 空           |
| 最小利回り偏差値  | 数字       | —                                                      | 空           |
| 総合スコア下限    | 数字       | —                                                      | 空           |

**必須項目はありません。数字の上限・下限も設定されていません。**

> **重点確認項目（最重要）**
> **「築年数上限」の初期値が「5」になっています。**
> つまり、この画面を開いた瞬間から**築5年以内の物件しか出ていません**。
> しかもこの条件だけは検索そのものにも効くため、「物件が少ない」の原因になりやすい箇所です。
> ここを空にすると結果件数が大きく増えます。QAの最初の確認項目にしてください。

**その他の注意**

- 「吉凶ステータス」は部分一致です。`OPTIMAL` を選ぶと `OPTIMAL_BOOST` の物件も出ます
- 「駅徒歩上限」を入れると、**徒歩分数が分からない物件は除外されます**
- 「築年数上限」も同様に、**築年数が分からない物件は除外されます**

## 6. 【条件③】同行者・合流する人

複数人で引っ越す場合に使います。**人ごとに別々の出発地から方位を測ります。**

### 5-1. 登録できること

**人数の上限はありません。**（画面にも内部処理にも制限がありません）

| 項目                   | 内容                     | 初期値              |
| ---------------------- | ------------------------ | ------------------- |
| 名前                   | 「母」「父」など         | 「同行者1」など自動 |
| 生年月日時             | 日付＋時刻               | 空                  |
| 出発地の緯度・経度     | 数字2つ                  | 空                  |
| 移動しない（現地在住） | チェック                 | オフ                |
| 比重                   | 数字（0.5〜10、0.5刻み） | 1                   |
| 削除                   | ボタン                   | —                   |

追加方法は2通り：

- 「保存済みプロフィールから追加」（すでに登録した人の一覧から選ぶ。**追加済みの人は候補から消えます**）
- 「＋ 手入力で同行者を追加」

> **重点確認項目**：**生年月日時を空のままにすると、その人は判定から丸ごと外れます**。
> 画面上に警告は出ません。「登録したのに結果に出てこない」場合はここを疑ってください。

### 5-2. 「移動しない（現地在住）」の扱い

引越し先にすでに住んでいて動かない人は、このチェックを付けます。

- チェックを付けると**緯度・経度の入力が使えなくなります**（グレーアウト）
- 方位が発生しないので、**判定の計算から完全に外れます**
- ただし**一覧には名前が残り、横に「(移動なし)」と表示されます**（方位や点数は出ません）
- **移動する人が0人になった場合**、点数は0、全員一致は不成立になります

### 5-3. 判定方法（まとめ方）

| 表示ラベル             | 意味                                                                                            |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| **全員一致**（初期値） | 最も評価の低い人に合わせる。**誰か1人でも避けるべき方位・期間なら、その日・その場所は選ばない** |
| 平均                   | 全員の点数を等しく平均する                                                                      |
| 重み付き               | 人ごとの「比重」で平均する。世帯主を重く、同行者を軽く、といった配分ができる                    |

> 「重み付き」で全員の比重が0の場合は、自動的に「全員一致」と同じ動きになります。

### 5-4. 結果の見え方

物件カードの中に「全員の方位」という枠が出ます。

```
全員の方位                              一致度 72
  自分   南東   85
  母     北     28   ← 赤い太字（避けるべき判定）
  父     (移動なし)
┌────────────────────────────────┐
│ この日は 母 が移転不可           │  ← 赤い枠
└────────────────────────────────┘
```

- 点数が70以上は緑の太字、避けるべき判定は赤の太字
- 「一致度」は**移動する人が2人以上のときだけ**出ます（1人以下は非表示）
- 一致度が低い＝片方だけに良い場所、という意味です

## 7. 【条件④】評価軸の重み

### 6-1. 重み付けプリセット（全10種類）

| ラベル                 | 説明（画面のツールチップ）                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **バランス**（初期値） | 割安さ・方位・住みやすさを均等に見る既定の配分。                                                                     |
| 割安重視               | 市場の歪みだけを取りにいく。裁定機会の発見用。                                                                       |
| 開運重視               | 方位と暦を最優先し、条件面は補助的に見る。                                                                           |
| 合流重視               | 同行者・合流する親族と一緒に動く前提。全員にとって方位が揃っていること、そして全員が動ける日が近いことを最優先する。 |
| 通勤・利便             | 駅の近さと生活圏の維持を最優先する。                                                                                 |
| 広さ・住環境           | 面積と建物条件を厚く見る。家族での住み替え向け。                                                                     |
| 築浅・建物重視         | 築年数と所在階を最重要視する。設備の新しさ優先。                                                                     |
| 家計重視               | 月額予算に収まるかを最優先する。予算の設定が前提。                                                                   |
| 穴場発掘               | まだ広く出回っていない新着・低掲載の出物を拾う。                                                                     |
| カスタム               | スライダーで軸ごとの重みを自由に決める                                                                               |

**「軸ごとのスライダーを表示」を押すと11本のスライダー**（0〜100）が出ます。動かすと自動で「カスタム」に切り替わります。

> **重要な仕様**：**プリセットや重みを変えても、再検索は走りません**（画面内で計算し直すだけ）。
> 結果が即座に並び替わるのが正常です。

### 6-2. 月額予算

「月額予算 (万円)」に数字を入れると、「予算適合」の軸が計算されます。
**空、または0以下の場合はこの軸が計算されません**（評価対象外になります）。

### 6-3. 候補の集め方（全6種類）

| ラベル               | 説明                                                         |
| -------------------- | ------------------------------------------------------------ |
| **割安順**（初期値） | ㎡単価の安い順に候補を集める。裁定機会の探索に最も直結する。 |
| 総合バランス順       | ㎡単価・築年数・駅徒歩・面積の順位を合成して候補を集める。   |
| 築浅順               | 築年数の浅い順。                                             |
| 広い順               | 専有面積の広い順。                                           |
| 駅近順               | 駅徒歩の短い順。                                             |
| 新着順               | 掲載開始の新しい順。                                         |

> **重点確認項目**：**これを変えたときだけ、データを取り直す再検索が走ります**。
> 重みを変えても走りません。この違いを理解していないと「反映されない」と誤報告します。

### 6-4. 天中殺の扱い（全5種類）

| ラベル                           | 説明                                                                      |
| -------------------------------- | ------------------------------------------------------------------------- |
| **厳格（年・月・日）**（初期値） | 年・月・日のいずれかが空亡なら移転不可として扱う。最も慎重な扱い          |
| 年天中殺は除く                   | 年天中殺は判定から外し、月・日の空亡だけを不可とする                      |
| 日のみ                           | 日の空亡だけを不可とする。最も適用範囲が狭い                              |
| 弱める（禁止しない）             | 移転不可にはせず、その期間の吉凶を弱める（**吉も凶も0.6倍で50に寄せる**） |
| 使わない                         | 天中殺を判定に使わず、九星気学の方位だけで見る                            |

選ぶと下に説明文と「根拠:」が表示されます。

### 6-5. その他の2つのチェック

| チェック                                   | 初期値   | 効果                                                  |
| ------------------------------------------ | -------- | ----------------------------------------------------- |
| やむを得ない移動（転勤など）として扱う     | オフ     | オンにすると天中殺でブロックせず、影響を0.7倍に弱める |
| 避けるべき方位・期間の物件を最下位に沈める | **オン** | オフにすると、凶方位の物件も総合点順に混ざる          |

## 8. 検索結果の見方

### 8-1. 物件カードに出るもの

```
┌────────────────────────────────────────────┐
│ ○○マンション 302号室            [ 大吉 ]  │ ← 物件名（リンク）＋バッジ
│ 愛知県名古屋市中区…                        │
│ ─────────────────────────────────────────  │
│ 総賃料: 8.5万円      利回り偏差値: 64.2    │
│ 広さ/築年/徒歩: 42㎡ / 築3年 / 7分         │
│ 近隣相場比: -12%     掲載: 5日 / 2社       │
│ 方位・吉凶: 南東 (天道方位)                │
│ ─────────────────────────────────────────  │
│ 方位  ████████░░ 82                        │ ← 軸バー（最大5本）
│ 割安  ██████░░░░ 61                        │
│ 広さ  █████░░░░░ 55                        │
│ ─────────────────────────────────────────  │
│ ★★★★☆  総合 72.4 （軸カバー 82%）        │
│ ［吉凶タイムライン・ヒートマップ］          │
└────────────────────────────────────────────┘
```

**「軸カバー」とは**：評価に使う予定の項目のうち、実際にデータがあった割合です。
100%未満のときだけ表示されます。データが無い項目は「0点」ではなく**評価から除外**され、
残りの項目で計算し直されます。

**おすすめ度（★）の決まり方**

| ★の数 | 条件                                                 |
| ----- | ---------------------------------------------------- |
| ★1    | **吉凶が「凶」系のときは、点数に関係なく無条件で★1** |
| ★5    | 総合80点以上                                         |
| ★4    | 総合70点以上                                         |
| ★3    | 総合60点以上                                         |
| ★2    | 総合50点以上                                         |
| ★1    | 50点未満                                             |

### 8-2. 11の評価軸

すべて0〜100点。**50点が「調べた物件全体の真ん中」**です。

| #   | 軸の名前（短縮）       | 意味                                                                                    |
| --- | ---------------------- | --------------------------------------------------------------------------------------- |
| 1   | 広域割安度（割安）     | 検索条件に合う全物件の㎡単価と比べた安さ。50が相場並み                                  |
| 2   | 近隣割安度（近隣）     | 同じ市区町村の㎡単価中央値との比較。**同じ市区町村のデータが8件未満だと計算されません** |
| 3   | 方位・吉凶（方位）     | 出発地から見た方位と暦の判定                                                            |
| 4   | 同行者との一致（一致） | 全員の点数の開き。**移動する人が2人以上のときだけ計算**                                 |
| 5   | 時期の開き（時期）     | 走査期間のうち全員が動ける日の割合                                                      |
| 6   | 駅アクセス（駅）       | 徒歩3分以内が100点、20分で約35点、40分で0点                                             |
| 7   | 現住地から近い（近さ） | 5km以内が100点、50kmで0点                                                               |
| 8   | 広さ（広さ）           | 面積の相対評価＋1部屋あたりの広さ                                                       |
| 9   | 建物・築年（建物）     | 築年数が中心。地下・1階は減点、3階以上は加点、新築は加点                                |
| 10  | 市場妙味（妙味）       | 掲載の新しさと、掲載している会社が少ないか                                              |
| 11  | 予算適合（予算）       | 予算の70%以下で100点、予算ちょうどで60点、予算+45%超で0点                               |

## 9. 時期の探索

「時期の走査 (日先)」という設定です。**同行者がいなくても効きます。**

| 選択肢                                                        | 初期値         |
| ------------------------------------------------------------- | -------------- |
| 見ない(0) / 14日先まで / 30日先まで / 60日先まで / 90日先まで | **30日先まで** |

**結果の3パターン**

| 状況                             | 表示                                                                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 動ける日がある                   | 「全員で動ける直近日: **2026-09-14**（30日中 12日）」（日付は緑の太字）                                                                            |
| 全期間ダメ＋原因の人が特定できる | 赤字で「走査した30日はすべて不可（**母: 天中殺（この期間は移転不可）**）。**移転先を変えても開かないため、時期そのものを見直す必要があります。**」 |
| 全期間ダメ＋原因が特定できない   | 琥珀色で「今後30日で全員が動ける日はありません」                                                                                                   |

**原因として表示される理由の種類**：天中殺（この期間は移転不可）／空亡／五黄殺／暗剣殺／歳破／本命殺／本命的殺／月命殺／月命的殺／月交点ノイズ

> **なぜ重要か**：「時期を変えれば解決する問題」と「物件を変えないと解決しない問題」を
> 区別するための表示です。年単位の天中殺は移転先を変えても開かないため、この文言が出ます。

## 21. テスト観点のチェックリスト

### 初期状態

- [ ] 設定が空のブラウザで開く → 「出発地を設定してください」の警告が出て検索が止まること
- [ ] 出発地を入れる → 自動で検索が始まること

- [ ] 築年数上限を空にする → 結果件数が増えること

### 条件の変更と再検索の有無

- [ ] 重みプリセットを変える → **再検索は走らず**、並び順だけ変わること
- [ ] 「候補の集め方」を変える → **再検索が走る**こと
- [ ] **初回表示**（保存済み設定が無い端末）→ 検索範囲が「範囲を限定しない」で、地図が出発地を中心にズームした状態から始まること。この時点で結果が数秒で出ること
- [ ] 「出発地から50km以内に絞る」を選ぶ → 出発地から50kmの検索になること
- [ ] 「範囲を限定しない」のままズームを引いて日本全体を映す → **県別の色分けと掲載数の数字が出る**こと。**このとき検索は走らない**（読み込み表示が出ない）こと
- [ ] 俯瞰から任意の県へズームインする → ズーム10を超えたところで、見えている範囲の検索が走って物件ピンが出ること
- [ ] 「範囲を限定しない」を選ぶ → 地図が日本全体へ引き、俯瞰になること。**その状態から任意の場所を拡大でき、勝手に引き戻されないこと**
- [ ] 都道府県を選ぶ → 地図の中心がその県へ移動すること
- [ ] スマート検索に「2LDK 8万円以下 北東」→ チップが3つ出て、一覧が絞られること
- [ ] チップの × を押す → その条件だけ外れること
- [ ] 物件カードをクリック → 詳細パネルが開き、地図がその物件へ寄ってリングが出ること

- [ ] URLで `prefecture=all&radiusKm=30` を渡す → 画面とAPIの両方が50kmへ正規化されること
- [ ] 「月相タイミング補正」をオフにしてリロード → **オンに戻る**こと（保存されない仕様）

### 同行者

- [ ] 同行者を3人以上追加できること（上限なし）
- [ ] 生年月日を空のまま検索 → その人が結果の「全員の方位」に出てこないこと
- [ ] 「移動しない」をオンにする → 緯度経度が入力できなくなること
- [ ] 「移動しない」の人が「(移動なし)」と表示され、点数が出ないこと
- [ ] 「全員一致」で1人でも凶 → その物件の評価が下がること
- [ ] 「平均」に切り替える → 評価が変わること
- [ ] 全員を「移動しない」にする → 破綻せずに動くこと

### 時期の探索

- [ ] 「見ない(0)」にする → 「時期」の軸が評価対象外になること（軸カバーが下がる）
- [ ] 年天中殺に当たる生年月日で試す → 「移転先を変えても開かないため…」の赤字が出ること

### 結果の表示

- [ ] 表示範囲の件数が101件以上 → 「※100件以下で一覧表示可能」と出て一覧に切り替えられないこと
- [ ] 100件以下にズームイン → 「一覧を表示」ボタンが出ること
- [ ] **地図のピンの★と、カードの★を突き合わせる**（重みを「開運重視」等に変えてから確認）
- [ ] 凶方位の物件が★1になっていること（点数が高くても）
- [ ] 「避けるべき方位・期間の物件を最下位に沈める」をオフ → 凶物件が上位に混ざること
- [ ] 「軸カバー」が100%未満の物件で、データが無い軸が「—」表示になっていること

### カレンダー

- [ ] 再計算中はカレンダーがクリックできなくなること
