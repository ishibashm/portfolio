# 06. 引越しの日取りを選ぶ（カレンダー）

[← 目次に戻る](./README.md) ｜ [共通仕様](./00-common.md)

| | |
|---|---|
| **URL** | `/calendar` |
| **画面名** | 引越しの日取りを選ぶ |
| **ログイン** | 不要（誰でも見られる） |
| **サイドバー** | 「引越しの日取りを選ぶ」が選択状態になる |
| **この画面でやること** | 引越し・契約・搬入に向いた日を探す |

---

## 1. この画面は何をするところか

「どこへ引っ越すか」ではなく「**いつ動くか**」を決める画面です。

この画面には、性格の違う**2つの道具が縦に並んでいます**。QAとしてはまず、この2つが別物であることを押さえてください。

```
┌──────────────────────────────────────────────────┐
│ ① 見出し「引越しの日取りを選ぶ」＋説明文          │
├──────────────────────────────────────────────────┤
│ ② 【道具1】三盤すべてが吉になる日を出す           │
│    条件を入れて「吉日を出す」を押す               │
│    → 方位ごとに、良い日が一覧表で出る             │
│    → 各行から物件検索へ飛べる ★重要              │
├──────────────────────────────────────────────────┤
│ ③ 読み物「引越しの日取りの決め方」                │
│    → 他の画面へのボタン2つ                        │
├──────────────────────────────────────────────────┤
│ ④ 【道具2】月間カレンダー                         │
│    1か月ぶんのマス目。日を押すと右に詳細が出る     │
│    → こちらは他画面へ飛ばない（見るだけ）         │
└──────────────────────────────────────────────────┘
```

> **よくある誤解**：②と④は**連動していません**。
> ②で「良い日」と出た日が、④のカレンダーで低い点数になっていることがあります。
> 計算のもとにしている考え方が違うためで、不具合ではありません（→ 8章）。

画面上部には「六曜・天赦日・一粒万倍日・月相」というラベルと、点滅する丸い印があります。これは飾りです。

## 2. 【道具1】三盤すべてが吉になる日を出す

### 2-1. 入力項目（全7つ）

上から（画面幅により1列／2列／3列に並び替わります）。

| # | 表示ラベル | 入れ方 | 初期値 | 必須 | 制限 |
|---|---|---|---|---|---|
| 1 | 生年月日（時刻まで分かれば入れる） | 日付＋時刻を選ぶ | 空（※） | **必須** | 上限・下限なし。未来の日付も入る |
| 2 | 現住地の経度 | 数字を入力 | 空（※） | **必須** | 上限・下限なし。例として「136.9008（名古屋）」が薄字で出る |
| 3 | 現住地の緯度（任意） | 数字を入力 | 空（※） | 任意 | 例として「35.1430」が薄字で出る |
| 4 | 方位 | プルダウン | **全方位（多い順に並べる）** | — | 下表の9択 |
| 5 | 開始日 | 日付を選ぶ | **今日** | — | 上限・下限なし。**過去の日付も入れられる** |
| 6 | 走査期間 | プルダウン | **12ヶ月** | — | 3ヶ月 / 6ヶ月 / 12ヶ月 / 24ヶ月 |
| 7 | 天中殺の扱い | プルダウン | **厳格（年・月・日）** | — | 下表の5択 |

（※）以前この端末で他の画面に入力した「生年月日・経度・緯度」が残っていれば、それが自動で入ります。

**「方位」の選択肢（9つ）**
全方位（多い順に並べる） / 北 / 北東 / 東 / 南東 / 南 / 南西 / 西 / 北西

> 「中央（中宮）」は選択肢にありません。

**「天中殺の扱い」の選択肢（5つ）**

| 表示ラベル | どういう扱いになるか |
|---|---|
| **厳格（年・月・日）**（初期値） | 年・月・日のどれかが天中殺なら、その日は「不可」になる。いちばん厳しい |
| 年天中殺は除く | 年の天中殺は無視し、月と日だけを見る |
| 日のみ | 日の天中殺だけを見る。いちばん緩い |
| 弱める（禁止しない） | 不可にはしない。吉凶の効き目を弱めるだけ |
| 使わない | 天中殺をまったく見ない |

各選択肢にマウスを乗せると説明文が出ます。

> **重要な仕様**：天中殺の扱いを変えても、**一覧に並ぶ日そのものは変わりません**。
> 変わるのは「不可」の印が付く日数と、最終的に使える日数の数え方だけです。
> 「モードを変えたのに日付が増減しない」は正しい動きです。

### 2-2. 「吉日を出す」を押したときの流れ

```
「吉日を出す」を押す
   │
   ├─ 生年月日 か 経度 が空 ──▶ 赤い枠で
   │                          「生年月日と現住地の経度を入力してください。」
   │                          （このとき通信は発生しない）
   │
   └─ 両方入っている
        │
        ├─ ボタンがグレーになり、中でくるくる回る（押せない）
        │
        ├─ 失敗 ──▶ 赤い枠にエラー文（下表）／それまでの結果は消える
        │
        └─ 成功
             ├─ 該当0日 ──▶ 黄色い枠で
             │              「走査した期間に、三盤すべてが吉になる日は
             │                ありませんでした。期間を延ばすか、方位を
             │                変えて試してください。」
             │
             └─ 該当あり ──▶ 方位ごとのカードが並ぶ
```

**エラー文の一覧**

| どんなとき | 画面に出る文言 |
|---|---|
| 生年月日が送られていない | 生年月日が必要です。本命星と天中殺はここからしか決まりません。 |
| 生年月日の形式が不正 | `INVALID_BIRTH_DATE` ← **英語のまま出ます**（日本語文言なし） |
| 経度が数字として読めない | 現住地の経度が必要です。方位も太陽時もここを起点に決まります。 |
| 終了日が開始日より前 | `INVALID_RANGE` ← 英語のまま |
| 方位の指定が不正 | `INVALID_DIRECTION` ← 英語のまま |
| その他の内部エラー | エラーの内容がそのまま出る |

> **報告対象になり得る点**：一部のエラーが英語の記号のまま画面に出ます。
> 日本語化されていないのは実装どおりですが、利用者には意味が伝わりません。

### 2-3. 結果の見た目

まず、本命星と天中殺の情報が1行出ます。その下に**方位ごとのカード**が並びます。

- 「全方位」を選んだ場合、**使える日数が多い方位が上**に来ます。
- **0日だった方位のカードは、そもそも表示されません**（空カードは出ない）。

**カードの見出し行**

```
南東    三盤吉 12 日 ／ 天中殺で不可 3 日 ／ 実質 9 日
                          年盤の期限: 2027-02-03 まで（翌日から「歳破」に変わる）
```

- 「天中殺で不可」「実質」は、不可の日がある場合のみ出ます。
- 「年盤の期限」は、方位の良し悪しが切り替わる日を示します。**計算できなかった場合はこの行が出ません**。
- 画面が狭いと、この見出し行は折り返されます。

**カードの表（7列）**

| 列 | 中身 |
|---|---|
| 日付 | `2026-09-14（月）` のように曜日つき |
| 年盤 | その日の年単位の吉凶（下表のラベル） |
| 月盤 | 月単位の吉凶 |
| 日盤 | 日単位の吉凶 |
| 暦 | 縁起のよい日のバッジ（琥珀色）。**天赦日 / 一粒万倍日 / 大安 / 天道** の4種のみ |
| 天中殺 | 不可なら「不可（年・月・日 のうち該当するもの）」を琥珀の太字。該当なしは「—」 |
| 物件 | 「この条件で探す」リンク |

**吉凶ラベルの全種類**

| 画面の表示 | 意味 |
|---|---|
| 大吉 | 最も良い |
| 吉 | 良い |
| 平 | 良くも悪くもない。**「吉日」には数えられない** |
| 注意 | 注意が必要 |
| 五黄殺 / 暗剣殺 / 歳破・月破 / 本命殺 / 本命的殺 / 月命殺 / 月命的殺 / 空亡 / 月交点 / 天中殺 | いずれも「凶」の種類 |

> **確認ポイント**：この対応表にない値が来ると、**英語の記号がそのまま表示されます**。
> 表の中に英大文字の文字列（例：`NOISE_XXX`）が見えたら報告してください。

**行の色**：天中殺で不可の行は、**行全体がうすい琥珀色**になります。

### 2-4. 「この条件で探す」で物件検索へ引き継ぐ

表の各行の右端のリンクです。マウスを乗せると「〇月〇日に 南東 へ移る前提で物件を探す」と出ます。

```
   カレンダーの1行                     物件を方位で探す画面
   ────────────                     ──────────────────
   日付        ─────────────▶  移転予定日として設定
   方位        ─────────────▶  絞り込みの方位として設定
   天中殺の扱い ────────────▶  同じ設定を引き継ぐ
   経度        ─────────────▶  出発地の経度（入力済みなら）
   緯度        ─────────────▶  出発地の緯度（入力済みなら）
```

飛び先は `/relocation/arbitrage` です。

> **重点確認項目**：引き継ぎ先の画面で、**カレンダーで選んだ日付・方位・天中殺の扱いが
> そのまま反映されているか**を必ず確認してください。この4つは、受け取り側で形式が正しいかを
> 検査したうえで採用され、**おかしな値は黙って捨てられます**（エラーは出ません）。
> 「引き継がれない」ように見えても画面上は無言なので、テストで見つけるしかない箇所です。

## 3. 読み物「引越しの日取りの決め方」

操作のない説明文です。以下が並びます。

1. 説明文
2. 番号付きの手順5項目（本命星を知る → 年盤 → 月盤 → 天中殺 → 日の吉凶）
   - 1項目めの中に「早見表」という文字リンク（→ `/houi`）
3. ボタン2つ
   - 「本命星と吉方位を調べる」→ `/houi`
   - 「物件を方位で探す」→ `/relocation/arbitrage`
4. 小さな注意書き：「六曜や天赦日は暦の考え方であり、科学的に効果が確認されたものではありません。…」

> この注意書きは**必ず表示されている必要があります**。消えていたら報告してください。

## 4. 【道具2】月間カレンダー

### 4-1. 構成

画面幅が**とても広いとき（1536px以上）だけ**、左にカレンダー・右に詳細が横並びになります。
それより狭い場合（一般的なノートPCを含む）は、**カレンダーの下に詳細が縦に並びます**。

```
【1536px以上】                      【それ未満（スマホ含む）】
┌────────────┬────────┐             ┌──────────────────┐
│ カレンダー  │ 選んだ  │             │   カレンダー      │
│            │ 日の詳細│             ├──────────────────┤
└────────────┴────────┘             │   選んだ日の詳細  │
                                    └──────────────────┘
```

カレンダー側は上から：
1. 「// Cosmic Calendar Telemetry」というラベル（英語のまま）
2. `＜` ／ `2026.08` ／ `＞`（前月・当月表示・翌月）
3. 曜日の見出し（**SUN〜SAT の英語3文字**）
4. 7列のマス目
5. 「// Legend」＝記号の凡例
6. 「// Month Aggregate」＝その月の集計4つ
7. 「⚙️ [Astro Telemetry Config]」＝開閉できる設定欄

> **報告対象になり得る点**：この部分は**見出しやラベルが英語のまま**です。
> 日本語のページの中で唐突に英語が出るので、翻訳漏れとして扱うか、
> デザインとして許容するかは仕様判断が必要です。事実として記録しておきます。

### 4-2. 操作できるもの

| 操作 | 挙動 |
|---|---|
| `＜` `＞` | 前月・翌月へ。**上限も下限もなく、何年でも遡れる／進める** |
| 日のマスを押す | 詳細パネルがその日の内容に変わる。**ページ移動はしない** |
| 当月以外のマス | 薄く表示され、**押せない** |
| ⚙️ の見出し | 設定欄を開閉。生年月日が未設定なら**最初から開いた状態** |
| Birth Date & Time (JST) | 生年月日時を入れる。**入れた瞬間にこの端末に保存される** |
| Birth Longitude | 出生地の経度。**初期値 139.6917**（数字として読めない場合もこの値になる） |

月を切り替えると、その月に「今日」があれば今日が、なければその月の1日が自動で選ばれます。

### 4-3. 1つのマスに表示されるもの

```
┌──────────────┐
│ 14        🌓 │  左上：日付／右上：月の満ち欠け
│              │
│ ●     赦 万  │  左下：点数を表す色つきの丸／右下：吉日マーク
└──────────────┘
```

**日付の数字の色**

| 色 | 条件 |
|---|---|
| ローズ（赤み） | 日曜、または祝日 |
| 水色 | 土曜 |
| グレー | 平日 |

**マスの枠の色**

| 枠 | 条件 |
|---|---|
| 琥珀 | 天赦日 |
| 緑 | 一粒万倍日 |
| グレー | それ以外 |
| アクセント色＋光る | 今選んでいる日 |
| 左上に「⌐」型の角飾り | 今日 |

天赦日と一粒万倍日が重なった場合、**枠は琥珀（天赦日）が優先**されます。

**吉日マーク（凡例に出る5種類）**

| 記号 | 意味 | 色 | 出る条件 |
|---|---|---|---|
| 赦 | 天赦日 | 琥珀 | 常に |
| 万 | 一粒万倍日 | 緑 | 常に。ただし**天赦日の日には出ない**（赦が優先） |
| 殺 | 天中殺 | 紫・**点滅する** | **生年月日を入れているときだけ** |
| 破 | 日破 | ローズ | **生年月日を入れているときだけ** |
| 合 | 支合 | 水色 | **生年月日を入れているときだけ** |

> **確認ポイント**：凡例には常に5つとも並びますが、生年月日を入れていないと
> 「殺・破・合」はマスに一度も出ません。「凡例にあるのにマスに無い」は仕様です。

**点数を表す丸（左下）**

| 色 | 点数 |
|---|---|
| 緑（光る） | 75点以上 |
| 藍（光る） | 60点以上 |
| 灰（光らない） | 45点以上 |
| 赤（光る） | 45点未満 |

### 4-4. 点数の決まり方

60点を基準に、以下を足し引きします（**0〜100点の範囲に収まる**）。

| 要素 | 増減 |
|---|---|
| 六曜：大安 | +15 |
| 六曜：友引 | +10 |
| 六曜：先勝・先負 | +2 |
| 六曜：赤口 | −10 |
| 六曜：仏滅 | −15 |
| 一粒万倍日 | +15 |
| 天赦日 | +25 |
| 水星の逆行 | −6 |
| 金星の逆行 | −8 |
| 火星の逆行 | −8 |
| 満月または新月 | +5 |
| 天中殺の日 | −15 |
| 日破の日 | −10 |
| 支合の日 | +10 |

木星と土星の逆行は**表示されるだけで点数に影響しません**。

### 4-5. 月の集計（「// Month Aggregate」）

その月のマスだけを対象に、4つのタイルが出ます。

| タイル | 内容 |
|---|---|
| 吉日 (Lucky) | 縁起のよい日の日数 |
| 天中殺 (Void) | 天中殺の日数 |
| 平均 (Avg) | その月の平均点 |
| 最良 (Peak) | 最も点数が高い日と、その点数 |

### 4-6. 日を選んだときの詳細パネル

上から順に以下が出ます。

| 項目 | 内容 |
|---|---|
| 日付 | `2026.08.14 (Fri)`。祝日ならその名前のバッジ |
| Alignment Rating | 点数と横棒グラフ（色は4段階と同じ） |
| Lunar Phase Telemetry | 月の満ち欠けの記号・名前・説明 |
| Solar seasonal Telemetry | 二十四節気（例：春分）と、太陽の位置の角度 |
| Calendar Fortunes | 六曜（例：大安 (Taian)）と、縁起の良い日（無ければ「特になし」） |
| Personal Fortune Telemetry | **生年月日を入れているときだけ**表示。その日の干支、生まれの干支、天中殺の期間、相性バッジ |
| Planetary Retrogrades | 水星・金星・火星・木星が「逆行」か「順行」か。**土星は計算されているのに表示されない** |
| Next Best Action Recommendation | 定型のアドバイス文（下記） |

**相性バッジの4種類**：天中殺 (Void Day) / 対沖 (Clash / 日破) / 支合 (Harmony / 合運) / 平常 (Neutral Day)

**アドバイス文は、上から順に最初に当てはまったもの1つだけ**が出ます。

| 優先 | 条件 | 出だし |
|---|---|---|
| 1 | 天中殺の日 | 🌀 [天中殺/VOID] … |
| 2 | 日破の日 | ⚡ [日破/CLASH] … |
| 3 | 支合の日 | 🤝 [支合/HARMONY] … |
| 4 | 80点以上 | 🪐 [OPTIMAL_ALIGNMENT] … |
| 5 | 65点以上 | ✨ [FAVORABLE_ENERGY] … |
| 6 | 逆行の惑星が3つ以上 | ⚠️ [COMMUNICATION_VOLATILITY] … |
| 7 | 45点未満 | 🛑 [ENERGY_DISSIPATION] … |
| 8 | 上記以外 | 🌐 [NEUTRAL_COGNITION] … |

> **確認ポイント**：点数が高くても、天中殺・日破の日はそちらのアドバイスが優先されます。
> 「90点なのに『避けましょう』と出る」は仕様どおりです。

## 5. 読み込み中・0件・エラーのまとめ

| 場所 | 読み込み中 | 0件 | エラー |
|---|---|---|---|
| 三盤すべてが吉になる日 | ボタンがグレー＋回転マーク | 黄色い枠のメッセージ | 赤い枠のメッセージ |
| 月間カレンダー | **表示なし**（一瞬マスが空になることがある） | 該当なし（必ず1か月分出る） | **画面には出ない**（静かに計算不能の項目が消えるだけ） |

月の満ち欠けの計算に失敗した場合だけ、例外的に
「中高月 🌓 月相データの算出に一時的な障害があります。」という文が出ます。

## 6. 端末に保存される設定

| 保存されるもの | どこで保存されるか | リロード後 |
|---|---|---|
| 生年月日時（カレンダー側の設定欄） | 入力した瞬間 | **残る** |
| 出生経度（カレンダー側の設定欄） | 入力した瞬間 | **残る** |
| 三盤の吉日パネルの入力7項目 | **保存されない** | **消える**（※） |

（※）ただし、他の画面で入力済みの「生年月日・経度・緯度」があれば、それが初期値として入ります。

> **テスト時の注意**：条件を変えて何度も試す場合、
> 上の「三盤の吉日パネル」は再読み込みのたびに入力し直しになります。
> 逆に、カレンダー側の生年月日は**ブラウザを閉じても残る**ので、
> 別のテストケースに移る前に消してください（ブラウザのサイトデータ削除で消えます）。
> 参考：保存名は `wealth_birthDate` / `wealth_birthLon` / `tactical_config_v1` です。

## 7. 画面幅による違い

| 部分 | スマホ幅 | タブレット～ノートPC | 大画面（1536px以上） |
|---|---|---|---|
| 三盤の吉日パネルの入力欄 | 1列 | 2列（768px〜）／3列（1024px〜） | 3列 |
| 三盤の吉日パネルの結果表 | **横スクロールになる** | 横スクロールになることあり | 収まる |
| 月間カレンダーと詳細 | 縦積み | **縦積み** | 横並び（2:1） |

## 8. QAが知っておくべき「食い違い」

この画面には、**同じ言葉が別の計算で出ている箇所**があります。事前に知らないと不具合と誤認します。

### 8-1. 「天中殺」が2か所にあり、結果が違うことがある

| | 三盤の吉日パネル | 月間カレンダー |
|---|---|---|
| 何を見るか | 年・月・日の3つ | **日だけ** |
| 効かせ方の選択 | できる（5種類） | **できない**（常に「日だけ」相当） |
| 計算のもと | 天体の位置から算出 | 暦のライブラリから算出 |

→ **同じ日について、片方が「天中殺」でもう片方が「天中殺でない」ことがあり得ます。**
これは実装の差であり、報告する場合は「仕様確認」として起票してください。

### 8-2. 「点数が高い日」と「三盤吉の日」は別物

月間カレンダーの点数は六曜・惑星の逆行などが中心で、**方位の吉凶を見ていません**。
一方、三盤の吉日パネルは方位の吉凶だけを見ています。両者が一致しないのは正常です。

### 8-3. 「平」は吉日に数えない

吉凶ラベルの「平」は、良くも悪くもない扱いですが、**「三盤すべてが吉」の条件には合格しません**。
「平・平・平」の日は一覧に出てきません。

## 9. テスト観点のチェックリスト

### 入力まわり
- [ ] 生年月日を空のまま「吉日を出す」→ 赤枠のメッセージが出て、通信が発生しないこと
- [ ] 経度を空のまま「吉日を出す」→ 同上
- [ ] 経度に文字を入れて実行 → 「現住地の経度が必要です。…」が出ること
- [ ] 開始日に**過去の日**を入れられること（入力自体は制限されない）
- [ ] 走査期間を24ヶ月にして実行 → 応答が返ること（**時間がかかる想定**。8方位×24ヶ月が最も重い）
- [ ] 生年月日を「日付だけ（時刻なし）」で保存した状態から画面を開く → 時刻に 12:00 が補われて表示されること

### 結果の表示
- [ ] 「全方位」で実行 → 使える日数が多い方位が上に来ていること
- [ ] 0日の方位のカードが表示されないこと
- [ ] 天中殺で不可の行が、うすい琥珀色になっていること
- [ ] 吉凶の列に、英大文字の記号（例 `NOISE_…`）がそのまま出ていないこと
- [ ] 「暦」列のバッジが、天赦日 / 一粒万倍日 / 大安 / 天道 の4種以外に出ていないこと

### 天中殺の扱いの切り替え
- [ ] 「厳格」→「使わない」に変えて再実行 → **日付の並びは変わらず**、「不可」の日数だけが変わること
- [ ] 「日のみ」が「厳格」より不可日数が少ない（または同数）こと

### 引き継ぎ（最重要）
- [ ] 「この条件で探す」を押す → `/relocation/arbitrage` に移動すること
- [ ] 移動先で、**押した行の日付**が移転予定日に入っていること

- [ ] 緯度を入れずに実行 → 引き継ぎ先で緯度が空でもエラーにならないこと
- [ ] 引き継ぎ先で画面を再読み込み → 引き継いだ日付が消えないこと

- [ ] 月を切り替えたとき、その月の1日が自動で選ばれること（今日を含む月なら今日）
