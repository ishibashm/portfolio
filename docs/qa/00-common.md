# 00. 全画面に共通する仕様

[← 目次に戻る](./README.md)

このページは、どの画面を触っていても同じように効いてくる「土台の決まりごと」をまとめたものです。
個別画面の仕様書を読む前に、ここを一度読んでおくと、各画面の説明が短く済みます。

---

## 1. 画面の枠組み

どの画面も、次の2つの部品で出来ています。

```
┌─────────────┬───────────────────────────────────┐
│             │                                   │
│  サイドバー  │        各画面の中身                │
│  （共通）    │        （画面ごとに違う）           │
│             │                                   │
│             │                                   │
└─────────────┴───────────────────────────────────┘
```

例外は1つだけです。**共有ページ（`/visualizer/share/…`）ではサイドバーが表示されません**。
（他人に見せるための公開ページなので、サイト内メニューを出さない作りになっています）

---

## 2. サイドバー（全画面共通メニュー）

### 2-1. 中に入っているもの

上から順に、以下が並びます。

| 位置 | 表示 | 内容 |
|---|---|---|
| 最上部 | ロゴ | コンパスのアイコン ＋「Cloud Palette」 |
| メニュー1段目 | ホーム | `/` へ移動 |
| 区切り線 | — | — |
| 見出し | 「引越しを決める」 | 文字だけの見出し。押せません |
| メニュー2段目 | 5項目（下表） | 各画面へ移動 |
| 最下部 | アプリ追加の案内 / ログイン状態 / メニュー開閉 / 稼働ランプ / Katmer Cloud / 制作者名 | 下で説明 |

「引越しを決める」の下に並ぶ5項目は以下です。**この順番と名前が正**です。

| 表示名 | 移動先 | アイコン |
|---|---|---|
| 物件を方位で探す | `/relocation/arbitrage` | 右肩上がりのグラフ |
| 引越し先を試算する | `/relocation/simulator` | 経路 |
| 移住先の地域を比べる | `/relocation/wealth` | 地図 |
| 本命星と吉方位を調べる | `/houi` | コンパス |
| 引越しの日取りを選ぶ | `/calendar` | カレンダー |

> **確認ポイント**：ここに並ぶ項目は1か所（サイトの構成定義）から自動で作られています。
> ここに載っていない画面（例：`/trends`、`/visualizer` など）は、**メニューからは絶対にたどり着けません**。
> これは不具合ではなく仕様です。URLを直接入力すれば開けます。

### 2-2. 今どの画面にいるかの表示

今いる画面のメニュー項目は、**背景がピンク（ローズ色）／文字が白**になり、右端に「>」が出ます。
それ以外の項目はグレー文字で、マウスを乗せると薄いピンクの背景になります。

判定のしかたに癖があります。

- 「ホーム」は、URLがちょうど `/` のときだけ選択状態になります。
- それ以外は、**URLがその項目で始まっていれば選択状態**になります。
  - 例：`/relocation/arbitrage?xxx=1` を開いている → 「物件を方位で探す」が選択状態
  - 例：`/houi/2026/一白水星` を開いている → 「本命星と吉方位を調べる」が選択状態

### 2-3. 画面幅による違い

| | パソコン幅（おおよそ1024px以上） | スマホ・タブレット幅 |
|---|---|---|
| 初期状態 | サイドバーが**出しっぱなし** | サイドバーは**隠れている** |
| 開き方 | 常時表示 | 左上のハンバーガーボタン（三本線）を押す |
| 開いたとき | — | 背景が暗くなり、ぼかしがかかる。背景を押すと閉じる |
| メニュー項目を押したとき | そのまま移動 | 移動して**サイドバーが自動で閉じる** |
| 折りたたみ | 「メニューを閉じる」ボタンで**アイコンだけの細い状態**にできる | この折りたたみボタンは**表示されない** |

折りたたみ状態（細い状態）では次の要素が消えます：文字ラベル、見出し「引越しを決める」、
アプリ追加の案内、ログイン中のメールアドレス、Katmer Cloud リンク、制作者名。
アイコンにマウスを乗せると画面名がツールチップで出ます。

> **注意**：折りたたんだ状態は**保存されません**。ページを再読み込みすると必ず展開状態に戻ります。

### 2-4. サイドバー下部の要素

| 要素 | 表示条件 | 挙動 |
|---|---|---|
| アプリとして追加の案内 | 折りたたんでいないとき | 下の「PWA」の項を参照 |
| メールアドレス | ログイン中かつ折りたたんでいないとき | ログイン中のメールアドレスを1行で表示（長い場合は「…」で省略） |
| 「ログアウト」ボタン | ログイン中 | 押すとログアウトし、`/login` へ移動 |
| 「ログイン」リンク | 未ログイン | `/login?next=（今いるURL）` へ移動 |
| 「メニューを閉じる／展開」 | パソコン幅のみ | 折りたたみ切り替え |
| 「システム稼働中」 | 常時 | 緑の点が点滅する飾り。押せません。**実際の死活監視はしていません** |
| Katmer Cloud | 折りたたんでいないとき | 外部サイト `https://katmer.cloud-palette.com` を**別タブ**で開く |
| Engineered by M. Ishibashi | 折りたたんでいないとき | 文字のみ。押せません |

> **確認ポイント（ログイン表示のタイミング）**
> ページを開いた直後の一瞬は、ログイン状態が「確認中」です。
> この間は**「ログイン」ボタンも「ログアウト」ボタンもどちらも表示されません**（空欄）。
> 確認が終わってからどちらか一方が出ます。一瞬ボタンが無いのは仕様です。

## 3. ログインとアクセス権限

### 3-1. 画面は3種類に分かれます

```
                 ┌──────────────────────────────────────┐
   URLを開く ──▶ │ この画面はログインが要る画面か？        │
                 └───────────┬──────────────┬───────────┘
                             │ いいえ        │ はい
                             ▼              ▼
                    ┌────────────────┐  ┌──────────────────┐
                    │ 誰でも見られる   │  │ ログインしている？ │
                    │ そのまま表示     │  └───┬──────────┬───┘
                    └────────────────┘      │ いいえ    │ はい
                                            ▼           ▼
                                  ┌──────────────┐ ┌────────────────────┐
                                  │ /login へ飛ぶ │ │ 許可されたメール？   │
                                  │ (next=元のURL)│ └──┬──────────┬──────┘
                                  └──────────────┘    │ いいえ    │ はい
                                                      ▼           ▼
                                             ┌────────────────┐ ┌────────┐
                                             │ /login へ飛ぶ   │ │ 表示   │
                                             │ error=Unauthorized│ └────────┘
                                             │ ...access.      │
                                             └────────────────┘
```

### 3-2. 誰でも見られる画面（ログイン不要）

トップページと、サイドバーに並ぶ5つの中核画面は、**ログインしなくても中身が見えて操作できます**。

- `/`（ホーム）
- `/relocation/arbitrage`（物件を方位で探す）
- `/relocation/simulator`（引越し先を試算する）
- `/relocation/wealth`（移住先の地域を比べる）
- `/houi` 配下すべて（本命星と吉方位）
- `/calendar`（引越しの日取り）
- `/about`、`/contact`、`/privacy`、`/terms`、`/login`

### 3-3. ログインが必要な画面

以下のURLで**始まる**画面は、未ログインだとログイン画面に飛ばされます。

| URL | 画面 |
|---|---|
| `/dashboard` | 全機能ランチャー |
| `/metaphysical` | 次の行動の提案ダッシュボード |
| `/trends` | 株価・技術トレンド |
| `/rentals` | 旧・物件一覧 |
| `/relocation/history` | 過去の判定履歴 |
| `/visualizer` | ビジュアライザ |
| `/x-viewer` | X（旧Twitter）閲覧 |
| `/research` | レポート生成 |
| `/extract` | 記事抽出 |
| `/agent-log` | 実行ログ |
| `/ceremonial-sample` | 冠婚葬祭の試作 |
| `/omni` | ※画面は無く、API名として残っているだけ |

> **判定は「前方一致」です。**
> `/relocation/history` は保護対象ですが、`/relocation/arbitrage` は対象外です。
> `/relocation` 全体が保護されているわけではない点に注意してください。

### 3-4. リダイレクトのURL

| 状況 | 飛び先 |
|---|---|
| 未ログインで保護画面を開いた | `/login?next=（開こうとしたURL＋検索条件）` |
| ログイン済みだが許可されていないメール | `/login?error=Unauthorized%20access.&next=（開こうとしたURL）` |
| ログイン済みで `/login` を開いた | `/dashboard` へ自動で移動 |
| サイドバーの「ログイン」を押した | `/login?next=（今いるURL）` |

「許可されたメール」は運用側の設定で1つだけ決まっています。設定が空の場合は、
**ログインさえしていれば誰でも保護画面に入れます**（テスト環境ではこの状態のことがあります）。

## 4. 別ドメイン（サブドメイン）でのアクセス

同じサイトが、別のドメイン名でも配信されています。**URLの見た目は変わりますが、中身は同じ画面**です。

| アクセス先 | 実際に表示される画面 |
|---|---|
| `fortune.cloud-palette.com/` | `/metaphysical` |
| `fortune.cloud-palette.com/なんとか` | `/metaphysical/なんとか` |
| `tech.cloud-palette.com/` | `/trends` |
| `tech.cloud-palette.com/なんとか` | `/trends/なんとか` |

例外として、`/login` と `/auth` で始まるURLは**どのドメインでも読み替えられません**。
（読み替えてしまうと、ログイン画面が `/trends/login` のような存在しない場所に飛んでしまうため）

> **確認ポイント**：`fortune.` と `tech.` の入口は、どちらも**ログインが必要な画面**につながります。
> 未ログインでこれらのドメインのトップを開くと、ログイン画面に飛ばされるのが正しい動きです。

## 5. ページが見つからないとき（404）

存在しないURLを開くと、飾りのない素朴な画面が出ます。

```
ページが見つかりません (Not Found)
お探しのリソースは見つかりませんでした。
ホームへ戻る          ← 押すと / へ移動
```

> この画面は**サイトの見た目（ピンク基調のデザイン）が適用されていません**。
> 素のHTMLに近い見た目になりますが、現時点ではこれが実装どおりです。

---

## 6. エラーと読み込み中の表示

サイト全体で共通のエラー画面・読み込み画面は用意されていません。
**画面ごとに個別に作られています**。専用のものが用意されているのは以下だけです。

- `/dashboard` … 読み込み中の表示と、エラー時の表示の両方あり
- それ以外 … 各画面の中で個別に処理（詳細は各画面の仕様書を参照）

---

## 7. 見た目（テーマ）が変わることがある

サイトの背景色・文字色・アクセント色・角の丸み・文字の書体などは、
**データベースに保存されている「テーマ設定」から読み込まれます**。

- 設定が無い場合は既定値（背景 `#faf7f3` のクリーム色、アクセント ローズ色 `#f43f5e`、
  角丸 `12px`、書体はゴシック体）が使われます。
- テーマ設定は**60秒間キャッシュ**されます。設定を変えても、最大1分は前の色のままです。
- 書体設定が「明朝」の場合のみ、日本語の明朝体（Shippori Mincho）が本文に使われます。

> **確認ポイント**：色や角丸が仕様書のスクリーンショットと違って見える場合、
> 不具合ではなくテーマ設定の違いの可能性があります。報告前にテーマ設定を確認してください。

画面全体にごく薄いザラつき（ノイズ）が重なっています。これも飾りで、クリックの邪魔はしません。

## 8. 広告枠

一部の画面に広告枠があります。動きが2通りあるので注意してください。

| 状況 | 表示 |
|---|---|
| 広告IDが設定されている | Google の広告が読み込まれる |
| 広告IDが設定されていない | 「スポンサーリンク / Sponsored」の見出しと、点線枠の**プレースホルダー**が出る |

テスト環境では通常、後者のプレースホルダーが出ます。「[ 広告スペース - Cloud Palette Intelligence ]」
という文字が見えていれば、それが正常です。

## 9. アプリとして追加（PWA）

サイドバー下部に「アプリとして追加」の案内が出ることがあります。

| 端末・状況 | 挙動 |
|---|---|
| すでにアプリとして起動している | 案内そのものが**出ない** |
| iPhone / iPad | 押すと、ホーム画面への追加手順を説明するモーダルが出る（自動追加はされない） |
| Android / Chrome など | 押すと、OS標準の「インストールしますか」ダイアログが出る |
| 上記のいずれでもない（ダイアログの準備が来ていない） | 押しても何も起きない |

## 10. 検索エンジンに出さない画面

「3-3. ログインが必要な画面」に挙げたURLは、検索エンジンとAIのクローラーからも
**見えないように設定されています**（`/api/` と `/admin/` も同様）。

画面自体は残っているので、URLを知っていれば従来どおり使えます。
「メニューに無い」「検索に出ない」＝「壊れている」ではない、という点に注意してください。

## 11. 画面ではないURL

以下のURLは、開いても**画面（デザインのあるページ）にはなりません**。
文字だけのファイルが表示されるか、そのままダウンロードされます。**これが正常です。**

| URL | 中身 | 誰のためのものか |
|---|---|---|
| `/robots.txt` | 検索エンジン向けの指示 | 検索エンジン |
| `/sitemap.xml` | サイト内の全URLの一覧 | 検索エンジン |
| `/ads.txt` | 広告事業者の情報 | 広告システム |
| `/llms.txt` | AI向けのサイト説明（短い版） | AIの検索サービス |
| `/llms-full.txt` | AI向けのサイト説明（詳しい版） | AIの検索サービス |
| `/manifest.json` | アプリとして追加するときの設定 | ブラウザ |
| `/sw.js` | 裏側で動く仕組みのファイル | ブラウザ |

> **確認ポイント**：ホームのフッターに「AI Agent Spec (/llms.txt)」というリンクがあります。
> これを押すと**文字だけのページが別タブで開きます**。デザインが無いのは仕様です。
>
> `/sitemap.xml` は、[05. 本命星と吉方位](./05-houi.md) の465ページを含む一覧です。
> ここに古い年のURLが残っていないかは、年をまたいだときの確認項目になります。

## 12. QAでよく使う専門用語（かんたん辞書）

このサイトは九星気学（きゅうせいきがく）という考え方をもとにしています。
仕様の意味を取り違えないよう、最低限の言葉だけ説明します。
**計算が正しいかの検証はQAの範囲外**ですが、画面に出る言葉の意味は知っておく必要があります。

| 言葉 | 読み | ざっくりした意味 | 画面での扱われ方 |
|---|---|---|---|
| 本命星 | ほんめいせい | 生まれた年から決まる、その人の「星」。全部で9種類 | 生年月日を入れると自動で決まる |
| 方位 | ほうい | 北・北東・東…といった向き。基本8方位＋中央 | 出発地から見た引越し先の向き |
| 吉方位 | きちほうい | その人にとって良いとされる向き | 画面上では緑や青などの「良い」色 |
| 凶方位 | きょうほうい | 避けたほうがよいとされる向き | 画面上では赤などの「悪い」色 |
| 五黄殺 | ごおうさつ | 避けるべき方位のひとつ | 凶方位の一種として表示 |
| 暗剣殺 | あんけんさつ | 避けるべき方位のひとつ（五黄殺の反対側） | 凶方位の一種として表示 |
| 歳破 | さいは | その年に避けるべき方位 | 凶方位の一種として表示 |
| 本命殺 | ほんめいさつ | その人固有の避けるべき方位 | 凶方位の一種として表示 |
| 天中殺 | てんちゅうさつ | 「動かないほうがよい期間」。**方位ではなく期間の話** | 期間中は引越し先を変えても解消しない |
| 年盤・月盤・日盤 | ねんばん・げつばん・にちばん | 年／月／日それぞれの方位の良し悪しの表 | 3つとも良い日を探すのが「吉日」 |
| 六曜 | ろくよう | 大安・仏滅などのカレンダーの表示 | カレンダー画面に表示 |
| 天赦日／一粒万倍日 | てんしゃにち／いちりゅうまんばいび | 縁起が良いとされる日 | カレンダー画面に表示 |
| 真北／磁北 | しんぽく／じほく | 地図上の北（真北）と、方位磁針が指す北（磁北）。日本では数度ずれる | 切り替えると方位の判定結果が変わることがある |

> **QAとしての心構え**：吉凶の計算結果そのものが「正しいか」は判定できません。
> 見るべきは「**同じ条件を入れたら毎回同じ結果になるか**」「**画面Aと画面Bで結果が食い違わないか**」
> 「**凡例の色と実際の色が合っているか**」です。
