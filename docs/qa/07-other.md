# 07. メニューに出ない画面（URL直打ちのみ・全9画面）

[← 目次に戻る](./README.md) ｜ [共通仕様](./00-common.md)

## 0. この章について

以下の9画面は、**サイドバーにリンクが無く、検索エンジンにも出ません**。
URLを直接入力したときだけ開けます。**すべてログインが必要です。**

| # | URL | 画面名 | サイドバー |
|---|---|---|---|
| 1 | `/metaphysical` | 次の行動を提案するダッシュボード | 出る |
| 2 | `/trends` | 技術トレンド・市場インテリジェンス | 出る |
| 3 | `/visualizer` | 波形ビジュアライザ | 出る |
| 4 | `/visualizer/share/{ID}` | 波形ビジュアライザ 共有ページ | **出ない** |
| 5 | `/x-viewer` | 地磁気・太陽アライメント監視モニタ | 出る |
| 6 | `/research` | 監査レポート生成 | 出る |
| 7 | `/extract` | Web記事のMarkdown抽出ツール | 出る |
| 8 | `/agent-log` | エージェント実行ログ | 出る |
| 9 | `/ceremonial-sample` | 冠婚葬祭システム ロジックデモ | 出る |

> **共通の挙動**：未ログインでこれらのURLを開くと、**画面は一切表示されず**、
> `/login?next=（開こうとしたURL）` に飛ばされます。

> **QAとしての位置づけ**：これらは主力機能ではありません。
> テストの優先度は低めですが、「**URLを直接開いたときに壊れていないか**」の
> 確認は必要です。特に**未ログインでの遮断**は全画面で確認してください。

## 1. `/metaphysical` 次の行動を提案するダッシュボード

体調のデータと世の中の状況をもとに、「次に何をすべきか」を提示する画面です。

**別のドメイン `fortune.cloud-palette.com` からも、この画面が表示されます。**

### 構成

1. 「ハブに戻る」ボタン（→ `/dashboard`）
2. 共通設定バー（[03. シミュレータの3章](./03-simulator.md#3-共通設定バーこの画面と履歴画面で共通)と同じもの）
3. 見出し「Agency Metaphysical System」＋「データ更新」ボタン
4. 警告バナー（条件つき）
   - 「⚠️ VOID TIME ACTIVE (天中殺/空亡期間)」
   - 「⚠️ CONFLICT DAY DETECTED (日支・年支相冲)」
5. **タブ3つ**

| タブ | 中身 |
|---|---|
| 総合環境テレメトリ | 統合リスク（低LOW / 警戒ELEVATED / 危機CRITICAL の3段階）、宇宙天気、金融市場、月の引力、体調 |
| 占術・易学・算術マトリクス | 3列のカード。各列の下に詳細レポートの開閉ボタン3つ |
| RL意思決定エンジン | 推奨される行動の大見出し、整合性の表示、要因の関係図 |

### 操作

| 操作 | 結果 |
|---|---|
| 「データ更新」 | データを取り直す。実行中はアイコンが回転して押せなくなる |
| タブ切替 | 表示が変わる（**取り直しはしません**） |
| 詳細レポートの開閉ボタン3つ | インド占星術／ネイタル四柱推命／トランジット四柱推命 の詳細を開閉 |
| 共通設定バーの変更 | **その場でデータを取り直します** |

### 表示の状態

| 状況 | 表示 |
|---|---|
| 読み込み中（初回のみ） | グレーの箱が3つ点滅 |
| エラー | 赤枠で「データの読み込みエラー: 〇〇」 |
| **データもエラーも無い** | **何も表示されません**（真っ白に近い状態） |

> **報告対象になり得る点**：体調データの取得元（Ouraリング）が未設定でも、
> **画面上に「未接続」の表示は出ません**。かわりに**既定値（50など）がそのまま表示されます**。
> つまり「本物の数値」と「取れなかったときの既定値」が画面から区別できません。
>
> 金融市場のデータも、取得できない場合は仮の値（VIX 18.0 など）が入ります。

## 3. `/visualizer` 波形ビジュアライザ

3. 右パネル：プレビュー（またはコード）＋幅切替＋保存・共有・書き出しのボタン
4. 下部：音声の再生バー

**プリセット3種**：Solar Wind Pulse ☀️ / Magnetosphere Resonance 🛡️ / Cosmic Noise Background 🌌
**スタイル4種**：🎵 Resonance Synth Oscilloscope / ☀️ Solar Azimuth Vector HUD / 🛡️ Magnetosphere Shield Matrix / 🌌 Cosmic Flux Dashboard

### 操作

| 操作 | 結果 |

## 4. `/visualizer/share/{ID}` 共有ページ

`/visualizer` で作ったものを、他の人に見せるためのページです。

### ★ 最重要の確認事項2つ

> **① 未ログインでは見られません。**
> 「共有ページ」という名前ですが、**ログインが必要です**。
> リンクを受け取った第三者は、（アクセス許可の設定がある環境では）開けません。
> 未ログインでアクセスすると `/login?next=/visualizer/share/xxxx` に飛ばされます。
> **これが意図した仕様かどうかは、開発側への確認が必要です。**

> **② この画面だけサイドバーが出ません。**
> サイト内のどのページへも、サイドバーからは移動できません。
> 戻る手段は、左上の「←」ボタン（→ `/visualizer`）だけです。

### 構成

1. 上部バー：「←」／タイトル／スタイルのバッジ／「Shared via Resonance Sandbox」
2. 中央：表示幅の切替（Desktop / Tablet / Mobile）※**768px未満では表示されません**
3. 右：`Copy Link` / `Copy Code` / `Export PNG` / `Open in Sandbox`
4. 本体：ブラウザ風の枠の中にプレビュー（アドレスバー風の表示は飾りです）

### 操作

| 操作 | 結果 |
|---|---|
| Desktop / Tablet / Mobile | プレビューの幅を 100% / 768px / 375px に変える |
| `Copy Link` | URLをコピー。2秒間「Copied URL!」 |
| `Copy Code` | HTMLをコピー。2秒間「Copied HTML!」 |
| `Export PNG` | 画像保存。失敗「Failed to generate image. Please try again.」／未準備「Error: Preview not fully loaded yet.」 |
| `Open in Sandbox` | `/visualizer` に移動し、その内容が読み込まれた状態になる |

**存在しないIDを指定した場合**：404画面が出ます。
ただし**未ログインの場合は、404より先にログイン画面に飛ばされます**。

| チャットコンソール（Omni-Command Console） | どの画面からも開けません。`/omni` というページも存在しません |
| ウィジェットを並べる作業画面（Dynamic Workspace） | どの画面からも開けません |
| 12個のウィジェット類（YouTube、Xトレンド、データ分析、Markdownビューア、JSONL分割、パイプライン、ナレッジ編集、メディア収集など） | **上の作業画面からしか開けないため、すべて到達不可**。唯一「カレンダー」だけが `/calendar` で使われています |
| `/research/yfinance` | ページが存在しません（`/research` からのリンクは404） |

これらのウィジェットは、**このサイトとは別に動く外部のプログラム**を呼ぶ作りになっています。
そちらはこのリポジトリに含まれていないため、仮に開けたとしても動きません。

## 11. ホーム画面に出る紛らわしい部品

以下の4つは**この章の画面ではなく、ログイン不要のホーム（`/`）に出ます**。
名前から `/metaphysical` にあると誤解しやすいので注意してください。

| 部品 | 内容 | 注意点 |
|---|---|---|
| 生体×地磁気ダッシュボード | 体調と地磁気の表示 | **画面上の波形アニメーションは、意味のない疑似データです**（ランダムに動いているだけ） |
| システムテレメトリログ | 計算の経過を流すログ風の表示 | **演出です。実際の監査ログではありません** |
| テレメトリチャート | 14日分の推移グラフ5種 | **データ取得に失敗すると、ランダムな仮データに自動で切り替わります。しかも画面上に「仮データです」という表示は出ません** |
| 専門家会議チャット | AIへの相談パネル | **ログインが必要です** |

> **重点確認項目（重要）**
> **ホーム（`/`）はログイン不要ですが、その中の「AI相談」チャットだけはログインが必要です。**
> 未ログインでホームを開き、AI相談を送信すると、
> チャット欄に「⚠️ エラーが発生しました: Unauthorized. Please login first.」と出ます。
>
> 「ログインしていないのに使えると思ったらエラーになった」という状態が起こります。
> ログイン導線が出ていないため、利用者は理由が分かりません。**改善提案の対象です。**
