# 第1部：`/relocation/simulator` 引越し先を試算する

## 1. この画面は何をするところか

物件が決まる前の「**どのあたりに、いつ動くか**」を検討する画面です。

- 引越しを**何段階かに分けて**計画できます（例：まず福井に3か月 → その後 名古屋へ）
- 凶方位を避けるために、いったん別の場所を経由する「**迂回ルート**」を提案します
- 同行者を登録して、全員ぶんを見られます

画面上の表記：

- 見出し「**引越し先を試算する**」／バッジ「段階的移動＆仮吉方シミュレーター」
- 説明「75日ルールに基づく『本拠地（太極）』の自動追跡と、大凶を回避する『仮吉方（迂回）』ルートを検証・保存できます。」

> **QA向けの言い換え**：
> 「**75日ルール**」＝ 引越し先に75日以上住むと、そこが新しい「拠点」になるという考え方。
> 75日未満だと拠点は元の場所のままなので、次の引越しの方位も元の場所から測ります。
> この画面はその「拠点がどこにあるか」を自動で追いかけます。

## 3. 共通設定バー（この画面と履歴画面で共通）

画面いちばん上の折りたたみバーです。閉じているときは「目標日 / 基準 / フィルタ / 目的」を1行で表示します。
保存中は「Syncing...」と出ます。

| ラベル                    | 選択肢                                                            | 初期値            |
| ------------------------- | ----------------------------------------------------------------- | ----------------- |
| 目標年月日                | 日付                                                              | **今日**          |
| 方位盤基準                | 暦基準 (古典) / 木星黄経 (物理)                                   | **暦基準 (古典)** |
| 月盤の算出方法            | 物理独立 / 伝統連動（**「木星黄経(物理)」を選んだときだけ出る**） | 物理独立          |
| 吉凶方位フィルター        | 総合 (ALL) / 個人吉凶 / 天中殺のみ / 環境のみ                     | **総合 (ALL)**    |
| アクション目的 (重みづけ) | 標準 / 休息・健康 / ビジネス / 長期移住                           | **標準**          |

> **重点確認項目**：**このバーで「目標年月日」を変えると、ステップ1の出発日が上書きされます。**
> ステップ1に入力していた日付が消えるので、意図しない挙動に見えることがあります。

### 4-5. 同伴者の設定

| 操作             | 挙動                                                                                                                        |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 「同伴者を追加」 | **ポップアップが2回**出る。①名前（初期候補「同伴者 2」）→ ②生年月日（初期候補「1990-01-01」）。どちらも空・キャンセルで中止 |
| 削除（ゴミ箱）   | **確認なしで即削除**                                                                                                        |
| 0人のとき        | 「同伴者はいません（単身移動シミュレーション）」                                                                            |

> **報告対象になり得る点**：同伴者の生年月日は**形式のチェックがありません**。

> 内部では「現在の日時」として扱われ、そのまま星が計算されます。
> つまり**誤った判定が出るのに、画面上は何の警告も出ません**。

## 7. ステップカードに出るもの

```
┌────────────────────────────────────────────┐
│ STEP 1 : 大吉        [長期移住]            │
│ ─────────────────────────────────────────  │
│ ※家屋全体の重大な凶方位（五黄殺 / 暗剣殺 / │  ← 大凶のときだけ
│   歳破・月破・日破）に衝突しています。      │
│   影響：自分, 母                            │
│ ─────────────────────────────────────────  │
│ 自分: 大吉   母: 凶                         │  ← 同伴者がいるとき
│ ─────────────────────────────────────────  │
│ 出発地: 京都市下京区                        │
│ 方位角: NE (42°)     Q値: 3.2               │
│ 滞在期間: 90 日間                           │
│ ※滞在が75日以上のため、この移動後に拠点は   │
│   「愛知県名古屋市」に移転します。           │
└────────────────────────────────────────────┘
```

- 滞在期間が75日未満は琥珀色、75日以上は緑
- Q値は数字のときだけ表示（負は赤、正は緑）
- **距離（km）はどこにも表示されません**

> **報告対象になり得る点（文言のバグ）**
> 滞在が75日未満のとき、次の文が出ます。
> 「※滞在が75日未満のため、この移動後の拠点（太極）は**京都**のまま動きません。」
> この「**京都**」の部分は**固定の文字**で、出発地を別の場所に変えても変わりません。
> 出発地が「札幌」でも「京都のまま動きません」と表示されます。

## 8. 鑑定詳細カード（右側）

ステップを選ぶと表示されます。**未選択のときは**「ステップを選択してください」＋
「左側のステップカードを選択すると、その移動における方位・節気干渉の幾何学的な詳細ブレイクダウンと仮吉方のアドバイスが展開されます。」と出ます。

上から順に：

1. `出発地 ➔ 目的地`
2. **ステップ吉凶評価**（判定ラベル＋説明文）
3. **時間適合度 (Q値)**：推奨行動とQ値
   - 推奨行動のラベル：**実行前進 / 浄化移住 / 撤退 / 情報収集 / 警戒待機**
4. **日付リスク要因**（あれば）：「〇〇 が干渉しています。」
   - 要因の種類：天中殺（空亡）／対沖（干渉衝突日）／土用期間（土公神の障り）／〇〇逆行
5. **占術インサイト**（データがあるときだけ）
   - 🚪 奇門遁甲：門の名前＋「吉門 / 凶門 / 中立」バッジ
   - ☯ 易経得卦：第N卦、卦名、「変爻あり」バッジ、六本線の図、解釈
   - 🃏 タロット：カード名、正位置／逆位置、意味、リスク寄与度
   - ⭐ 紫微斗数飛星：日次のコメント
6. **最適化アクションアドバイス**
   - 【天中殺/拠点定着警告】短期旅行なのに75日以上滞在するとき（赤）
   - 【拠点未確定アラート】長期移住なのに75日未満のとき（琥珀。あと何日必要かを表示）
   - **出発日程の最適化推奨**：7日後〜49日後の7候補のうち、今より良い上位3件
     - `📅 日付 (N日後) / Q: 値` の行を**クリックすると出発日が差し替わります**
   - **【吉方位迂回ルート提案 (仮吉方)】**：判定が「凶」「大凶」のときだけ
     - `📍 〇〇経由で迂回ルートを作成` の行を**クリックするとステップが2つに分割されます**
       （現ステップの目的地が経由地になり、75日後に新しいステップが追加される）
   - 問題ないとき：「この移動ステップには凶方位との衝突はありません。このままスケジュールを実行して問題ありません。」

**迂回の候補地は10か所で固定**です。
福井県敦賀周辺 / 滋賀県大津周辺 / 三重県桑名周辺 / 静岡県浜松周辺 / 長野県飯田周辺 /
福井県福井市周辺 / 石川県金沢周辺 / 岐阜県高山周辺 / 兵庫県姫路周辺 / 和歌山県田辺周辺

## 9. 計画総合適合度と天地人マトリクス

### 9-1. 計画総合適合度（ヘッダー右の点数）

空間の点数×0.6 ＋ 時間の点数×0.4 で計算します。ただし：

> **大凶（五黄殺・暗剣殺・歳破）が1つでもある、またはQ値が −50 未満の場合、
> 点数は40点で頭打ちになります。**

色：40以下＝赤／75以上＝緑／その間＝グレー

### 9-2. 天地人・統合適合性マトリクス

プラン全体用（画面中段）と、ステップ別（鑑定詳細の中）の**2か所に出ます**。

| バッジ    | 条件                                               |
| --------- | -------------------------------------------------- |
| EXCELLENT | 総合シンクロ指数が70より大きい                     |
| WARNING   | 40より大きい                                       |
| CRITICAL  | 40以下（**点滅。ただしスマホ幅では点滅しません**） |

**3つの指標**（各%＋バー。40%以下は赤＋警告アイコンが点滅）

| 指標                     | 良いときの文言                       | 悪いときの文言                                   |
| ------------------------ | ------------------------------------ | ------------------------------------------------ |
| 天（時間タイミング）     | 宇宙天気、惑星アスペクトともに良好   | 注意: 〇〇等による制限                           |
| 地（空間方位ベクトル）   | 移動方向の地磁気エネルギーは安全領域 | 警戒: 強力な方位凶殺（五黄殺/暗剣殺/歳破）を検出 |
| 人（心身・相性シンクロ） | 個人コンディションが100%連動中       | 相性: 〇〇% (同伴者 N 名)                        |

**アドバイス欄**

| 段階 | 内容                                                                                                |
| ---- | --------------------------------------------------------------------------------------------------- |
| 高   | 「【警告】地脈エネルギーの衝突」＋ボタン「敦賀を経由する迂回ルートを挿入」                          |
| 中   | 「【調整推奨】天・人の不整合」＋ボタン「〇月〇日 に出発日を変更」または「生体回復アドバイスを表示」 |
| 低   | 「【調和】完全整合化フェーズ」（ボタンなし）                                                        |

> **報告対象になり得る点**：「地」の指標に含まれる**同伴者の評価は、全員60点で固定**されています。
> ステップカードに出る同伴者の判定（実際に計算されたもの）とは別の仕組みです。
> **同伴者を変えても「地」の数値が動かない**ことがあります。

## 10. 保存・読み込み・削除

| 操作                 | 結果                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------ |
| プランを保存（成功） | ポップアップ「プランをデータベースに保存しました。」                                             |
| プランを保存（失敗） | 「保存に失敗しました。」                                                                         |
| 通信エラー           | 「通信エラーが発生しました。」                                                                   |
| プラン読み込みの失敗 | 「データの展開に失敗しました。」                                                                 |
| プランの削除         | 確認ダイアログ「このシミュレーションプランを削除しますか？」。**失敗しても画面には何も出ません** |
| ポータル同期の失敗   | 「ポータルからの同期に失敗しました。」／「通信エラーが発生しました。」                           |

> **持ち主の絞り込み（対応済み）**
> かつては**ログインしていなくても保存・読み込み・削除ができ**、一覧に**別の利用者のプランも全件表示されて**いました。#84 で API を作り直し、現在は次のとおりです。
>
> - 保存・読み込み・削除はいずれもログイン必須（未ログインは 401）
> - 一覧に出るのは自分が保存したプランだけ
> - 他人のプランは id を知っていても更新・削除できない（404）
>
> `__tests__/relocationSimulationRoute.test.ts` で固定してあります。個人が特定できる情報を入れてテストしてかまいません。

# 第2部：`/relocation/history` 過去の移動履歴

## 14. 概要

|                        |                                                             |
| ---------------------- | ----------------------------------------------------------- |
| **URL**                | `/relocation/history`                                       |
| **画面名**             | 過去の移動履歴 History                                      |
| **ログイン**           | **必要**。未ログインは `/login?next=/relocation/history` へ |
| **メニュー**           | 出ません。**サイトマップにも載っていません**。URL直打ちのみ |
| **ブラウザのタイトル** | **専用の設定が無く、サイト全体の既定タイトルが出ます**      |

過去にした引越しや旅行を記録して、そのときの方位の吉凶をあとから調べる画面です。

## 15. 構成

1. 共通設定バー（シミュレータと同じもの）
2. 見出し＋右上「移動履歴を追加」⇔「閉じる」ボタン
3. 現在の判定条件バー（表示のみ）
   - 「方位偏角: 真北基準 (物理) / 磁北基準 (磁気偏角補正)」
   - 「方位盤基準: 古典暦基準 (立春) / 物理天体基準 (木星黄経)」
   - 「フィルター: 総合 / 個人吉凶 / 天中殺のみ / 環境方位のみ」
   - 右端に「※詳細設定は上部のコントロールバーから変更できます。」（**スマホでは非表示**）
4. 左（2/3）：追加フォーム（折りたたみ）→ 履歴の一覧
5. 右（1/3）：詳細鑑定ボード（**1024px以上では画面に貼り付いて追従します**）

## 16. 追加フォームの入力項目

| ラベル                  | 種類                                             | 必須     | 初期値・制約                                                |
| ----------------------- | ------------------------------------------------ | -------- | ----------------------------------------------------------- |
| 日時の精度              | 4択ボタン                                        | —        | **日単位**。年単位 / 月単位 / 日単位 / 時単位               |
| 出発日時                | **精度によって入力欄が変わる**                   | **必須** | 空                                                          |
| 出発地の名称            | 文字（例: 自宅, 京都市...）                      | **必須** | 空                                                          |
| 目的地の名称            | 文字（例: 新居, 京都市中京区...）                | **必須** | 空                                                          |
| 出発地を住所/地名で検索 | 文字＋「検索」                                   | —        | 空                                                          |
| 目的地を住所/地名で検索 | 文字＋「検索」                                   | —        | 空                                                          |
| 地図（高さ320px）       | 青＝出発地／赤＝目的地。**両方ドラッグできます** | —        | 東京（35.6895, 139.6917）／京都（35.0116, 135.7681）        |
| 目的区分                | 2択                                              | —        | **短期旅行 (日・時重視)**。もう一方は 長期移住 (年・月重視) |
| メモ・備考 (任意)       | 文字                                             | 任意     | 空                                                          |

**「出発日時」の入力欄は、精度によって次のように変わります。**

| 精度   | 入力欄           | 制約           |
| ------ | ---------------- | -------------- |
| 年単位 | 数字（例: 2018） | **1900〜2099** |
| 月単位 | 年月を選ぶ       | 制限なし       |
| 日単位 | 日付を選ぶ       | 制限なし       |
| 時単位 | 日付＋時刻       | 制限なし       |

> **重点確認項目**：**精度を切り替えると、入力済みの出発日時が空にリセットされます。**
> 日付を入れてから精度を変えると消えます。これは実装どおりですが、利用者は驚きます。

**この画面にも生年月日の入力欄はありません。**（判定にはサーバー側の既定値が使われます）

**地図クリックによる地点指定はできません。** 変えられるのは①名称の入力、②住所検索、③マーカーのドラッグ の3通りです。

> **注意**：住所検索が成功すると、**座標だけでなく名称の欄も上書きされます**。
> 自分で入れた「自宅」という名前が、検索した住所に置き換わります。

## 17. 一覧と詳細鑑定

### 一覧カード

```
● 大吉  2024年05月10日  [日単位] [長期移住]
        神戸市 → 京都市中京区   NE (42°方位)
        引越しのメモ…
                                  [🗑]  [>]
```

- カードをクリックすると右に詳細が開き、もう一度押すと閉じます
- ゴミ箱で削除（確認ダイアログあり）。**削除に失敗しても画面には何も出ません**
- スマホでは「クリックして詳細を表示」の文字が出ます（PCでは出ません）

### 詳細鑑定ボード

| 項目                   | 内容                                                                                                                   |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 総合吉凶評価           | 判定ラベル／評価コード／説明文                                                                                         |
| **レイヤー別影響分析** | 年盤レイヤー（約60年〜数年間の引力波）／月盤レイヤー（約数ヶ月〜数年間の影響）／日盤レイヤー（数日〜数週間の短期引力） |
| 移動座標               | 真方位角（度と方位）／出発地の緯度経度／目的地の緯度経度                                                               |
| 末尾の解説文           | 「気学における方位の吉凶は、出発時における天体の電磁的干渉に基づきます。…」                                            |

**「未指定」の出方**（重要）

| 精度           | 年盤       | 月盤       | 日盤       |
| -------------- | ---------- | ---------- | ---------- |
| 年単位         | 判定される | **未指定** | **未指定** |
| 月単位         | 判定される | 判定される | **未指定** |
| 日単位・時単位 | 判定される | 判定される | 判定される |

> 精度を粗くすると、細かいレイヤーは「未指定」になるのが正常です。

**距離（km）はここにも表示されません。**

### 判定ラベルの説明文（シミュレータと文言が違います）

| ラベル           | 説明文                                                                                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 大吉 / 吉 / 普通 | 吉方位 / 平穏                                                                                                                                                |
| **注意**         | 一部干渉・引越当日注意（長期方位は吉ですが、移動当日に注意が必要です）                                                                                       |
| 凶               | 本命殺（健康運の低下）／本命的殺（目的阻害のエネルギー）／月命殺（精神的ストレスの元）／月命的殺（仕事や対人関係の停滞）／羅睺・計都軸（宿命的磁気ストレス） |
| 大凶             | 天中殺方位（基盤の崩壊）／五黄殺（自己破壊のエネルギー）／暗剣殺（他動的トラブルの兆候）／歳破・月破・日破（破れのエネルギー）                               |

> シミュレータでは「注意」に専用の説明文がありませんが、**この画面にはあります**。
> 同じ判定なのに画面によって説明文が違うのは実装どおりです。

## 20. 2画面で結果が食い違う理由

|                    | シミュレータ           | 履歴                 |
| ------------------ | ---------------------- | -------------------- |
| 磁北の計算         | **簡易な近似式**       | **実測に基づく計算** |
| 判定に使うレイヤー | 総合                   | 精度によって切り替え |
| 「注意」の説明文   | なし（「平穏」と表示） | あり                 |

> **同じ移動を両方に入れても、判定が違うことがあります。** 実装が異なるためです。
> 「画面Aと画面Bで違う」だけでは不具合になりません。ただし**開発側に仕様確認を出す価値はあります**。
