## 1. この画面群の特徴

**操作するものがほとんどありません。読むためのページです。**

他の画面と違い、ボタンやプルダウンで結果が変わることはありません。
**URLごとに内容が決まっており、あらかじめ作り置きされています。**

> **QAとしての見どころは3つです。**
> 1. **URLの組み合わせが正しく作られているか**（存在すべきページが404になっていないか）
> 2. **存在しないURLを開いたときに404になるか**
> 3. **ページ内のリンクが全部つながっているか**（558ページの相互リンク）

## 2. URLに入る値の範囲

### 2-1. 年

| ページ | 対象年 |
|---|---|
| `/houi/{年}/{星}` | **今年・来年・再来年の3年** |
| `/houi/{年}/{星}/{月}` | **今年・来年の2年**（再来年の月ページはありません） |

> **最重要の注意点**
> **この「今年」は、サイトを作り直した（デプロイした）時点の年で固定されます。**
>
> 例：2026年8月に作ったまま2027年1月を迎えても、
> ページは 2026 / 2027 / 2028 のままで、**2029年のページは存在しません**。
> 年が変わったら作り直しが必要です。
>
> QAでは「**年をまたいだあとに古い年のページが残っていないか**」を必ず確認してください。

## 4. `/houi` 入口ページ

### 4-1. 構成（上から）

1. 見出し「九星気学の本命星と吉方位の早見表」
2. リード文
3. 「生まれ年から本命星を調べる」＋立春の注意書き（2月4日ごろ、立春前は前年扱い）
4. **本命星9枚のカード**
   - 星の名前 ／ 「〇〇年の吉方位を見る →」リンク ／ 該当する生まれ年の一覧
5. 「算出方法が2種類あります」の説明ボックス（**違いの件数が動的に表示されます**）
6. **広告枠**
7. 「吉方位が分かったら、その方位に何があるか」ボックス → 黒いボタン → `/houi/area`
8. 「年ごとの方位一覧」（3年分のカード × 各9星 ＝ **27リンク**）
9. 「用語について」の説明リスト（五黄殺／暗剣殺／歳破／本命殺／本命的殺／天中殺）
10. 琥珀色の注意ボックス → 黒いボタン「物件を方位で探す」→ `/relocation/arbitrage`

> **報告対象になり得る点（重要）**
> カードに並ぶ「生まれ年」は **1950年〜2025年の76年分が固定で書かれています**。
> 年が進んでも自動では増えません。**2026年以降生まれの人は載っていません。**
> 年次のメンテナンス対象として記録しておいてください。

## 5. `/houi/{年}/{星}` 年ごとのページ

### 5-1. 構成（上から）

1. パンくず（`方位の早見表 > 2026年 一白水星`）
2. 見出し「2026年 一白水星の吉方位と凶方位」
3. リード文（中央の星、吉方位の一覧、避けるべき方位）
   - 吉方位が1つも無い年は「この年は吉方位に当たる方位がありません。」
4. **「方位ごとの判定」＝ 8枚のカード**（PCで2列、スマホで1列）
5. 「月ごとの吉方位」＝ 1〜12月へのリンク
   - **再来年のページにはこのセクション自体がありません**（月ページが無いため）
6. 「算出方法による違い」＝ 2行の比較表
7. 琥珀ボックス「この表だけで引越し先を決められない理由」→ `/relocation/arbitrage`
8. エリアページへのリンク集（**データのある県 × 各3件**。現在は12県＝36リンク。対象県が増えると自動で増える）＋「すべての市区町村」
9. **広告枠**
10. 「ほかの本命星」（8リンク）／「ほかの年」（2リンク）

### 5-2. 「方位ごとの判定」カード

```
┌──────────────────────────┐
│ 南東              [吉方位] │
│                            │
│ 本命星と相性の良い星が回座  │
│ しており、凶方位にも当たって│
│ いません。                  │
│                            │
│ 回座している星: 六白金星    │
└──────────────────────────┘
```

**8方位すべてが必ず出ます。**（北 → 北東 → 東 → 南東 → 南 → 南西 → 西 → 北西 の順）
**中央（中宮）は出ません。**

### 5-3. 判定ラベルの全種類

| ラベル | 色 | 画面に出る説明文 |
|---|---|---|
| **吉方位** | 緑 | 本命星と相性の良い星が回座しており、凶方位にも当たっていません。 |
| **平** | グレー | 凶方位ではありませんが、積極的に選ぶ理由もない方位です。 |
| **五黄殺** | 赤 | 五黄土星が回座する方位。九星気学では最も避けるべき方位とされます。 |
| **暗剣殺** | 赤 | 五黄殺の正反対にあたる方位。五黄殺と対で生じます。 |
| **歳破** | 赤 | その年の十二支の正反対にあたる方位。約束事が壊れる方位とされます。 |
| **本命殺** | 赤 | 自分の本命星そのものが回座する方位。自身に影響が出るとされます。 |
| **本命的殺** | 赤 | 本命殺の正反対にあたる方位。本命殺と対で生じます。 |

**月ページでは「歳破」の代わりに「月破」と表示されます**（同じ判定です）。
説明文も「その月の十二支の正反対にあたる方位。歳破の月版にあたります。」に変わります。

> **記号は使われていません。色とラベルの文字だけで区別しています。**

### 5-4. この画面に出ない判定

以下は仕組みとしては存在しますが、**この記事ページ群には絶対に表示されません**。

- 月命殺 / 月命的殺 / 空亡 / 月交点 / 「注意」

> 生年月日を使わず「生まれ年だけ」で計算しているためです。
> **表示されなくても不具合ではありません。**

### 5-5. 判定が上書きされる仕組み（QAが混乱しやすい点）

判定は次の順で決まりますが、**歳破・月破だけは最後に無条件で上書きします**。

```
① 五黄殺 → 暗剣殺 を置く
② 本命殺 → 本命的殺 を置く（すでに埋まっているマスは上書きしない）
③ その他
④ 【最後】歳破・月破を無条件で上書き
```

結果として、こういうことが起こります。

> **本命星が「五黄土星（星=5）」のとき、本命殺と五黄殺が同じ場所に来ます。**
> このとき表示されるのは**「五黄殺」だけ**で、「本命殺」は出ません。
> 本命的殺も同様に「暗剣殺」に吸収されます。
>
> **`/houi/2026/5` などの五黄土星のページで「本命殺が無い」のは正常です。**

## 6. `/houi/{年}/{星}/{月}` 月ごとのページ

年ページとほぼ同じ構成ですが、以下が違います。

1. パンくずが3階層（`方位の早見表 > 2026年 一白水星 > 8月`）
2. 見出しの下に **「対象期間: 2026年8月7日 〜 2026年9月6日」** が出る
3. 白いボックス「九星気学の月は暦の1日ではなく**節入り**で切り替わります」
4. 「歳破」の代わりに「月破」
5. 琥珀ボックスに「2026年の年盤を見る」ボタン（白）＋「物件を方位で探す」ボタン（黒）
6. 下部が「2026年のほかの月」（11リンク）と「ほかの本命星（2026年8月）」（8リンク）

> **確認ポイント**：**月の区切りが暦の1日ではありません。**
> 8月のページの対象期間が「8月1日〜8月31日」ではなく、
> 「8月7日ごろ〜9月6日ごろ」になるのが正常です。

## 8. `/houi/area/{コード}` エリア詳細

### 8-1. 構成（上から）

1. パンくず（3階層）
2. 見出し「〇〇県△△市から見た方位別のエリアと家賃相場」＋リード文
3. **白いボックス**：その市自身の相場（㎡単価・家賃中央値・集計件数）＋集計日と注意書き
4. 「方位ごとのエリア」＋「中心から 5〜150km の範囲。距離が近い順」
5. **広告枠**
6. 「〇〇年、自分にとっての吉方位はどれか」＝ 9行の表（本命星ごとの吉方位）
7. 琥珀ボックス「この表の読み方と限界」→ 黒ボタン「物件を方位で探す」
8. 「〇〇県のほかのエリアを出発地にする」（最大24件）＋「すべての市区町村から選ぶ（313エリア）」

### 8-2. 「方位ごとのエリア」の表

**方位ごとに、該当するエリアが表になります。**

| 列 | 内容 |
|---|---|
| 市区町村 | リンク（別のエリアページへ） |
| 距離 | 出発地からの距離 |
| ㎡単価 | 1㎡あたりの家賃 |
| 家賃中央値 | — |
| 「〇〇市比」 | 出発地の相場と比べて何%か |

> **重要な仕様**
> - **該当エリアが0件の方位は、見出しごと表示されません。**
>   8方位すべてが並ぶとは限りません。これは正常です。
> - **各方位、最大12件までしか表示されません。**

### 8-3. 「吉方位はどれか」の表

9つの本命星それぞれについて、その年の吉方位を並べます。
吉方位が1つも無い星は「この年は吉方位なし」と出ます。

各本命星の名前は、その年のページ（`/houi/{年}/{星}`）へのリンクです。

### 8-4. 「物件を方位で探す」ボタンの引き継ぎ

このボタンは、**その市の座標と都道府県名を持って**物件スキャナーへ移動します。

```
/houi/area/23100 の「物件を方位で探す」
        ↓
/relocation/arbitrage  に以下が引き継がれる
  ・その市の緯度・経度 → 出発地
  ・都道府県名         → 対象都道府県
  ・スキャン半径       → 全国
```

> **重点確認項目**：移動先で、**出発地が空のままになっていないか**を必ず確認してください。
> 出発地が入らないと、スキャナーは「出発地を設定してください」の警告で止まります。

### 8-5. 方位の区切り方（重要）

**このエリアページの方位は、45度ずつの均等割ではありません。**

| 方位 | 角度の範囲 | 幅 |
|---|---|---|
| 北 | 345°〜15° | **30度** |
| 北東 | 15°〜75° | **60度** |
| 東 | 75°〜105° | **30度** |
| 南東 | 105°〜165° | **60度** |
| 南 | 165°〜195° | **30度** |
| 南西 | 195°〜255° | **60度** |
| 西 | 255°〜285° | **30度** |
| 北西 | 285°〜345° | **60度** |

> 北・東・南・西が狭く、斜めの4方位が広いのが正しい仕様です。
> 「北東に入っているエリアが多すぎる」ように見えても、これが正常です。

## 11. ページの作られ方と更新のタイミング

| 項目 | 内容 |
|---|---|
| 作り方 | **サイトを作り直したとき（デプロイ時）に558ページすべてが作り置きされます** |
| ページを開いたときの計算 | **ありません**（作り置きされた内容をそのまま出します） |
| 内容が変わるタイミング | 作り直したときだけ |
| エリアの家賃相場 | 毎日 深夜〜早朝に自動収集され、変化があればデータが自動更新されます |
| 検索エンジンへの掲載 | **558ページすべてが対象**（この画面群は非公開設定になっていません） |

> **報告対象になり得る点**：家賃相場の自動更新は、更新後に**サイトの作り直しが走らない設定**に
> なっている可能性があります。「データは更新されているのにページに反映されない」場合は、
> この点を開発側に確認してください。

**色や書体が変わって見える場合**は、[共通仕様の7章（テーマ）](./00-common.md#7-見た目テーマが変わることがある)を確認してください。
テーマ設定は最大60秒遅れて反映されます。
