## 1. `/` ホーム（トップページ）

### 1-1. この画面は何をするところか

サイトの入口です。**上半分は案内、下半分は本格的な道具**という、性格の違う2つの部分に分かれています。

```
┌────────────────────────────────────────────┐
│ ① 見出しカード                              │
│   「引越しの方位とタイミングを決める」        │
│   ＋ ボタン「物件を方位で探す →」            │
├────────────────────────────────────────────┤
│ ② 5つの案内カード（2列に並ぶ）              │
│   ここから各機能へ入る                       │
├────────────────────────────────────────────┤
│ ③ 「いまの方位と時刻」カード                 │
│   ★ここが巨大な多機能ツール（→ 1-4）        │
├────────────────────────────────────────────┤
│ ④ 広告枠                                    │
├────────────────────────────────────────────┤
│ ⑤ フッター（4つのリンク＋AI向け仕様リンク）  │
└────────────────────────────────────────────┘
```

> **QAへの注意**：③の中身は、このサイトで**最も規模が大きく、最もテスト工数がかかる部分**です。
> 見た目は1枚のカードですが、中にタブが5つあり、それぞれが独立した道具になっています。

### 1-3. 読み込み中の表示

③のツール部分は、あとから読み込まれます。読み込み中は枠の中にぐるぐるが回り、
**「Solar Time & Geomancy Engine ロード中...」** と英語で表示されます。

読み込みが終わったあとも、内部の準備ができるまでは
**「Initializing Tactical Systems...」** という緑色の点滅文字が全面に出ます。

## 1-4. 【最重要】「いまの方位と時刻」ツールの中身

ホームの下半分にある大きな道具です。ここだけで1つのアプリと言える規模があります。

### 常に見えている部分（タブの外）

上から順に：

| 要素 | 内容 |
|---|---|
| 天中殺の警告バナー | 条件に当てはまるときだけ出る。「Global Time Check Error」＋「現在は『年の天中殺』／『月の天中殺』期間です。…」 |
| 見出し「Bio-Location Simulator」 | 英語の見出し |
| 「[?] どのように引越し方位とタイミングを割り出しているのか（統合ワークフロー）」 | 押すと4段階の解説が開く。**初期状態は閉じている**。閉じるときのラベルは `[-] CLOSE ALGORITHM WORKFLOW` |
| カレンダー2枚 | 左＝月間カレンダー、右＝選んだ日の詳細。**画面が非常に広いとき（1280px以上）だけ横並び**、それ以外は縦積み |

このカレンダーは、[引越しの日取りを選ぶ画面](./06-calendar.md)で使われているものと**同じ部品**です。
記号・色・点数の意味はそちらのページを参照してください。

> **重要**：ここで生年月日を入れると、`/calendar` 画面のカレンダーにも同じ値が反映されます。
> **逆も同じ**です。片方でテストデータを入れたら、もう片方に影響します。

### タブ（5つ）

画面をスクロールしても上に貼り付いて残ります。

| タブ | 中身 |
|---|---|
| 1. プロフィール | 生年月日・出生地・現住地などの基本設定（→ 1-5） |
| 2. 目的地/健康 | 行き先の指定と、日付を動かしながら吉凶を見る（→ 1-6） |
| 3. タイミング | 真太陽時の時計と、時間帯ごとの吉凶表 |
| 4. AI相談 | AIに相談するチャット（→ 1-7） |
| 5. 総合スコア | 8方位をまとめて比較する表（→ 1-8） |

- 初期は「1. プロフィール」が開きます。
- **最後に開いていたタブは端末に記憶され、次に開いたときに復元されます。**
- 画面が狭いとタブが2段に折り返します。

> **報告対象になり得る点**：内部にはもう1つ「履歴」のタブが用意されていますが、
> **切り替えるボタンが画面に存在しません**。通常の操作では絶対に開けません。

### 1-5. タブ1「プロフィール」

| 要素 | 選択肢 / 初期値 |
|---|---|
| Action Intent（行動の目的） | 日常の行動・短期旅行（初期）／休息と回復／ビジネス／引越し・長期移住。**選ぶと吉凶の判定方法そのものが変わります** |
| プロフィール設定パネル | 下の「1-9」で詳述 |
| 天中殺の可視化 | 生年月日から天中殺の期間を図で表示 |

### 1-6. タブ2「目的地/健康」

このタブが最も操作項目が多い部分です。

**体調のスライダー3本**

| 項目 | 範囲 | 初期値 |
|---|---|---|
| 心拍のゆらぎ（HRV） | 10〜150 | 30 |
| 皮膚の電気反応（GSR） | 0〜20（0.5刻み） | 1.8 |
| 環境になじんだ日数 | 0〜100 | 30日 |

**日付を動かす操作**

| 操作 | 内容 |
|---|---|
| 対象日（日付入力） | 判定の対象になる日 |
| 「自動検索」ボタン | 押すと、**最大365日先まで**自動で走査し、安全な日を探して移動する。押している間はラベルが「検索中...」になり押せなくなる |
| 見つからなかったとき | ポップアップで「365日以内に完全に安全な移動タイミングが見つかりませんでした。目的（Action Intent）を変更して再検索するか、目的地を変えてください。」 |
| 「▶ 再生 / ⏸ 一時停止」 | 0.5秒ごとに日付が自動で進む |
| 速度の選択 | 1日ずつ（初期）／1週間ずつ／1か月ずつ／1年ずつ。**再生中は変更できない** |
| 日送りボタン | `◀`（−1日）／`▶`（+1日）／`TODAY`／`+30D`／`+90D`／`+180D`／`+1Y` |

**行き先の指定（4通り）**

1. 「[ 地図検索 ]」を押して地図を開き、地図をクリックする
2. 座標や Google マップのURLを貼り付ける欄に貼る → 自動で座標が入り、欄が空になる
   - **読み取れない文字列を貼っても、何も起きません（エラーも出ません）**
3. 緯度・経度・標高を数字で直接入力する（**上限・下限の指定なし**）
4. 地図上のマーカーを動かす

座標が入っていると「📋 座標をコピー」「🗺️ Googleマップで開く」の2ボタンが出ます。
後者は Google マップを**別タブ**で開きます。

**判定の表示**：「真北: 〇〇 / 磁北: 〇〇 / ステータス」というバッジ。
状況により「✨天道回座中」「⚠️偏角ズレ」が追加されます。

**傾向のヒートマップ**

| 操作 | 内容 |
|---|---|
| 「30 DAYS」/「12 MONTHS」 | 押すと表示。**もう一度押すと消える**（初期は非表示） |
| 「🌟 大吉絞込」「🛡️ 凶除外」 | 押すたびに絞り込みと通常表示を往復する |
| 「▶ 月次自動再生」「◀ 前月」「次月 ▶」 | ヒートマップ表示中のみ |
| セルをクリック | 詳細パネルが開く。「了解」ボタンで閉じる |

**観点フィルタ（7つのボタン）**
🪐 総合判定（初期）／👤+🌍 吉凶+環境／👤+☯ 吉凶+天中殺／☯+🌍 天中殺+環境／👤 個人吉凶／☯ 個人天中殺／🌍 環境方位のみ

総合判定以外を選ぶと、上に色つきの説明バナーが出ます。

**その他のトグル**
- 「☑ 新築のみ表示 / ☐ 全物件表示」（初期＝全物件）
- 月の算出方法「物理独立 / 伝統連動」（**特定の設定のときだけ表示されます**）
- モデル「Classical（暦基準）/ Physical（木星黄経基準）」（初期＝Classical）

**地図（TacticalMagneticMap）**：4種類の重ね表示（地形／天気／生体／危険）のトグル、
表示するレイヤー（統合／年／月／日）、真北・磁北の切り替え、地図クリックでの行き先指定。

### 1-7. タブ4「AI相談」

チャット形式です。

| 要素 | 内容 |
|---|---|
| 入力欄 | 「アドバイスを求める、またはテーマ変更を指示...」。送信中は入力できず、文言が「エージェントが思考を同期中...」に変わる |
| 「送信」ボタン | 空欄のときと送信中は押せない |
| 送信中の表示 | 2秒ごとに文言が切り替わる（生体測定データ同期中 → 宇宙天気 → 占星 → エージェント思考） |
| 失敗したとき | チャットの中に「⚠️ エラーが発生しました: 〇〇」と表示される。**画面は移動しません** |

> **重点確認項目**：AIの返答内容によっては、**サイト全体の配色がその場で変わることがあります**。
> 「AIに相談したら画面の色が変わった」は不具合ではなく仕様です。
> ただし、意図せず読めない配色になった場合は報告してください。

下部に「Ephemeris Engine Diagnostics」という数値の一覧があります。値が無い箇所は `--` と表示されます。

| 操作 | 選択肢 / 初期値 |
|---|---|
| 対象県のプルダウン | 全国／**愛知県（初期値）**／東京都／大阪府／神奈川県／埼玉県／千葉県／京都府／兵庫県／福岡県 |
| 「NOISE方位を非表示 / 表示中」 | 初期は**非表示** |

| 「UNIFIED MASTER EXPORT」ボタン | 体調の値なども合わせたJSONをダウンロード |

**表の列**：方位 / 古典 / 物理独立 / 伝統連動 / 合意判定 / ① 気学方位 / ② アストロ / ③ 時間ゲート / 30日吉日 / 推奨エリア（所得）/ 推奨物件（差益）

**読み込み中**
- 1回目：「Loading Relocation Scenarios...」＋ぐるぐる
- 2回目以降：表全体が薄くなり、押せなくなる。上端に進行バーが出る

> **報告対象になり得る点（重要）**
> - この表のデータ取得が**失敗しても、画面には何も表示されません**。表が空のままになるだけです。
> - エクスポートが**失敗しても、画面には何も表示されません**。ボタンが元に戻るだけです。
> 　→ テスト中に「表が空」「押しても何も落ちてこない」場合、成功か失敗か画面から判断できません。

| Gemini APIキー | 伏せ字入力。保存済みの場合は `********` と表示される |

## 2. `/dashboard` 全機能ランチャー

### 2-1. 概要

| **ログイン** | **必要**。未ログインは `/login?next=/dashboard` へ飛ばされる |

### 2-2. 構成

```
┌────────────────────────────────────────────┐
│ 見出し「Meta-Metaphysical Hub」            │
│                    ボタン2つ（右側）        │
├────────────────────────────────────────────┤
│ アプリポータル（カード3枚）                 │
├────────────────────────────────────────────┤
│ 6つのタイルが並ぶ（幅により1〜4列）         │

└────────────────────────────────────────────┘
```

### 2-3. 操作できるもの

**この画面に入力欄は1つもありません。すべてリンクです。**

| リンク | 飛び先 |
|---|---|
| 「Decision Engine」 | `/metaphysical` |

### 2-4. データが取れないときの表示

**この画面は、どのデータが取れなくてもエラー画面になりません。**
取れなかった部分だけが以下の文言に置き換わります。

| タイル | データが無い／取れないとき |
|---|---|
| 不動産 | 該当する物件が見つかりません |
| 吉日 | 今後の吉日データはありません。 |
| 体調 | Oura API未接続またはキーがありません |
| 世の中の動き | Tavily API未接続 |
| 地域の所得 | 所得統計データはありません。 |
| 行動の提案 | RLエージェント オフライン |

> **確認ポイント**：テスト環境では外部サービスに繋がっていないことが多く、
> 「Oura API未接続」「Tavily API未接続」が**常に出ているのが正常**な場合があります。
> 事前に環境の設定を確認してください。

### 2-5. 表示の鮮度

この画面のデータは**最大60秒**、体調と世の中の動きはさらに**最大300秒（5分）**古い可能性があります。
また、体調と世の中の動きは**1.5秒で応答が返らないと諦めて「未接続」表示**になります。

> **確認ポイント**：「さっき更新したのに反映されない」は、この時間差が原因のことがあります。
> 数分待って再確認してから報告してください。

読み込み中の専用表示はありません（表示されたときには完成しています）。

## 3. `/login` ログイン

### 3-1. 概要

| | |
|---|---|
| **URL** | `/login` |
| **ログイン** | 不要。ただし**ログイン済みだと `/dashboard` へ自動で飛ばされ、この画面は見えません** |

### 3-2. 構成

```
        Cloud Palette

  ログインすると、生年月日や出発地の設定を
  他の端末でも引き継げます。

  ログインしなくても、方位の判定・物件検索・
  カレンダーはそのままご利用いただけます。

  ┌──────────────────────────────┐
  │  [G]  Googleでログイン        │
  └──────────────────────────────┘

  （エラーがあるとき）⚠️ メッセージ
```

権限のないアカウントでログインしている場合だけ、上に「現在ログイン中のアカウント」の枠が出て、
メールアドレスと「ログアウトして別のアカウントでログイン」リンクが表示されます。

### 3-3. 操作

| 要素 | 挙動 |
|---|---|
| 「Googleでログイン」 | Googleの同意画面へ移動。失敗すると赤帯にエラー内容が出る |
| 「ログアウトして別のアカウントでログイン」 | ログアウトして `/login` を再読み込み |
| 「⚡ 開発用バイパスでログイン」 | **開発環境でのみ表示**。本番では出ない |

**入力欄はありません。**

> **報告対象になり得る点**：「Googleでログイン」ボタンは、
> 押しても**押せない状態（グレーアウト）になりません**。連打できてしまいます。

### 3-4. URLに付く情報

| パラメータ | 意味 |
|---|---|
| `?error=…` | 赤帯に表示されるメッセージ |
| `?next=…` | ログイン後に戻る先。**指定が無い場合は `/dashboard`** |

## 4. `/auth/callback` ログイン後の受け渡し（画面なし）

Googleでのログインが終わったあと、一瞬だけ通る場所です。**画面は表示されず、必ずどこかへ移動します。**

| 状況 | 移動先 |
|---|---|
| 成功、かつ戻り先の指定あり | 指定されたURL |
| 成功、戻り先の指定なし | **`/rentals`** |
| 失敗 | `/login?error=Could not authenticate user` |

> **重点確認項目（食い違いあり）**
> ログイン画面が想定している既定の戻り先は `/dashboard` ですが、
> ここでの既定の戻り先は **`/rentals`** で、**両者が食い違っています**。
>
> さらに `/rentals` はログインが必要な画面なので、権限のないアカウントの場合、
> ログイン成功 → `/rentals` → 権限なし → `/login` に戻る、という往復が起きます。
> **ログインしたのにログイン画面に戻ってきた**という現象が出たら、この経路を疑ってください。

## 6. `/contact` お問い合わせ

ログイン不要。**このサイトで唯一の、外部に送信するフォームです。**

### 6-1. 入力項目

| ラベル | 必須 | 上限 | 種別 |
|---|---|---|---|
| お名前 | **必須** | 100文字 | 1行 |
| メールアドレス | **必須** | 200文字 | メール形式のチェックあり |
| お問い合わせ内容 | **必須** | 4000文字 | 8行の複数行入力 |

「送信することでプライバシーポリシーに同意したものとみなします。」の文中に `/privacy` へのリンクがあります。

> **見えない項目がひとつあります。**
> 画面には表示されない入力欄（迷惑投稿よけ）が1つ隠れています。
> 自動入力ツールなどが誤ってこの欄を埋めると、**画面上は「送信しました」と出るのに、
> 実際には保存されません**。ブラウザの自動入力を使ってテストする場合は注意してください。

### 6-2. 送信の流れ

```
「送信する」を押す
   │ （ボタンが「送信中...」になり押せなくなる）
   │
   ├─ 成功 ──▶ フォームが消え、緑色の枠で
   │           「送信しました」
   │           「内容を確認のうえ、必要に応じてご記入の
   │             メールアドレス宛にご連絡します。」
   │           ＋「ホームに戻る」リンク（→ /）
   │
   ├─ 入力エラー ──▶ フォームは残り、ボタンの下に赤文字
   │
   └─ 通信できない ──▶ 「通信に失敗しました。時間をおいてお試しください。」
```

**エラー文言の一覧**

| どんなとき | 文言 |
|---|---|
| 必須項目が空 | お名前・メールアドレス・お問い合わせ内容を入力してください。 |
| 文字数オーバー | 入力が長すぎます。 |
| メール形式が不正 | メールアドレスの形式が正しくありません。 |
| 保存に失敗 | 送信に失敗しました。時間をおいてお試しください。 |
| リクエストの形式不正 | リクエストの形式が正しくありません。 |
