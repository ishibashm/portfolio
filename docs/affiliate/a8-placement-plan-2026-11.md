## 実装時の注意（コードはまだ変えない）

- リンクは `rel="sponsored nofollow"`。取得コードは `rel="nofollow"` だけなので、貼るときに足す。
- PR 表記は記事冒頭（ファーストビュー）と広告枠の直前の両方。枠だけ・フッターだけにはしない。
- 誇大表現を避ける。「最安値」「必ず安い」「ランキング1位」「勝てる／開運する」などは書かない。管理画面の PR 文も転載しない。
- ハコブも楽天も本人利用（セルフバック以外の自己購入）はアイコン上 NG。運営者自身の成果を作らない。
- 商標・サービス名でのリスティング出稿はしない（ハコブは商標NG、楽天はリスティングNG、DMM FX は社名キーワードNG）。今回の範囲外。
- 既存の AdSense 枠と隣接させる場合は、アフィリエイトを「PR（広告）」付きの独立ブロックにし、自動広告と見た目が溶けないようにする。
- 公開後、A8 の「広告掲載URL管理」へ当該 URL を提出する。
- 本番反映の前に、`/privacy`（および必要なら `/about`）へ、アフィリエイトと成果計測 Cookie の説明を足すかを別途決める。
