どこへ — 方位と相場で選ぶ

出発地から見た8方位の地図・家賃水準・候補エリアを比較できます

方位で街を探す

→

淡色地図と羅盤の8方位を重ね、市区町村ごとの家賃相場・空き家率・ハザード参考層をまとめて確認します。

引越し先を試算する

→

出発地・候補地・移動予定日の3点から、方位の角度と三盤の参考判定・周辺相場を試算します。

本命星と吉方位を調べる

→

生まれ年から本命星を確認し、年盤・月盤ごとの方位の目安を早見表で見比べられます。

いつ・いくら — 時期と予算を整理する

引越しの日取り候補と公的統計ベースの賃料・売買相場を確認できます

引越しの日取りを選ぶ

→

六曜・土用・節入りと三盤の重なりをカレンダーで一覧し、候補日を整理します。

家賃相場を分析する

→

e-Stat の住宅・土地統計調査をもとに、エリア別の平米単価と空き家率の傾向を比較します。

購入の相場を分析する

→

国土交通省の公開データをもとに、成約価格帯と地域差を客観的に把握できます。
