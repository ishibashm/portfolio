## Gemini の提案の要約

### (a) 地図
- 既定の下地を地理院「標準」から「淡色」に替え、CSS フィルタで彩度を落とす（`saturate(0.38) contrast(0.95) brightness(1.03) sepia(0.08)`）。陰影起伏図を任意で薄く重ねる。
- 中心点を青いピンから羅盤風の SVG マーカーへ（紺 `#1E3A6E` の芯 + 金 `#C9A54A` の輪）。
- 方位の境目は 1px の放射線。真北だけ金色の線。
- 扇形の塗りは `TIER_FILL` のまま、不透明度を淡色地図向けに調整。凶と天中殺は破線の縁も付けて、色だけに頼らない。
- 8 方位の札は、地図の短辺の 33% の円周上に並べた白いカプセル（段階色の点 + 「北東 · S 三盤吉」）。スマホでも重ならない。
- 選んだ方位は紺 3px で縁取り、ほかの 7 方位は薄くする。
- 検索半径の緑の円（`#10b981`）は、吉の色と同じなのでやめて、紺の細い破線の距離の輪にする。
- 地図の上の操作は 3 つにまとめる: 左上に状態ピル、右上に細い縦ツールバー（設定は 1 枚のポップオーバー）、左下に 1 行の凡例。**右下はしるべのために空ける。**
- スマホ: 埋め込み地図は 1 本指でページをスクロールできるようにし、全画面（100dvh + safe-area）で地図を操作。下から 3 段のボトムシート。
- ダーク: サイトの `:root.dark` に地図も合わせる（`useMapTheme` を連動）。Leaflet の間は CSS の反転フィルタ、地図の背景は `#121622`。
- 将来: MapLibre GL JS + 地理院の最適化ベクトルタイル、または Protomaps の PMTiles を Cloudflare R2 に置く。地名を扇形の上に描ける。

### (b) サイト全体
- しるべの紺・金・生成りをブランドの軸にする。ピンクのぼかし背景、重い backdrop-blur、`rounded-3xl`、赤いタブはやめる。
- 色はちょうど 4 役:

| 役 | ライト | ダーク |
|---|---|---|
| ① 地色 | `#FAF7F2`（カード `#FFFFFF`、罫線 `#DDD6CA`） | `#151722`（カード `#1E2130`、罫線 `#383E56`） |
| ② 文字 | `#171C2B`（補足 `#4D5568`） | `#F3EFE8`（補足 `#B2B8CA`） |
| ③ 主アクセント（勝色） | `#1E3A6E` | `#8CB4FF` |
| ④ 副アクセント（羅盤金） | 文字 `#8A6216` / 線画 `#C9A54A` | `#DFB968` |

  判定色（`TIER_FILL` 6 色・天中殺）はそのまま別の層として残す。
- 書体: Web フォントは増やさない。Geist + 遅延読み込みの Shippori Mincho（見出し）のまま、和文は Hiragino → BIZ UDPGothic → Yu Gothic の順。`text-[10px]` をやめて 12px を下限にする。数字は `tabular-nums`。
- 寸法: 余白は 4px 刻み（4/8/12/16/20/24/32/48）。角丸は 6 / 10 / 16 / 9999px（カードは 24px から 16px へ）。影は 3 段。本文の最大幅は 1200px、地図の画面は 1440px。
- 部品: ボタンは高さ 44px の紺のピル。都市のピルは、選んでいるものを紺にする（今は黒）。サイドバーで選んでいる項目は、淡い藍の面に紺 3px の左線。判定バッジは「色の点 + S〜X + 呼び名」。
- feat/dark-mode と同じ変数名で値だけを替える対応表がある（raw の 4.1 節）。

### 注意点・リスク
1. **ブランドの色を rose から紺に替えるのは大きな判断**なので、本人に決めてもらう。決まれば、feat/dark-mode のトークンもその値で作り直すのが二度手間にならない。
2. 扇形の不透明度を下げる案（平 C が 0.04 など）。ΔE テストは塗りの色そのものしか見ていない。淡色地図の上に重ねた後の色で、隣の段との差が残るかは測っていないので、採るなら合成後の色で ΔE を確認する。
3. Gemini が書いた ΔE やコントラストの数値は、こちらでは検算していない。`TIER_FILL` を変えなければ今のテストは通る。
4. CSS 反転のダーク地図は、写真や色別標高図には使えない（案でも除外している）。地図の見え方はスクリーンショットで確認する。
5. MapLibre への移行は bundle が約 200KB 増え、スタイルの保守も要る。地理院の最適化ベクトルタイルの提供状況も、採る前に確かめる。いまは後回し。
6. モックの Google Fonts と unpkg はモックだけ。本番は今の next/font と npm のまま。
7. 4K の文字の拡大率の変更（24px → 20px）と「システム稼働中」の撤去は、デザインの外の判断なので別に聞く。
