# AdSense 導入手順（cloud-palette.com）

**このドキュメントは、AdSense の申請から広告表示までにやることを、実際に必要な操作だけ並べたものです。**
コード側の準備は完了しています。以下の 3 ステップ以外に作業はありません。

---

## 現状（コード側の準備状況）

| 項目 | 状態 |
|---|---|
| 独自ドメイン | ✅ `cloud-palette.com` |
| プライバシーポリシー | ✅ `/privacy`（AdSense・Cookie・パーソナライズ広告・オプトアウト先を明記済み） |
| 利用規約・運営者情報・問い合わせ | ✅ `/terms` `/about` `/contact` |
| オリジナルコンテンツ | ✅ 記事 465 ページ（`/houi` 配下） |

| `ads.txt` | ✅ ID 設定時のみ配信。未設定なら 404（架空の ID を出さない） |

いずれも `NEXT_PUBLIC_ADSENSE_ID` が設定されたときに一斉に有効になります。
未設定の間は、広告関連の出力が一切ありません（空の枠も出ません）。

---

## ステップ 1: AdSense に申し込む（あなたの操作）

<https://adsense.google.com/> でアカウントを作り、サイトに `cloud-palette.com` を登録します。

- 支払い先の住所・氏名、税務情報の入力が必要です
- 利用規約への同意が必要です

**この 3 つは契約行為なので、代行できません。**

申し込みの途中で「サイトを AdSense にリンク」としてコードの設置を求められます。
そこで表示される 16 桁の ID を控えてください。**必要なのはこの ID だけです。**
表示されたスニペット本体を貼る必要はありません（同じものをコードが出力します）。

管理画面によっては `pub-` の形しか出ないことがあります。それで構いません
（`ca-pub-` が要る箇所はコード側で変換します）。「お客様 ID」は別物で、
コードには使いません。

---

## ステップ 2: ID を設定する（設定済み）

**2026-08-07 に設定済みです。** 変更したいときだけ触ってください。

GitHub の **Settings → Secrets and variables → Actions → Variables** に
`NEXT_PUBLIC_ADSENSE_ID` を置いてあります（現在の値: `pub-8880564510659079`）。

secret ではなく variable にしているのは、パブリッシャー ID が `ads.txt` と
ページのソースに出る公開情報だからです。`ENV_FILE` secret は書き込み専用で
中身を読み出せないため、追記ではなく別の変数として渡しています
（`.github/workflows/deploy.yml` が `.env` に書き足します）。

`pub-` と `ca-pub-` のどちらの形でも受け付けます。変更後は master への
push か、Actions から `Deploy to GCP Cloud Run` の再実行で反映されます。

デプロイ後、次が自動的に成立します。

- `<head>` に AdSense のスクリプトと確認用メタタグが入る → **サイト確認が通る**
- `https://cloud-palette.com/ads.txt` が `google.com, pub-XXXX, DIRECT, f08c47fec0942fa0` を返す
- 自動広告を有効にすれば、そのまま広告が出る

## ステップ 3: 広告の出し方を選ぶ（あなたの操作・管理画面のみ）

### A. 自動広告だけで運用する（おすすめ・追加作業なし）

AdSense 管理画面 → 広告 → サイトごと → 自動広告を**オン**。
これだけで Google が配置を決めて表示します。コード側の変更は不要です。

### B. 決まった位置に出す（任意）

管理画面で広告ユニットを作ると `data-ad-slot` の数字が発行されます。
それを ID と同じく **Variables** に足すと、あらかじめ埋めてある枠に表示されます。

```
NEXT_PUBLIC_ADSENSE_SLOT_ARTICLE=1234567890
NEXT_PUBLIC_ADSENSE_SLOT_LIST=1234567890
```

枠の場所は `<AdBanner />` を置いてある次のページです。

- `/`（トップ）
- `/houi`、`/houi/{年}/{星}`、`/houi/{年}/{星}/{月}`
- `/houi/area`、`/houi/area/{コード}`
- `/guide`、`/guide/{slug}`

スロットを設定しない限り、これらの枠は**何も描きません**。A と B は併用できます。

## 審査に落ちたときに見るところ

| 指摘されがちな点 | 現状 |
|---|---|
| 価値の低いコンテンツ | 記事 465 ページ。ただし大半が自動生成の方位表なので、指摘される可能性はある |
| プライバシーポリシーがない | あり（`/privacy`） |
| サイトが未完成に見える | 空の広告枠は撤去済み。ログイン必須の画面は `robots.txt` で閉じている |
| 運営者が不明 | `/about` `/contact` あり |

「価値の低いコンテンツ」で落ちた場合に効くのは、記事ページに固有の解説を増やすことです。
現状の `/houi` 配下は計算結果の表が中心で、ページ間の差分が数値だけになっています。
